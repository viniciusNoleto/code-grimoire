`jsonb` guarda JSON num formato binário: sem espaços, sem chaves duplicadas, sem ordem de chaves, e com operadores e índices. Use para atributos variáveis (especificações de produto, metadados, payloads de integrações), não para fugir da modelagem de dados que têm estrutura fixa.

```sql [jsonb.sql]
-- produtos.atributos = {"marca": "MX", "cores": ["preto", "branco"], "dimensoes": {"largura": 44}}

SELECT atributos -> 'marca'               FROM produtos;  -- "MX"   (jsonb)
SELECT atributos ->> 'marca'              FROM produtos;  -- MX     (text)
SELECT atributos #>> '{dimensoes,largura}' FROM produtos; -- 44     (caminho, text)
SELECT atributos['cores'][0]              FROM produtos;  -- "preto" (subscript, PG 14)

SELECT * FROM produtos WHERE atributos @> '{"marca": "MX"}';        -- contém (usa GIN)
SELECT * FROM produtos WHERE atributos ? 'garantia';                  -- tem a chave
SELECT * FROM produtos WHERE atributos @? '$.cores[*] ? (@ == "branco")'; -- jsonpath

UPDATE produtos SET atributos = jsonb_set(atributos, '{dimensoes,largura}', '45');
UPDATE produtos SET atributos = atributos || '{"garantia": "1 ano"}';  -- mescla
UPDATE produtos SET atributos = atributos - 'obsoleto';                -- remove chave

-- Expandir arrays e objetos em linhas
SELECT p.id, cor FROM produtos p, jsonb_array_elements_text(p.atributos -> 'cores') AS cor;
SELECT chave, valor FROM produtos, jsonb_each(atributos) AS e(chave, valor);

-- JSON_TABLE (PG 17): JSON vira tabela relacional
SELECT jt.* FROM pedidos_api,
  JSON_TABLE(payload, '$.itens[*]' COLUMNS (sku text PATH '$.sku', qtd int PATH '$.qtd')) AS jt;

-- Índices
CREATE INDEX ON produtos USING gin (atributos jsonb_path_ops);   -- menor, só @> e @?
CREATE INDEX ON produtos ((atributos ->> 'marca'));               -- B-tree numa chave muito filtrada
```

::note{type="pitfall" title="Quando não usar JSONB"}
Campos que você filtra, ordena, junta ou valida sempre devem virar colunas: ganham tipo, `NOT NULL`, FK, estatísticas melhores e índices simples. Atualizar uma chave reescreve o documento inteiro, então documentos grandes atualizados com frequência custam caro.
::
