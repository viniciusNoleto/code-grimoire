Uma consulta pode usar o resultado de outra: como valor, como tabela ou como conjunto de comparação. CTEs dão nome a essas etapas.

```sql [subconsultas.sql]
-- Escalar: retorna um valor
SELECT nome, (SELECT count(*) FROM pedidos p WHERE p.cliente_id = c.id) AS qtd FROM clientes c;

-- Em FROM (tabela derivada)
SELECT faixa, count(*) FROM (
  SELECT CASE WHEN total > 500 THEN 'alto' ELSE 'normal' END AS faixa FROM pedidos
) t GROUP BY faixa;

-- Comparação com conjunto
SELECT * FROM produtos WHERE preco > ALL (SELECT preco FROM produtos WHERE categoria = 'mouse');
```

### WITH (Common Table Expressions)

Uma CTE dá nome a uma subconsulta e deixa consultas longas legíveis de cima para baixo. Desde o PG 12, CTEs não recursivas usadas uma vez são **embutidas** na consulta (o planejador otimiza tudo junto). Use `MATERIALIZED` para forçar o cálculo separado, ou `NOT MATERIALIZED` para forçar o embutimento.

```sql [cte.sql]
WITH pagos AS (
  SELECT cliente_id, sum(total) AS gasto
  FROM pedidos WHERE status = 'pago'
  GROUP BY cliente_id
),
vips AS (
  SELECT cliente_id FROM pagos WHERE gasto > 5000
)
SELECT c.nome, p.gasto
FROM vips v JOIN pagos p USING (cliente_id) JOIN clientes c ON c.id = v.cliente_id;

-- CTE que modifica dados: move pedidos antigos para o arquivo numa só instrução
WITH movidos AS (
  DELETE FROM pedidos WHERE criado_em < now() - interval '5 years' RETURNING *
)
INSERT INTO pedidos_arquivo SELECT * FROM movidos;
```

### CTE recursiva

```sql [recursiva.sql]
-- Árvore de categorias: todos os descendentes de "Periféricos", com profundidade e caminho
WITH RECURSIVE arvore AS (
  SELECT id, nome, pai_id, 1 AS nivel, ARRAY[nome] AS caminho
  FROM categorias WHERE nome = 'Periféricos'          -- caso base
  UNION ALL
  SELECT c.id, c.nome, c.pai_id, a.nivel + 1, a.caminho || c.nome
  FROM categorias c JOIN arvore a ON c.pai_id = a.id   -- passo recursivo
)
SEARCH DEPTH FIRST BY nome SET ordem                    -- PG 14: ordem de travessia
CYCLE id SET em_ciclo USING rota                         -- PG 14: proteção contra ciclos
SELECT repeat('  ', nivel - 1) || nome AS item, caminho FROM arvore ORDER BY ordem;

-- Gerar séries sem tabela: generate_series é mais simples
SELECT d::date FROM generate_series('2026-11-01', '2026-11-30', interval '1 day') d;
```
