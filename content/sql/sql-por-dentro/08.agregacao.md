`GROUP BY` junta as linhas com os mesmos valores nas colunas listadas e reduz cada grupo a uma linha. No `SELECT`, toda coluna precisa estar no `GROUP BY` ou dentro de um agregado (o Postgres aceita colunas que dependem funcionalmente da chave primária agrupada).

```sql [agregacao.sql]
SELECT
  date_trunc('month', criado_em) AS mes,
  count(*)                                   AS pedidos,
  count(*) FILTER (WHERE status = 'cancelado') AS cancelados,   -- agregado condicional
  sum(total)                                 AS faturamento,
  round(avg(total), 2)                       AS ticket_medio,
  percentile_cont(0.5) WITHIN GROUP (ORDER BY total) AS mediana,
  count(DISTINCT cliente_id)                 AS clientes_unicos
FROM pedidos
WHERE criado_em >= '2026-01-01'
GROUP BY 1                                   -- posição da coluna (prático, mas menos legível)
HAVING count(*) > 10
ORDER BY mes;

-- Agregados que montam coleções
SELECT cliente_id,
       string_agg(produto, ', ' ORDER BY produto) AS produtos,
       array_agg(DISTINCT categoria)               AS categorias,
       jsonb_agg(jsonb_build_object('id', id, 'total', total)) AS pedidos_json
FROM ...
GROUP BY cliente_id;
```

### GROUPING SETS, ROLLUP e CUBE

```sql [rollup.sql]
-- Subtotais por região, por região+cidade e total geral numa só consulta
SELECT regiao, cidade, sum(total), grouping(cidade) AS e_subtotal
FROM vendas
GROUP BY ROLLUP (regiao, cidade);
-- CUBE (a, b) gera todas as combinações; GROUPING SETS ((a), (b), ()) escolhe quais

-- PG 19: GROUP BY ALL agrupa por todas as colunas não agregadas do SELECT
SELECT regiao, cidade, sum(total) FROM vendas GROUP BY ALL;
```
