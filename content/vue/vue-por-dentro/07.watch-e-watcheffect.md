### watch

::signature
`watch(fonte | [fontes], (novo, antigo) => …, { immediate, deep, once, flush })`
::

Observa uma fonte específica e roda o callback quando ela muda. É **preguiçoso**: não roda na criação, a menos que `immediate: true`. A fonte pode ser um ref, um getter, um objeto reactive ou um array deles.

```js [watch-fontes.js]
const estado = reactive({ pagina: 1, filtro: '' });

watch(termo, (novo, antigo) => { /* ref */ });
watch(() => estado.pagina, (p) => carregar(p));             // getter: propriedade de reactive
watch([termo, () => estado.pagina], ([t, p], [tAnt, pAnt]) => { /* várias fontes */ });

watch(estado, () => salvarRascunho(estado));                // reactive direto: deep automático
watch(() => estado.filtros, cb, { deep: true });            // getter de objeto: precisa de deep
watch(() => estado.arvore, cb, { deep: 2 });                // 3.5: profundidade máxima

watch(usuario, cb, { once: true });                         // 3.4: para depois da 1ª vez
```

::note{type="pitfall" title="Armadilha clássica"}
`watch(estado.pagina, …)` não funciona: você passou o *número*, não uma fonte reativa. Use um getter: `watch(() => estado.pagina, …)`. O mesmo vale para props: `watch(() => props.id, …)`.
::

### watchEffect

::signature
`const handle = watchEffect(() => { … }, { flush })`
::

Roda **imediatamente** e rastreia sozinho tudo o que leu, re-executando quando qualquer leitura muda. Bom quando as dependências são as mesmas que você usa no corpo. Só rastreia o que é lido antes do primeiro `await`.

```js [watchEffect.js]
watchEffect(async () => {
  const res = await fetch(`/api/pedidos?pagina=${pagina.value}&q=${termo.value}`); // pagina e termo rastreados
  pedidos.value = await res.json();
});
```

### Cleanup, flush, pause e stop

- **`onWatcherCleanup(fn)`** :version[3.5]: registra uma limpeza que roda antes da próxima execução (e no stop). Precisa ser chamado de forma síncrona, antes de qualquer `await`. Antes da 3.5 o equivalente era o terceiro argumento `onCleanup` do callback.
- **`flush`**: `'pre'` (padrão) roda antes do render do componente; `'post'` roda depois, com o DOM atualizado (atalho `watchPostEffect`); `'sync'` roda na hora de cada mutação (atalho `watchSyncEffect`), caro e raramente necessário.
- **Handle**: `watch` e `watchEffect` retornam uma função que para o watcher, com `pause()`, `resume()` e `stop()` :version[3.5].

```js [onWatcherCleanup.js]
import { watch, onWatcherCleanup } from 'vue';

watch(id, async (novoId) => {
  const controller = new AbortController();
  onWatcherCleanup(() => controller.abort());   // id mudou de novo: cancela a requisição antiga
  const res = await fetch(`/api/itens/${novoId}`, { signal: controller.signal });
  item.value = await res.json();
});
```

Timeouts combinados (`AbortSignal.any`, `AbortSignal.timeout`), o que `fetch` considera erro e leitura em streaming estão em [Fetch, AbortController e Streams](/web#fetch-abort-e-streams), no tomo Web.

::note{type="pitfall" title="Watchers criados depois de um await"}
Watchers criados de forma síncrona no `setup` ficam presos ao componente e param sozinhos na desmontagem. Um watcher criado dentro de um callback assíncrono (depois de um `await`, num `setTimeout`) não fica preso a nada e vaza. Pare-o manualmente com o handle.
::

### effectScope, getCurrentScope e onScopeDispose

::signature
`const scope = effectScope(); scope.run(() => { … }); scope.stop()`
::

Todo componente tem um escopo de efeitos que é descartado na desmontagem. `effectScope` cria o seu próprio, para agrupar computeds e watchers fora de um componente (stores, composables compartilhados). `onScopeDispose(fn)` registra uma limpeza no escopo ativo; num composable, é a alternativa a `onUnmounted` que também funciona fora de componentes.

```js [useIntervalo.js]
import { ref, onScopeDispose } from 'vue';

export function useAgora(intervalo = 1000) {
  const agora = ref(Date.now());
  const id = setInterval(() => { agora.value = Date.now(); }, intervalo);
  onScopeDispose(() => clearInterval(id));   // limpa no unmount OU no scope.stop()
  return agora;
}
```
