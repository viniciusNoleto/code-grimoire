```vue [Cartao.vue]
<script setup>
const props = defineProps({ cor: String });
const tamanho = ref(16);
</script>

<style scoped>
.cartao { border: 1px solid; color: v-bind('props.cor'); font-size: v-bind(tamanho + 'px'); }
.cartao :deep(.titulo) { font-weight: 600; }   /* atinge elementos de componentes filhos */
:slotted(p) { margin: 0; }                      /* atinge conteúdo vindo de slot */
:global(.tema-escuro) .cartao { color: white; } /* regra global dentro do bloco scoped */
</style>

<style module>
.destaque { outline: 2px solid; }   /* uso: :class="$style.destaque" ou useCssModule() */
</style>
```

- **`scoped`** adiciona um atributo `data-v-xxxx` aos elementos e às regras, limitando o CSS ao componente. O elemento raiz de um filho também recebe o atributo do pai.
- **`v-bind()` no CSS** vira uma variável CSS ligada a estado reativo, atualizada sem recompilar o estilo.
- **`module`** gera classes com hash, acessíveis por `$style` ou `useCssModule()`.
