::signature
`provide(chave, valor)   ·   const v = inject(chave, padrao?, tratarComoFabrica?)`
::

O equivalente do Context do React: um ancestral **fornece** um valor e qualquer descendente o **injeta**, sem passar por cada nível. A diferença importante está na atualização. Se o valor fornecido é reativo (um ref ou reactive), só os componentes que **leem** aquele dado no render atualizam. O provider não precisa renderizar de novo, e não existe o problema de "todos os consumidores renderizam" do React.

```ts [auth.ts]
import { ref, readonly, provide, inject, type InjectionKey, type Ref } from 'vue';

type Auth = {
  usuario: Readonly<Ref<Usuario | null>>;
  entrar: (email: string, senha: string) => Promise<void>;
  sair: () => void;
};

// Symbol + InjectionKey: chave única e tipada
export const AuthKey: InjectionKey<Auth> = Symbol('auth');

export function provideAuth() {
  const usuario = ref<Usuario | null>(null);

  async function entrar(email: string, senha: string) {
    usuario.value = await api.login(email, senha);
  }
  function sair() { usuario.value = null; }

  // readonly: descendentes leem, mas só mudam via funções (fluxo de dados previsível)
  provide(AuthKey, { usuario: readonly(usuario), entrar, sair });
}

export function useAuth() {
  const auth = inject(AuthKey);
  if (!auth) throw new Error('useAuth precisa de provideAuth() num ancestral');
  return auth;
}
```

```vue [uso.vue]
<!-- App.vue: <script setup> provideAuth() </script> -->

<script setup>
const { usuario, sair } = useAuth();
</script>

<template>
  <span v-if="usuario">Olá, {{ usuario.nome }} <button @click="sair">Sair</button></span>
</template>
```

- **Valores padrão:** `inject('tema', 'claro')`; para objetos caros, `inject('x', () => criar(), true)` trata o padrão como fábrica.
- **Nível de app:** `app.provide(...)` disponibiliza para todos os componentes, útil em plugins.
- **`hasInjectionContext()`** diz se você está num lugar onde `inject` funciona (setup, ou um `app.runWithContext`), útil em composables que também rodam fora de componentes.
- **Escopo:** provide/inject é ótimo para dados de uma subárvore (formulário, tabela, tema de uma seção). Para estado global da aplicação, com DevTools, SSR e organização, use Pinia.

::note{type="pitfall" title="Armadilha"}
`provide('contador', contador.value)` fornece o *número*, que nunca mais muda. Forneça o ref (`provide('contador', contador)`) ou um getter/computed. Na bancada do capítulo [03](#o-que-causa-re-render), a caixa `<LeTema>` mostra que só o consumidor atualiza quando o tema fornecido muda.
::
