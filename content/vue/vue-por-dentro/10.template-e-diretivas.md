| Diretiva | O que faz e detalhes |
| --- | --- |
| `v-if` / `v-else-if` / `v-else` | Cria e destrói o elemento (e o estado dos componentes dentro). |
| `v-show` | Só alterna `display: none`. Mais barato para alternâncias frequentes; não funciona em `<template>`. |
| `v-for` | `v-for="(item, i) in itens" :key="item.id"`. Também itera objetos e intervalos (`n in 10`). Sempre com `key` estável. |
| `v-on` / `@` | Eventos. Modificadores: `.prevent`, `.stop`, `.once`, `.self`, `.capture`, `.passive`, teclas (`@keyup.enter`), `.exact`. |
| `v-bind` / `:` | Liga atributo ou prop a uma expressão. `:id` sozinho equivale a `:id="id"` (3.4). `v-bind="obj"` espalha um objeto. |
| `v-model` | Ligação bidirecional em inputs e componentes. Modificadores `.lazy`, `.number`, `.trim`. |
| `v-slot` / `#` | Preenche slots nomeados e recebe props de slot (`#item="{ item }"`). |
| `v-html` | Insere HTML cru. **Risco de XSS** com conteúdo do usuário; nunca use sem sanitizar (DOMPurify). XSS, CSP e Trusted Types em [Origem e segurança](/web#origem-e-seguranca). |
| `v-text` | Define o `textContent`. |
| `v-once` | Renderiza uma vez e trata o trecho como estático dali em diante. |
| `v-memo="[a, b]"` | Pula o re-render do trecho se os valores não mudaram. Para listas enormes com `v-for`. |
| `v-pre` | Não compila o conteúdo (mostra as chaves duplas de interpolação literalmente). |
| `v-cloak` | Esconde o template não compilado até montar (só para uso sem build). |

```vue [ListaPedidos.vue]
<template>
  <form @submit.prevent="buscar">
    <input v-model.trim="termo" @keyup.esc="termo = ''" />
  </form>

  <p v-if="carregando">Carregando…</p>
  <p v-else-if="!pedidos.length">Nenhum pedido.</p>
  <ul v-else>
    <li v-for="p in pedidos" :key="p.id" :class="{ atrasado: p.atrasado }">
      {{ p.codigo }} · {{ p.status }}
    </li>
  </ul>

  <TabelaDados :linhas="pedidos">
    <template #cabecalho>Pedidos</template>
    <template #celula="{ linha, coluna }">
      <StatusPill v-if="coluna === 'status'" :status="linha.status" />
      <span v-else>{{ linha[coluna] }}</span>
    </template>
  </TabelaDados>
</template>
```

::note{type="pitfall" title="v-if com v-for"}
No mesmo elemento, `v-if` tem precedência sobre `v-for` no Vue 3 (era o contrário no Vue 2), então `v-if` não enxerga a variável do loop. Filtre num `computed` ou envolva com `<template v-for>`.
::

### Atributos e elementos especiais

- **`key`**: identidade em listas; trocar a `key` de um componente força remontagem (útil para resetar estado).
- **`ref`**: referência a elemento ou componente (capítulo [09](#script-setup-e-macros)).
- **`<component :is="X">`**: componente dinâmico, escolhido em tempo de execução.
- **`<slot>`**: ponto de saída de conteúdo do pai; pode receber props (`<slot :item="item" />`) e ter conteúdo padrão.
- **`<template>`**: agrupador invisível para `v-if`, `v-for` e `v-slot`.

### Diretivas customizadas

```js [vFoco.js]
// Em <script setup>, qualquer variável vNomeCamel vira v-nome-camel no template
const vFoco = {
  mounted: (el, binding) => { if (binding.value !== false) el.focus(); },
};
// Hooks disponíveis: created, beforeMount, mounted, beforeUpdate, updated, beforeUnmount, unmounted
// Uso: <input v-foco />  · global: app.directive('foco', vFoco)
```

#### Exemplo: uma diretiva com IntersectionObserver

Diretivas são o lugar natural para APIs que precisam do elemento e de um cleanup. `v-visivel` chama uma função quando o elemento entra ou sai da tela, e desconecta o observer quando o elemento é desmontado.

```js [vVisivel.js]
const observadores = new WeakMap();

export const vVisivel = {
  mounted(el, { value: aoMudar, modifiers }) {
    const io = new IntersectionObserver(([e]) => {
      aoMudar(e.isIntersecting);
      if (modifiers.once && e.isIntersecting) io.disconnect();   // v-visivel.once
    }, { rootMargin: '200px' });
    io.observe(el);
    observadores.set(el, io);
  },
  unmounted(el) { observadores.get(el)?.disconnect(); },
};
// <img v-visivel.once="(v) => carregar = v" …>   ·   <li v-visivel="marcarComoLido">
```

Para usar dentro do `<script setup>`, o mesmo padrão cabe num composable com `useTemplateRef` e `onScopeDispose` (o VueUse tem `useIntersectionObserver` e `useResizeObserver`). Os quatro observers do navegador, com uma bancada ao vivo, estão em [Observers](/web#observers), no tomo Web.
