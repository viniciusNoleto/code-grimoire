A API do Vue 3.5, agrupada como na referência oficial. Os capítulos seguintes detalham cada item.

| API | Para que serve | Capítulo |
| --- | --- | --- |
| **Reatividade: núcleo** |  |  |
| `ref` | Valor reativo com `.value`. | [05](#ref-reactive-e-utilitarios) |
| `reactive` / `readonly` | Proxy profundo de um objeto; versão só leitura. | [05](#ref-reactive-e-utilitarios) |
| `computed` | Valor derivado, cacheado, só leitura ou gravável. | [06](#computed) |
| `watch`, `watchEffect` | Efeitos colaterais quando dados mudam. | [07](#watch-e-watcheffect) |
| `watchPostEffect`, `watchSyncEffect` | Atalhos de `watchEffect` com `flush` post e sync. | [07](#watch-e-watcheffect) |
| `onWatcherCleanup` :version[3.5] | Registra cleanup do watcher atual. | [07](#watch-e-watcheffect) |
| **Reatividade: utilitários** |  |  |
| `isRef`, `unref`, `toValue` | Testar e ler refs, getters ou valores comuns. | [05](#ref-reactive-e-utilitarios) |
| `toRef`, `toRefs` | Refs ligados a propriedades de um reactive. | [05](#ref-reactive-e-utilitarios) |
| `isProxy`, `isReactive`, `isReadonly` | Inspecionar proxies. | [05](#ref-reactive-e-utilitarios) |
| **Reatividade: avançado** |  |  |
| `shallowRef`, `triggerRef` | Ref reativo só no `.value`; disparo manual. | [05](#ref-reactive-e-utilitarios) |
| `shallowReactive`, `shallowReadonly` | Reatividade só no primeiro nível. | [05](#ref-reactive-e-utilitarios) |
| `customRef` | Ref com controle manual de track e trigger. | [05](#ref-reactive-e-utilitarios) |
| `toRaw`, `markRaw` | Obter o original; impedir que vire proxy. | [05](#ref-reactive-e-utilitarios) |
| `effectScope`, `getCurrentScope`, `onScopeDispose` | Agrupar e descartar efeitos juntos. | [07](#watch-e-watcheffect) |
| **Ciclo de vida** |  |  |
| `onMounted`, `onUpdated`, `onUnmounted` e os `onBefore*` | Montagem, atualização e desmontagem. | [08](#ciclo-de-vida) |
| `onErrorCaptured` | Captura erros de descendentes. | [08](#ciclo-de-vida) |
| `onActivated`, `onDeactivated` | Entrar e sair de um `<KeepAlive>`. | [08](#ciclo-de-vida) |
| `onServerPrefetch` | Busca de dados antes do render no SSR. | [08](#ciclo-de-vida) |
| `onRenderTracked`, `onRenderTriggered` | Depuração de dependências (dev). | [08](#ciclo-de-vida) |
| **Injeção de dependência** |  |  |
| `provide`, `inject`, `hasInjectionContext` | Passar dados para descendentes sem props. | [15](#provide-inject) |
| **Helpers e macros do script setup** |  |  |
| `defineProps`, `withDefaults` | Declarar props (com destructure reativo na 3.5). | [09](#script-setup-e-macros) |
| `defineEmits` | Declarar eventos. | [09](#script-setup-e-macros) |
| `defineModel` :version[3.4] / `useModel` | Prop + evento de `v-model` num ref. | [09](#script-setup-e-macros) |
| `defineExpose`, `defineOptions`, `defineSlots` | Expor API, opções do componente, tipar slots. | [09](#script-setup-e-macros) |
| `useTemplateRef` :version[3.5] | Ref para elemento ou componente do template. | [09](#script-setup-e-macros) |
| `useId` :version[3.5] | ID único e estável no SSR. | [09](#script-setup-e-macros) |
| `useAttrs`, `useSlots` | Atributos repassados e slots no script setup. | [09](#script-setup-e-macros) |
| **Template** |  |  |
| `v-if`, `v-show`, `v-for`, `v-on`, `v-bind`, `v-model`, `v-slot` | Diretivas principais. | [10](#template-e-diretivas) |
| `v-html`, `v-text`, `v-once`, `v-memo`, `v-pre`, `v-cloak` | Diretivas especiais. | [10](#template-e-diretivas) |
| `key`, `ref`, `is`, `<component>`, `<slot>`, `<template>` | Atributos e elementos especiais. | [10](#template-e-diretivas) |
| **Componentes embutidos** |  |  |
| `<Transition>`, `<TransitionGroup>` | Animações de entrada, saída e listas. | [11](#componentes-embutidos) |
| `<KeepAlive>` | Mantém componentes em cache ao alternar. | [11](#componentes-embutidos) |
| `<Teleport>` | Renderiza em outro ponto do DOM. | [11](#componentes-embutidos) |
| `<Suspense>` (experimental) | Fallback para dependências assíncronas. | [11](#componentes-embutidos) |
| **API global** |  |  |
| `createApp`, `createSSRApp`, `app.*` | Criar, configurar e montar o app. | [12](#api-global-e-app) |
| `nextTick` | Esperar o próximo flush do DOM. | [02](#como-a-reatividade-funciona) |
| `defineComponent`, `defineAsyncComponent` | Tipagem; componente carregado sob demanda. | [12](#api-global-e-app) |
| `h`, `defineCustomElement` | Render functions; Web Components. | [12](#api-global-e-app) |
