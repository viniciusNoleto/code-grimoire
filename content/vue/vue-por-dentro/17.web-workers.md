O JavaScript da página roda numa única main thread, que também processa eventos, renderiza e pinta. Uma tarefa síncrona longa congela tudo. Um Worker é outra thread, sem DOM e sem Vue, que conversa por `postMessage` com structured clone. Os tipos de Worker, transferables, `SharedArrayBuffer` e `OffscreenCanvas` em profundidade estão em [Web Workers](/web#web-workers), no tomo Web.

### Um composable useWorker

```ts [composables/useWorker.ts]
import { shallowRef, ref, markRaw, onScopeDispose } from 'vue';

export function useWorker<TEntrada, TSaida>(criar: () => Worker) {
  const worker = markRaw(criar());          // instância de navegador: nunca vira proxy
  const resultado = shallowRef<TSaida>();   // resultado pode ser grande: reatividade rasa
  const ocupado = ref(false);
  const erro = ref<Error | null>(null);
  const pendentes = new Map<number, { resolve: (v: TSaida) => void; reject: (e: Error) => void }>();
  let seq = 0;

  worker.onmessage = (e) => {
    const { id, result, error } = e.data;
    const p = pendentes.get(id); if (!p) return;
    pendentes.delete(id);
    ocupado.value = pendentes.size > 0;
    if (error) { erro.value = new Error(error); p.reject(erro.value); }
    else { resultado.value = result; p.resolve(result); }
  };

  function executar(payload: TEntrada, transfer: Transferable[] = []) {
    const id = ++seq;
    ocupado.value = true; erro.value = null;
    return new Promise<TSaida>((resolve, reject) => {
      pendentes.set(id, { resolve, reject });
      worker.postMessage({ id, payload }, transfer);
    });
  }

  onScopeDispose(() => {                    // componente desmontou (ou o escopo parou)
    worker.terminate();
    pendentes.forEach(p => p.reject(new Error('worker encerrado')));
  });

  return { executar, resultado, ocupado, erro };
}

// Uso (Vite):
const { executar, resultado, ocupado } = useWorker(() =>
  new Worker(new URL('../workers/csv.worker.ts', import.meta.url), { type: 'module' })
);
```

- **`markRaw` na instância** evita que o Vue tente torná-la reativa caso você a guarde num ref ou store.
- **`shallowRef` no resultado**: 100 mil linhas processadas não precisam de um proxy por objeto. Substitua o valor inteiro a cada resposta.
- **Dados reativos não podem ir direto para `postMessage`**: proxies não são clonáveis. Use `toRaw(estado)` ou uma cópia simples.
- **VueUse** oferece `useWebWorker` e `useWebWorkerFn` prontos, e o Comlink continua sendo útil para RPC.
