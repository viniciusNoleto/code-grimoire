Um Worker é uma thread de JavaScript separada, com seu próprio event loop e escopo global (`self`), sem acesso ao DOM. Ele conversa com a página por mensagens. É a única forma de ter paralelismo real de CPU em JavaScript no navegador.

A bolinha é movida por `requestAnimationFrame` e só anda com a main thread livre. Rode o mesmo cálculo (Fibonacci recursivo) nos dois lugares.
::

| Tipo | Quem usa | Uso típico |
| --- | --- | --- |
| **Dedicated Worker** (`new Worker`) | só a página que criou | Cálculo pesado, parse, compressão, criptografia. |
| **Shared Worker** (`new SharedWorker`) | todas as abas da mesma origem | Uma única conexão WebSocket compartilhada por várias abas. |
| **Service Worker** | a origem, mesmo sem abas abertas | Proxy de rede, offline, push ([capítulo 07](#service-workers-e-pwa)). |
| **Worklets** | o pipeline de renderização ou áudio | AudioWorklet (processamento de som em tempo real), Paint Worklet. |

```js [worker.js + main.js]
// worker.js — module worker
import { analisar } from './analise.js';
self.onmessage = ({ data }) => {
  const resultado = analisar(data.texto);
  self.postMessage(resultado);
};

// main.js
const worker = new Worker(new URL('./worker.js', import.meta.url), { type: 'module' });
worker.onmessage = ({ data }) => mostrar(data);
worker.onerror = (e) => console.error(e.message);
worker.postMessage({ texto });
// worker.terminate() quando não precisar mais
```

### Como os dados passam

- **Structured clone**: `postMessage` copia profundamente objetos, arrays, `Map`, `Set`, `Date`, `Blob`, `ArrayBuffer`, e até referências circulares. Funções, nós do DOM e protótipos de classe não passam. A mesma cópia está disponível como `structuredClone(obj)`.
- **Transferables**: `postMessage(buffer, [buffer])` move a posse sem copiar; o buffer fica vazio na origem. Vale para `ArrayBuffer`, `MessagePort`, `ImageBitmap`, `OffscreenCanvas`, streams.
- **Memória compartilhada**: `SharedArrayBuffer` é visto pelas duas threads ao mesmo tempo, coordenado com `Atomics` (`wait`, `notify`, operações atômicas). Exige isolamento cross-origin (COOP + COEP); confira `crossOriginIsolated`.
- **OffscreenCanvas**: `canvas.transferControlToOffscreen()` permite desenhar (2D, WebGL, WebGPU) dentro do Worker.

Bibliotecas como Comlink transformam o protocolo de mensagens em chamadas de função assíncronas.

::note{type="tip" title="Nos frameworks"}
A regra comum é criar o Worker no cliente e encerrá-lo no cleanup. Veja o hook [`useWorker` no React](/react#web-workers), o composable [`useWorker` no Vue](/vue#web-workers) e o [uso no Nuxt](/nuxt#web-workers).
::
