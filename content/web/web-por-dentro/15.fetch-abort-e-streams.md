`fetch` é a porta de entrada de quase todo dado da aplicação. Os detalhes que mais causam bugs são o que ela considera erro e como cancelar uma requisição que ninguém mais espera.

```js [fetch.js]
// fetch só rejeita em erro de REDE; 404 e 500 resolvem normalmente
const res = await fetch('/api/pedidos', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify(pedido),
  credentials: 'include',                              // cookies em cross-origin
  signal: AbortSignal.any([controller.signal, AbortSignal.timeout(8000)]), // cancelar OU timeout
});
if (!res.ok) throw new Error(`HTTP ${res.status}`);
const dados = await res.json();

// Cancelar ao trocar de busca (o mesmo padrão dos cleanups de React e Vue)
let atual;
async function buscar(termo) {
  atual?.abort();
  atual = new AbortController();
  try { return await (await fetch(`/busca?q=${encodeURIComponent(termo)}`, { signal: atual.signal })).json(); }
  catch (e) { if (e.name !== 'AbortError') throw e; }
}

// Enviar algo que deve sobreviver ao fechamento da página
navigator.sendBeacon('/analytics', JSON.stringify(evento));
fetch('/analytics', { method: 'POST', body, keepalive: true });
```

::note{type="tip" title="Nos frameworks"}
O `abort()` mora no cleanup: [do `useEffect` no React](/react#efeitos) e [do `watch` no Vue](/vue#watch-e-watcheffect) (`onWatcherCleanup`).
::

### Streams

`response.body` é um `ReadableStream`: você processa os dados **enquanto chegam**, sem esperar o download terminar nem guardar tudo na memória. Streams se encadeiam com `pipeThrough` (transformações) e `pipeTo` (destino), e respeitam *backpressure*: se o consumidor é lento, o produtor desacelera.

```js [streams.js]
// Ler uma resposta em streaming (ex.: tokens de um LLM via POST, onde EventSource não serve)
const res = await fetch('/api/chat', { method: 'POST', body: JSON.stringify({ pergunta }) });
const leitor = res.body.pipeThrough(new TextDecoderStream()).getReader();
for (;;) {
  const { value, done } = await leitor.read();
  if (done) break;
  saida.textContent += value;
}

// Barra de progresso de download
const total = Number(res.headers.get('Content-Length'));
let recebido = 0;
const comProgresso = res.body.pipeThrough(new TransformStream({
  transform(pedaco, ctl) { recebido += pedaco.byteLength; progresso(recebido / total); ctl.enqueue(pedaco); },
}));

// Descomprimir no navegador
const texto = await new Response(blob.stream().pipeThrough(new DecompressionStream('gzip'))).text();
```
