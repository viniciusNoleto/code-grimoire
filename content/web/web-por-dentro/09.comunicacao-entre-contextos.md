Uma aplicação web pode ter várias abas, janelas, iframes e workers ao mesmo tempo. A plataforma oferece canais para eles conversarem.

::workbench{demo="cart-broadcast" title="BroadcastChannel"}
Dois "contextos" desta página, cada um com sua própria instância de `BroadcastChannel('carrinho')`. Uma mensagem enviada por um chega aos outros (inclusive em outras abas desta página, se você abrir uma).
::

```js [contextos.js]
// BroadcastChannel: todas as abas/workers da mesma origem
const canal = new BroadcastChannel('sessao');
canal.postMessage({ tipo: 'logout' });
canal.onmessage = ({ data }) => { if (data.tipo === 'logout') location.assign('/login'); };

// postMessage entre janelas e iframes (origens diferentes): SEMPRE verifique a origem
iframe.contentWindow.postMessage({ tema: 'escuro' }, 'https://widget.parceiro.com');
window.addEventListener('message', (e) => {
  if (e.origin !== 'https://widget.parceiro.com') return;   // sem isso, qualquer site manda comandos
  aplicar(e.data);
});

// MessageChannel: um canal privado com duas pontas
const { port1, port2 } = new MessageChannel();
worker.postMessage({ porta: port2 }, [port2]);   // a porta é transferida
port1.onmessage = (e) => console.log('resposta direta', e.data);

// Web Locks: só uma aba executa algo por vez (ex.: renovar o token)
await navigator.locks.request('renovar-token', async () => { await renovar(); });

// Evento storage: outras abas são avisadas de mudanças no localStorage
window.addEventListener('storage', (e) => { if (e.key === 'tema') aplicarTema(e.newValue); });
```

::note{type="tip" title="Nos frameworks"}
Estado sincronizado entre abas: [com `useSyncExternalStore` no React](/react#useid-stores-e-hooks-proprios) e [com `customRef` no Vue](/vue#ref-reactive-e-utilitarios).
::
