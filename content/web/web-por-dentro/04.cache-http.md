A requisição mais rápida é a que não acontece. Caches existem no navegador (privado), em CDNs e proxies (compartilhados) e no Service Worker. O servidor controla todos eles com cabeçalhos.

| Diretiva de Cache-Control | Efeito |
| --- | --- |
| `max-age=N` | Fresco por N segundos: usa sem perguntar ao servidor. |
| `s-maxage=N` | Como max-age, só para caches compartilhados (CDN). |
| `no-cache` | Pode guardar, mas **revalida sempre** antes de usar. Não significa "não guarde". |
| `no-store` | Não guarde em lugar nenhum (dados sensíveis). |
| `private` / `public` | Só o navegador pode guardar / caches compartilhados também. |
| `immutable` | Não vai mudar: nem revalida no recarregar. Para arquivos com hash no nome. |
| `stale-while-revalidate=N` | Depois de expirar, serve o velho por até N s enquanto busca o novo em segundo plano. |
| `stale-if-error=N` | Serve o velho se o servidor falhar. |
| `must-revalidate` | Expirado nunca pode ser usado sem revalidar. |

### Revalidação condicional

Quando a cópia expira, o navegador não precisa baixar tudo de novo. Ele pergunta se mudou, enviando o `ETag` recebido em `If-None-Match` (ou `Last-Modified` em `If-Modified-Since`). Se não mudou, o servidor responde `304 Not Modified`, sem corpo.

### A estratégia padrão

```text [cabeçalhos recomendados]
# HTML: sempre revalida (é ele que aponta para as versões novas dos assets)
/index.html             Cache-Control: no-cache
                        ETag: "a1b2c3"

# Assets com hash no nome: cache "para sempre"
/assets/app.4f9e1c.js   Cache-Control: public, max-age=31536000, immutable

# API pública que tolera dados um pouco velhos
/api/cotacoes           Cache-Control: public, s-maxage=30, stale-while-revalidate=300

# Dados do usuário
/api/minha-conta        Cache-Control: private, no-cache
/api/extrato            Cache-Control: no-store
```

::note{type="pitfall" title="Vary"}
Se a resposta muda conforme um cabeçalho da requisição (idioma, encoding, cookie), o servidor deve enviar `Vary: Accept-Language`. Sem isso, uma CDN pode entregar a versão em inglês para quem pediu português. `Vary: Cookie` praticamente desliga o cache compartilhado.
::
