Observers substituem o padrão antigo de escutar `scroll` e `resize` e medir tudo a cada evento. O navegador calcula de forma eficiente e avisa só quando algo relevante muda.

::workbench{demo="intersection-observer" title="IntersectionObserver"}
Role a caixa. Cada item avisa quando pelo menos metade dele entra ou sai da área visível da caixa, sem nenhum listener de scroll.
::

```js [observers.js]
// IntersectionObserver: lazy loading, scroll infinito, analytics de visualização, animações de entrada
const io = new IntersectionObserver((entradas) => {
  for (const e of entradas) if (e.isIntersecting) { carregar(e.target); io.unobserve(e.target); }
}, { root: null, rootMargin: '200px', threshold: 0 });
document.querySelectorAll('[data-lazy]').forEach(el => io.observe(el));

// ResizeObserver: reagir ao tamanho do ELEMENTO, não da janela (gráficos, layouts adaptativos)
new ResizeObserver(([e]) => grafico.redimensionar(e.contentRect.width)).observe(container);

// MutationObserver: mudanças no DOM (integração com scripts de terceiros, editores)
new MutationObserver((mudancas) => { /* ... */ }).observe(alvo, { childList: true, subtree: true, attributes: true });

// PerformanceObserver: métricas (capítulo 11)
```

Para responsividade por componente, considere também **container queries** em CSS (`@container (min-width: 400px)`), que resolvem muitos casos de ResizeObserver sem JavaScript.

::note{type="tip" title="Nos frameworks"}
Observers precisam de um elemento e de um cleanup: no React, [um ref callback com cleanup](/react#refs); no Vue, [uma diretiva customizada](/vue#template-e-diretivas).
::
