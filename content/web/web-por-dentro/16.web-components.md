Três APIs nativas para criar elementos reutilizáveis que funcionam em qualquer framework ou sem nenhum: **Custom Elements** (novas tags com comportamento), **Shadow DOM** (DOM e CSS encapsulados) e **`<template>`/`<slot>`** (conteúdo inerte e pontos de inserção).

```js [contador-estoque.js]
class ContadorEstoque extends HTMLElement {
  static observedAttributes = ['qtd'];

  constructor() {
    super();
    this.attachShadow({ mode: 'open' }).innerHTML = `
      <style>:host { display: inline-flex; gap: .5em } .baixo { color: crimson }</style>
      <slot name="rotulo">Estoque</slot>: <b part="valor"></b>`;
  }
  connectedCallback() { this.render(); }                    // entrou no DOM
  disconnectedCallback() { /* limpar listeners, timers */ }  // saiu do DOM
  attributeChangedCallback() { this.render(); }             // atributo observado mudou

  render() {
    const qtd = Number(this.getAttribute('qtd') ?? 0);
    const b = this.shadowRoot.querySelector('b');
    b.textContent = qtd;
    b.className = qtd < 5 ? 'baixo' : '';
  }
}
customElements.define('contador-estoque', ContadorEstoque);   // o nome precisa ter hífen

// <contador-estoque qtd="3"><span slot="rotulo">Restam</span></contador-estoque>
// Estilizar de fora: contador-estoque::part(valor) { font-size: 2rem }
```

- **Declarative Shadow DOM** (`<template shadowrootmode="open">`) permite renderizar Shadow DOM no servidor, sem JavaScript para a primeira pintura.
- **Form-associated custom elements** (`static formAssociated = true` + `attachInternals()`) participam de formulários nativos como um input.
- **Interoperabilidade**: o Vue passa props e eventos para custom elements com naturalidade e ainda **gera** custom elements a partir de componentes ([`defineCustomElement`](/vue#api-global-e-app)); o React 19 passou a tratar propriedades e eventos customizados corretamente ([custom elements no React](/react#react-dom)).
