Tente responder antes de abrir.

::question
#title
Em que ordem rodam um `setTimeout(fn, 0)`, um `Promise.then` e um `requestAnimationFrame`?

#default
O código síncrono primeiro; depois todas as microtasks (o `then`); depois, conforme o navegador, o rAF (no próximo frame) e o timeout (na próxima task). Microtasks sempre vêm antes de qualquer nova task ou renderização.
::

::question
#title
Por que animar `transform` é mais barato que animar `left`?

#default
`left` altera a geometria e refaz layout e paint em cada frame, na main thread. `transform` só muda a composição das camadas, que o compositor faz em outra thread, mesmo com o JavaScript ocupado.
::

::question
#title
`no-cache` significa "não guarde em cache"?

#default
Não. Significa "guarde, mas revalide antes de cada uso" (com `ETag`, recebendo 304 se não mudou). Quem proíbe guardar é `no-store`.
::

::question
#title
CORS protege meu servidor?

#default
Não. A requisição chega e é executada; o navegador só impede o JavaScript de outra origem de ler a resposta. Proteção do servidor é autenticação, autorização e defesas contra CSRF.
::

::question
#title
Qual a diferença entre origem e site?

#default
Origem é esquema + host + porta (`https://app.loja.com`) e define a same-origin policy. Site é esquema + domínio registrável (`https://loja.com`) e define o que é "cross-site" para cookies `SameSite`. Subdomínios são origens diferentes do mesmo site.
::

::question
#title
Como uma CSP com nonce impede XSS?

#default
O servidor gera um valor aleatório por resposta e o coloca nos scripts legítimos e na CSP. Um script injetado pelo atacante não conhece o nonce, então o navegador se recusa a executá-lo.
::

::question
#title
Quando usar Web Worker, Service Worker e Shared Worker?

#default
Web Worker para CPU pesada sem travar a página. Service Worker para interceptar a rede (offline, cache, push). Shared Worker para compartilhar um recurso entre abas da mesma origem, como uma conexão.
::

::question
#title
Por que `SharedArrayBuffer` exige COOP e COEP?

#default
Memória compartilhada permite construir timers de altíssima precisão, que viabilizam ataques do tipo Spectre para ler memória de outros sites. O isolamento cross-origin garante que a página não carrega recursos de outras origens sem consentimento explícito.
::

::question
#title
SSE ou WebSocket?

#default
SSE quando só o servidor envia (notificações, progresso, streaming de texto): é HTTP comum, reconecta e retoma sozinho, passa por proxies. WebSocket quando os dois lados enviam com frequência e baixa latência (chat, jogos, colaboração), ou quando precisa de binário.
::

::question
#title
Por que não guardar token de sessão em `localStorage`?

#default
Qualquer script rodando na origem (um XSS, uma dependência comprometida) o lê e envia para fora. Um cookie `HttpOnly`, `Secure`, `SameSite` é inacessível ao JavaScript.
::

::question
#title
O que piora o INP e como melhorar?

#default
Long tasks na main thread no momento da interação: handlers pesados, hidratação, re-renders grandes, layout forçado. Melhore quebrando o trabalho (`scheduler.yield`), adiando o que não precisa ser imediato, movendo cálculo para Workers e reduzindo o trabalho de renderização.
::

::question
#title
Como evitar CLS causado por imagens?

#default
Declare `width` e `height` (ou `aspect-ratio`) para o navegador reservar o espaço antes de baixar a imagem. Faça o mesmo com anúncios e embeds, e evite inserir conteúdo acima do que o usuário já está vendo.
::

::question
#title
`fetch` rejeita a Promise em um 500?

#default
Não. `fetch` só rejeita em falha de rede ou cancelamento. Erros HTTP resolvem com `res.ok === false`; verifique sempre.
::
