O que a página baixa, em que ordem e com que prioridade decide quanto tempo o usuário espera pela primeira pintura útil.

### Scripts

| Forma | Baixa | Executa |
| --- | --- | --- |
| `<script>` | bloqueando o parser | na hora |
| `<script defer>` | em paralelo | depois do parse, em ordem, antes de `DOMContentLoaded` |
| `<script async>` | em paralelo | assim que chegar, sem ordem (analytics, independentes) |
| `<script type="module">` | em paralelo | como `defer` por padrão; aceita `async` |

### Dicas de recursos

```html [head.html]
<link rel="preconnect" href="https://cdn.loja.com" crossorigin>   <!-- abre DNS + TCP + TLS cedo -->
<link rel="dns-prefetch" href="https://analytics.exemplo.com">      <!-- só o DNS (mais barato) -->
<link rel="preload" href="/fontes/inter.woff2" as="font" type="font/woff2" crossorigin>  <!-- vou usar nesta página -->
<link rel="modulepreload" href="/assets/rota-produto.js">           <!-- preload de módulo JS (com dependências) -->
<link rel="prefetch" href="/assets/checkout.js">                     <!-- prioridade baixa, para a próxima página -->
<img src="destaque.avif" fetchpriority="high" alt="...">             <!-- prioridade da imagem de LCP -->
<img src="rodape.webp" loading="lazy" decoding="async" width="800" height="400" alt="...">
```

- **Imagens responsivas**: `srcset` com larguras e `sizes` dizem ao navegador qual arquivo baixar para cada tela; `<picture>` escolhe formatos (AVIF, WebP). Sempre declare `width` e `height` para reservar o espaço (CLS).
- **Fontes**: `font-display: swap` mostra texto com a fonte reserva enquanto a sua carrega; `size-adjust` e companhia no `@font-face` reduzem o pulo na troca. Faça subset para os caracteres usados.
- **Code splitting**: `import()` dinâmico carrega código só quando necessário (rotas, modais, editores).
- **103 Early Hints**: o servidor envia `Link: rel=preload` antes da resposta final, enquanto ainda gera a página.

::note{type="tip" title="Nos frameworks"}
O React 19 expõe essas dicas como funções (`preload`, `preconnect`, `preinit`) e deduplica `<link>` renderizados em qualquer componente ([react-dom](/react#react-dom)); code splitting é [`lazy`](/react#use-suspense-e-lazy). No Vue, [`defineAsyncComponent`](/vue#api-global-e-app) divide o código e ainda adia a hidratação.
::

### Speculation Rules e bfcache

```html [speculation.html]
<script type="speculationrules">
{ "prerender": [{ "where": { "href_matches": "/produtos/*" }, "eagerness": "moderate" }],
  "prefetch":  [{ "where": { "selector_matches": "a.provavel" } }] }
</script>
```

A **Speculation Rules API** (Chromium) pré-carrega ou até pré-renderiza a próxima página quando o usuário passa o mouse num link, tornando a navegação instantânea. O **back/forward cache** guarda a página inteira na memória ao sair, para que voltar seja imediato. Ela é desqualificada por `unload` listeners, `Cache-Control: no-store` em alguns navegadores e conexões abertas; use `pagehide`/`pageshow` e o DevTools (Application → Back/forward cache) para testar.
