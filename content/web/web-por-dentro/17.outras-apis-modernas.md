O suporte muda rápido. Antes de usar, confira o selo **Baseline** no MDN ou no web.dev: "Baseline widely available" significa que funciona nos principais navegadores há pelo menos 30 meses.

| API | Para quê |
| --- | --- |
| `<dialog>` | Modais nativos com foco preso, `Esc` e camada superior (`showModal()`). |
| Popover API (`popover`, `popovertarget`) | Menus, tooltips e toasts na camada superior, com fechamento ao clicar fora, sem JS. |
| CSS anchor positioning | Posicionar um popover relativo ao seu botão sem bibliotecas de posicionamento. |
| Navigation API | Interceptar navegações de SPA com um evento único (`navigation.addEventListener('navigate')`), substituindo truques com `history.pushState`. |
| WebAssembly | Rodar código compilado (C, C++, Rust, Go) perto da velocidade nativa: codecs, SQLite, editores de imagem. |
| WebGPU | GPU moderna para gráficos e computação (inclusive inferência de modelos de ML no navegador). |
| WebAuthn / Passkeys | Login sem senha com chave criptográfica no dispositivo, resistente a phishing. |
| Clipboard API | `navigator.clipboard.writeText()` e leitura com permissão. |
| Web Share | Folha de compartilhamento nativa do sistema (`navigator.share()`). |
| Notifications, Push | Notificações do sistema, também com o site fechado (via Service Worker). |
| File System Access | Abrir e salvar arquivos locais com permissão (Chromium). |
| Intl | Formatar datas, números, moedas, listas, plurais e tempos relativos por idioma, sem bibliotecas. |
| Temporal | Substituto moderno do `Date`, com fusos e calendários corretos; em implementação nos navegadores. |
| `structuredClone` | Cópia profunda nativa. |
| Page Visibility, `visibilitychange` | Pausar trabalho quando a aba fica oculta; o último momento confiável para salvar estado. |

```js [intl.js]
new Intl.NumberFormat('pt-BR', { style: 'currency', currency: 'BRL' }).format(1234.5);   // "R$ 1.234,50"
new Intl.DateTimeFormat('pt-BR', { dateStyle: 'long', timeZone: 'America/Manaus' }).format(new Date());
new Intl.RelativeTimeFormat('pt-BR', { numeric: 'auto' }).format(-1, 'day');            // "ontem"
new Intl.ListFormat('pt-BR', { type: 'conjunction' }).format(['React', 'Vue', 'Nuxt']); // "React, Vue e Nuxt"
new Intl.PluralRules('pt-BR').select(2);                                                // "other"
```
