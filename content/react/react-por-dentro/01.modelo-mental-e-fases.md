Um componente React é uma função que recebe dados e devolve uma **descrição** da interface (elementos React, objetos simples). Ele não mexe no DOM. Quem compara essa descrição com a anterior e aplica as mudanças é o React.

O ponto que mais confunde: **renderizar não é atualizar o DOM**. Renderizar é o React chamar sua função. Se o resultado for igual ao anterior, nada muda na tela, mas a função rodou mesmo assim.

::phases-diagram
::

### As fases em detalhe

1. **Gatilho.** O primeiro render (`createRoot().render()`) ou uma atualização de estado em algum componente. O React marca aquele componente como "sujo" e agenda trabalho.
2. **Render.** O React chama o componente marcado e, recursivamente, os filhos que ele retorna. Cada componente vira uma *fiber*, a unidade de trabalho interna. No modo concorrente (transições, `Suspense`) essa fase pode ser pausada, descartada e refeita, por isso ela precisa ser pura.
3. **Reconciliação.** A nova árvore é comparada com a anterior. Mesmo tipo na mesma posição: o React reaproveita o nó e atualiza atributos. Tipo diferente: desmonta tudo abaixo e monta de novo, perdendo o estado.
4. **Commit.** Aplica as mutações no DOM de uma vez, atualiza `ref`s e roda `useLayoutEffect`. Não é interrompível.
5. **Paint e efeitos.** O navegador pinta; depois o React roda os `useEffect` (de forma assíncrona, sem bloquear o paint). O que o navegador faz entre o commit e o pixel (style, layout, paint, composite) está em [Como o navegador funciona](/web#como-o-navegador-funciona), no tomo Web.

::note{type="note" title="Na prática"}
Em desenvolvimento, o `<StrictMode>` chama seus componentes, inicializadores e reducers **duas vezes**, e monta → desmonta → monta cada efeito. Isso existe para expor código impuro e efeitos sem cleanup. Se algo quebra só em dev, normalmente é esse o motivo e o bug é real.
::

```jsx [impuro.jsx]
let visitas = 0;

function Contador() {
  visitas++;                     // ❌ efeito colateral durante o render
  document.title = `${visitas}`; // ❌ mexendo no DOM no render
  return <p>Visitas: {visitas}</p>;
}

function ContadorPuro({ visitas }) {
  useEffect(() => {              // ✅ sincroniza com o mundo externo após o commit
    document.title = `${visitas}`;
  }, [visitas]);
  return <p>Visitas: {visitas}</p>;
}
```
