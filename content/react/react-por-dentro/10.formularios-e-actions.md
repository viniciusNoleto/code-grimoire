O React 19 trouxe **Actions**: funções (normalmente assíncronas) passadas para `<form action>`, `formAction` de botões ou `startTransition`. O React cuida do estado pendente, dos erros e das atualizações otimistas, e reseta o formulário não controlado depois do sucesso.

### &lt;form action>

```jsx [Newsletter.jsx]
function Newsletter() {
  async function inscrever(formData) {        // recebe FormData, sem preventDefault
    await api.inscrever(formData.get('email'));
  }
  return (
    <form action={inscrever}>
      <input name="email" type="email" required />
      <BotaoEnviar />
    </form>
  );
}
```

### useFormStatus (react-dom)

::signature
`const { pending, data, method, action } = useFormStatus()`
::

Lê o estado do `<form>` **pai**. Precisa ser chamado num componente renderizado dentro do form, não no mesmo componente que o renderiza. É o que permite um `<BotaoEnviar />` genérico.

```jsx [BotaoEnviar.jsx]
import { useFormStatus } from 'react-dom';

function BotaoEnviar() {
  const { pending } = useFormStatus();
  return <button disabled={pending}>{pending ? 'Enviando…' : 'Enviar'}</button>;
}
```

### useActionState

::signature
`const [estado, acaoDoForm, isPending] = useActionState(acao, estadoInicial, permalink?)`
::

Envolve uma action e guarda o **valor retornado** como estado. A action recebe `(estadoAnterior, formData)`. É a forma idiomática de mostrar erros de validação vindos do servidor ou de uma API.

```jsx [Login.jsx]
import { useActionState } from 'react';

async function entrar(_anterior, formData) {
  const res = await api.login(formData.get('email'), formData.get('senha'));
  if (!res.ok) return { erro: 'E-mail ou senha incorretos.', email: formData.get('email') };
  window.location.assign('/painel');
  return { erro: null };
}

function Login() {
  const [estado, acao, enviando] = useActionState(entrar, { erro: null, email: '' });
  return (
    <form action={acao}>
      <input name="email" defaultValue={estado.email} />
      <input name="senha" type="password" />
      {estado.erro && <p role="alert">{estado.erro}</p>}
      <button disabled={enviando}>Entrar</button>
    </form>
  );
}
```

### useOptimistic

::signature
`const [otimista, adicionarOtimista] = useOptimistic(estado, (atual, valor) => novo)`
::

Mostra um valor provisório **enquanto uma action está pendente**. Quando a action termina, o valor otimista é descartado e a UI volta a refletir o estado real (que você atualizou com o resultado, ou que permaneceu igual se deu erro).

```jsx [Mensagens.jsx]
function Mensagens({ mensagens, enviar }) {
  const [otimistas, adicionar] = useOptimistic(
    mensagens,
    (lista, texto) => [...lista, { id: 'temp', texto, enviando: true }]
  );

  async function acao(formData) {
    adicionar(formData.get('texto'));      // aparece na hora, com estilo "enviando"
    await enviar(formData.get('texto'));   // ao terminar, o pai atualiza `mensagens`
  }

  return (<>
    {otimistas.map(m => <p key={m.id} style={{ opacity: m.enviando ? 0.5 : 1 }}>{m.texto}</p>)}
    <form action={acao}><input name="texto" /><button>Enviar</button></form>
  </>);
}
```
