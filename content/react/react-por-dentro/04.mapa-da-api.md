Tudo o que o pacote `react` e o `react-dom` oferecem hoje (React 19.3), agrupado como na documentação oficial. Os capítulos seguintes detalham cada item com assinatura, exemplo e armadilhas.

| API | Para que serve | Capítulo |
| --- | --- | --- |
| **Estado** |  |  |
| `useState` | Variável de estado com setter. | [02](#como-o-estado-funciona) · [05](#usestate-em-detalhe) |
| `useReducer` | Estado com lógica de atualização num reducer. | [16](#usereducer) |
| `useOptimistic` :version[19] | Valor temporário enquanto uma ação assíncrona roda. | [10](#formularios-e-actions) |
| `useActionState` :version[19] | Estado derivado do resultado de uma action. | [10](#formularios-e-actions) |
| **Contexto** |  |  |
| `useContext` | Lê e assina um contexto. | [15](#context-api) |
| **Refs** |  |  |
| `useRef` | Valor mutável que não causa render; nós do DOM. | [07](#refs) |
| `useImperativeHandle` | Personaliza o que a ref do componente expõe. | [07](#refs) |
| **Efeitos** |  |  |
| `useEffect` | Sincroniza com sistemas externos, após o paint. | [06](#efeitos) |
| `useLayoutEffect` | Roda antes do paint; para medir layout. | [06](#efeitos) |
| `useInsertionEffect` | Roda antes das mutações do DOM; para libs de CSS-in-JS. | [06](#efeitos) |
| `useEffectEvent` :version[19.2] | Lógica não reativa chamada de dentro de efeitos. | [06](#efeitos) |
| **Performance** |  |  |
| `useMemo` | Cacheia o resultado de um cálculo entre renders. | [08](#performance) |
| `useCallback` | Cacheia a definição de uma função. | [08](#performance) |
| `useTransition` | Marca uma atualização como não urgente e expõe `isPending`. | [08](#performance) |
| `useDeferredValue` | Adia a atualização de uma parte não crítica da UI. | [08](#performance) |
| **Outros hooks** |  |  |
| `useId` | ID único e estável entre servidor e cliente. | [11](#useid-stores-e-hooks-proprios) |
| `useSyncExternalStore` | Assina uma store externa ao React. | [11](#useid-stores-e-hooks-proprios) |
| `useDebugValue` | Rótulo de um hook customizado no DevTools. | [11](#useid-stores-e-hooks-proprios) |
| `use` :version[19] | Lê uma Promise, um contexto ou `browser()`; pode ser condicional. | [09](#use-suspense-e-lazy) |
| **Componentes nativos** |  |  |
| `<Fragment>` | Agrupa nós sem elemento extra; aceita ref desde 19.3. | [12](#componentes-nativos) |
| `<Suspense>` | Fallback enquanto os filhos carregam. | [09](#use-suspense-e-lazy) |
| `<StrictMode>` | Verificações extras em desenvolvimento. | [12](#componentes-nativos) |
| `<Profiler>` | Mede o tempo de render programaticamente. | [12](#componentes-nativos) |
| `<Activity>` :version[19.2] | Esconde e restaura UI preservando estado. | [12](#componentes-nativos) |
| `<ViewTransition>` :version[19.3] | Anima entradas, saídas e mudanças com a View Transition API. | [12](#componentes-nativos) |
| **APIs do pacote react** |  |  |
| `createContext` | Cria um contexto. | [15](#context-api) |
| `memo` | Pula render se as props não mudaram. | [08](#performance) |
| `lazy` | Carrega o código de um componente sob demanda. | [09](#use-suspense-e-lazy) |
| `startTransition` | Versão sem hook do `useTransition`. | [08](#performance) |
| `addTransitionType` :version[19.3] | Rotula a causa de uma transição para animá-la. | [12](#componentes-nativos) |
| `cache` / `cacheSignal` | Memoização por requisição em Server Components. | [09](#use-suspense-e-lazy) |
| `act` | Processa atualizações em testes antes das asserções. | [13](#react-dom) |
| `captureOwnerStack` | Lê a Owner Stack em desenvolvimento. | [13](#react-dom) |
| **react-dom** |  |  |
| `useFormStatus` | Estado do `<form>` pai (pending, data). | [10](#formularios-e-actions) |
| `createRoot` / `hydrateRoot` | Monta o app num nó do DOM. | [13](#react-dom) |
| `createPortal` | Renderiza filhos em outro ponto do DOM. | [13](#react-dom) |
| `flushSync` | Força uma atualização síncrona do DOM. | [13](#react-dom) |
| `browser` :version[19.3] | Marca um componente como só do navegador no SSR. | [09](#use-suspense-e-lazy) |
| `preload`, `preinit`, `preconnect`… | Carregamento antecipado de recursos. | [13](#react-dom) |
