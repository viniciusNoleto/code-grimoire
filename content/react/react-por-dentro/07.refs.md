::signature
`const ref = useRef(valorInicial)  // { current: valorInicial }`
::

Uma ref é uma caixa `{ current }` que o React guarda entre renders. Mudar `ref.current` **não causa render**, e o valor é o mesmo objeto durante toda a vida do componente. Use para o que não aparece na tela: nós do DOM, IDs de timer, instâncias (Worker, EventSource, player), o valor anterior de algo.

|  | useState | useRef |
| --- | --- | --- |
| Mudar causa render? | sim | não |
| Valor atualiza quando? | no próximo render (snapshot) | imediatamente |
| Ler no render? | sim | evite (só para inicialização preguiçosa) |
| Uso típico | o que a UI mostra | DOM, timers, instâncias, flags internas |

```jsx [Cronometro.jsx]
function Cronometro() {
  const [inicio, setInicio] = useState(null);
  const [agora, setAgora] = useState(null);
  const intervalo = useRef(null);          // não aparece na tela: ref
  const inputRef = useRef(null);           // nó do DOM

  function iniciar() {
    setInicio(Date.now()); setAgora(Date.now());
    clearInterval(intervalo.current);
    intervalo.current = setInterval(() => setAgora(Date.now()), 10);
    inputRef.current.focus();
  }
  function parar() { clearInterval(intervalo.current); }

  const segundos = inicio && agora ? (agora - inicio) / 1000 : 0;
  return (<>
    <p>{segundos.toFixed(2)} s</p>
    <input ref={inputRef} placeholder="anotação" />
    <button onClick={iniciar}>Iniciar</button><button onClick={parar}>Parar</button>
  </>);
}
```

### ref como prop e cleanup de ref :version[19]

No React 19, componentes de função recebem `ref` como uma prop comum. `forwardRef` não é mais necessário em código novo. E um **callback ref** pode retornar uma função de cleanup, chamada quando o nó sai do DOM.

```jsx [ref-react-19.jsx]
// Antes: const Campo = forwardRef((props, ref) => <input ref={ref} {...props} />);
function Campo({ ref, ...props }) {
  return <input ref={ref} {...props} />;
}

// Callback ref com cleanup: ótimo para observers
function Medidor() {
  return (
    <div ref={(no) => {
      const obs = new ResizeObserver(([e]) => console.log(e.contentRect.width));
      obs.observe(no);
      return () => obs.disconnect();   // React 19: chamado quando o nó é removido
    }} />
  );
}
```

### Observers com ref callback

O mesmo padrão vira um hook reutilizável. O ref callback é o lugar certo para observers: ele recebe o nó assim que existe e o cleanup roda quando o nó sai, sem `useEffect` nem `useRef` intermediários. Envolva-o em `useCallback` para que o React não desconecte e reconecte o observer a cada render.

```jsx [useVisivel.jsx]
function useVisivel(opcoes) {
  const [visivel, setVisivel] = useState(false);
  const ref = useCallback((no) => {
    if (!no) return;
    const io = new IntersectionObserver(([e]) => setVisivel(e.isIntersecting), opcoes);
    io.observe(no);
    return () => io.disconnect();
  }, [opcoes?.rootMargin, opcoes?.threshold]);   // eslint-disable-line react-hooks/exhaustive-deps
  return [ref, visivel];
}

function ImagemPreguicosa({ src, alt }) {
  const [ref, visivel] = useVisivel({ rootMargin: '200px' });
  return <div ref={ref} className="moldura">{visivel && <img src={src} alt={alt} />}</div>;
}
```

`IntersectionObserver`, `ResizeObserver`, `MutationObserver` e `PerformanceObserver` em profundidade, com uma bancada ao vivo, estão em [Observers](/web#observers), no tomo Web.

### useImperativeHandle

::signature
`useImperativeHandle(ref, () => objetoExposto, dependencias?)`
::

Em vez de expor o nó do DOM inteiro, o componente expõe só os métodos que fazem sentido. Raro, útil em componentes de biblioteca (player de vídeo, editor). Prefira props quando o comportamento puder ser declarativo (`aberto={true}` em vez de `ref.current.abrir()`).

```jsx [CampoBusca.jsx]
function CampoBusca({ ref }) {
  const input = useRef(null);
  useImperativeHandle(ref, () => ({
    focar: () => input.current.focus(),
    limpar: () => { input.current.value = ''; },
  }), []);
  return <input ref={input} type="search" />;
}

// No pai: buscaRef.current.focar()  — o pai não tem acesso ao <input> em si
```

Desde o React 19.3, `<Fragment ref={ref}>` entrega uma `FragmentInstance` que age sobre os filhos como grupo: `focus()`, `addEventListener`, `observeUsing(observer)`, `scrollIntoView()`, sem precisar de um `div` extra (capítulo 12).
