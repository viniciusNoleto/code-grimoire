Como o Next transforma componentes React em páginas servidas por rota: o que roda no servidor e o que vai para o navegador, quando uma página é estática ou dinâmica, como o cache funciona no modelo novo e como mutar dados com segurança. Neste tomo, :server[servidor] e :client[cliente] têm cores próprias.
