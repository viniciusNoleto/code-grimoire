Cada pasta dentro de `app/` é um **segmento** da URL. Uma pasta só vira rota pública quando tem um `page.tsx` (UI) ou um `route.ts` (endpoint HTTP). Os outros arquivos especiais envolvem a página em camadas.

| Arquivo | Papel |
| --- | --- |
| `layout.tsx` | Envolve o segmento e os filhos. **Não remonta** ao navegar entre rotas irmãs: estado e efeitos são preservados. |
| `template.tsx` | Como layout, mas remonta a cada navegação (útil para animação de entrada). |
| `page.tsx` | A UI da rota. Recebe `params` e `searchParams` como Promises. |
| `loading.tsx` | Atalho para um `<Suspense>` em volta da página e dos segmentos abaixo. |
| `error.tsx` | Error boundary do segmento. Precisa ser :client['use client']. |
| `not-found.tsx` | UI exibida quando `notFound()` é chamado. |
| `route.ts` | Endpoint HTTP (`GET`, `POST`…). Não pode coexistir com `page.tsx` no mesmo segmento. |
| `default.tsx` | Fallback de um slot paralelo. Obrigatório para todo slot desde o Next 16. |

| Pasta | Significado | Exemplo |
| --- | --- | --- |
| `[slug]` | segmento dinâmico | `/produtos/teclado` |
| `[...slug]` | captura tudo (1 ou mais) | `/blog/2026/11/cache` |
| `[[...slug]]` | captura tudo, opcional (0 ou mais) | `/docs` e `/docs/a/b` |
| `(grupo)` | organiza sem entrar na URL; pode ter layout próprio | `(loja)/produtos` → `/produtos` |
| `_pasta` | privada, fora do roteamento | `_components/` |
| `@slot` | rota paralela: vira prop do layout | `@analytics` → `props.analytics` |
| `(.)pasta` | rota interceptada (modal sobre a página atual) | `(.)foto/[id]` |

Escolha uma URL e veja quais arquivos o Next empilha para renderizá-la, de fora para dentro.
::

```tsx [app/(loja)/produtos/[slug]/page.tsx]
// params e searchParams são Promises desde o Next 15 (acesso síncrono removido no 16)
export default async function ProdutoPage(props: PageProps<'/produtos/[slug]'>) {
  const { slug } = await props.params;
  const { cor } = await props.searchParams;

  const produto = await db.produto.findUnique({ where: { slug } });
  if (!produto) notFound();              // renderiza o not-found.tsx mais próximo

  return <ProdutoDetalhe produto={produto} corInicial={cor} />;
}

// Quais slugs pré-renderizar no build
export async function generateStaticParams() {
  const maisVendidos = await db.produto.findMany({ take: 50, select: { slug: true } });
  return maisVendidos.map(p => ({ slug: p.slug }));
}
```

::note{type="note" title="Na prática"}
Layouts não recebem `searchParams` e não renderizam de novo quando você navega entre páginas filhas. Se algo no layout depende da URL atual (aba ativa no menu), extraia para um :client[Client Component] com `usePathname()`. Para params de nível raiz como `[lang]`, o 16.3 trouxe `next/root-params`, que lê o valor de qualquer Server Component sem passar props.
::
