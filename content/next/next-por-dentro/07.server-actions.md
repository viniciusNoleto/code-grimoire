Uma função `async` marcada com `'use server'` pode ser chamada pelo cliente como se fosse local. Por baixo, o Next cria um endpoint POST, serializa os argumentos, executa no servidor e devolve o resultado junto com o RSC payload atualizado. Funciona até sem JavaScript quando usada em `<form action>` (progressive enhancement).

```ts [app/contato/actions.ts]
'use server';
import { z } from 'zod';
import { redirect } from 'next/navigation';
import { updateTag } from 'next/cache';

const Schema = z.object({
  email: z.string().email(),
  mensagem: z.string().min(10).max(2000),
});

export type Estado = { erro?: string; campos?: Record<string, string[]> };

export async function enviarMensagem(_anterior: Estado, formData: FormData): Promise<Estado> {
  const usuario = await getUsuarioAtual();
  if (!usuario) return { erro: 'Faça login para enviar.' };        // autorização AQUI, sempre

  const dados = Schema.safeParse(Object.fromEntries(formData));     // nunca confie no input
  if (!dados.success) return { campos: dados.error.flatten().fieldErrors };

  await db.mensagem.create({ data: { ...dados.data, autorId: usuario.id } });
  updateTag(`mensagens-${usuario.id}`);
  redirect('/contato/obrigado');
}
```

```tsx [app/contato/Formulario.tsx]
'use client';
import { useActionState } from 'react';
import { useFormStatus } from 'react-dom';
import { enviarMensagem } from './actions';

function BotaoEnviar() {
  const { pending } = useFormStatus();   // lê o estado do <form> pai
  return <button disabled={pending}>{pending ? 'Enviando…' : 'Enviar'}</button>;
}

export function Formulario() {
  const [estado, acao, pendente] = useActionState(enviarMensagem, {});
  return (
    <form action={acao}>
      <input name="email" type="email" />
      {estado.campos?.email && <p>{estado.campos.email[0]}</p>}
      <textarea name="mensagem" />
      {estado.erro && <p role="alert">{estado.erro}</p>}
      <BotaoEnviar />
    </form>
  );
}
```

### UI otimista

`useOptimistic` mostra o resultado esperado enquanto a action roda e volta ao estado real quando ela termina (ou falha). Ideal para curtidas, checkboxes e listas de mensagens.

```tsx [Curtir.tsx]
'use client';
export function Curtir({ curtidas, postId }: { curtidas: number; postId: string }) {
  const [otimista, somar] = useOptimistic(curtidas, (atual, delta: number) => atual + delta);
  return (
    <form action={async () => { somar(1); await curtirPost(postId); }}>
      <button>♥ {otimista}</button>
    </form>
  );
}
```

::note{type="pitfall" title="Segurança"}
Toda Server Action exportada é um **endpoint público**. Qualquer um pode chamá-la com qualquer argumento, mesmo que nenhum botão da sua UI permita. Valide o input e verifique autenticação e permissão **dentro** da action, não só na página que a renderiza. Use actions para mutações; para leitura, prefira Server Components.
::
