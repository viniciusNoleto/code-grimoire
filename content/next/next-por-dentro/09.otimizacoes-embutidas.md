| Recurso | O que faz | Ponto de atenção |
| --- | --- | --- |
| `next/image` | Redimensiona, converte para formatos modernos, gera `srcset` e lazy loading. Evita layout shift exigindo dimensões. | Imagens remotas exigem `images.remotePatterns`. Use `sizes` em imagens responsivas, ou o navegador baixa a maior. |
| `next/font` | Baixa a fonte no build e serve do seu domínio, sem requisição ao Google em produção, com fallback ajustado para reduzir layout shift. | Declare no layout e aplique via `className` ou variável CSS. |
| `<Link>` | Navegação suave e prefetch automático quando o link aparece na viewport. | Em listas enormes, prefetch de tudo custa caro; ajuste com `prefetch` e Partial Prefetching. |
| Metadata API | `export const metadata` ou `generateMetadata()` geram `<title>`, Open Graph e afins no servidor. | Use `cache()` para não buscar o mesmo dado na página e nos metadados. |
| `next/dynamic` | Carrega um Client Component sob demanda (`import()` com code splitting). | Use para editores, mapas e gráficos que não aparecem na primeira dobra. |

```tsx [app/layout.tsx]
import { Inter } from 'next/font/google';
import type { Metadata } from 'next';

const inter = Inter({ subsets: ['latin'], display: 'swap', variable: '--fonte' });

export const metadata: Metadata = {
  title: { template: '%s · Loja MX', default: 'Loja MX' },
  description: 'Teclados e periféricos',
};

export default function RootLayout({ children }: LayoutProps<'/'>) {
  return (
    <html lang="pt-BR" className={inter.variable}>
      <body><Providers>{children}</Providers></body>
    </html>
  );
}
```
