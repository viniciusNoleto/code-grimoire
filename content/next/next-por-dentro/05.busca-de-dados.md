Server Components buscam dados direto, sem API intermediária: `await db.query(...)` ou `await fetch(...)` no corpo do componente. As regras que importam são sobre **evitar cascatas** e **não buscar duas vezes**.

```tsx [app/pedidos/[id]/page.tsx]
// ❌ cascata: cada await espera o anterior (300 + 400 + 250 ms)
const pedido = await getPedido(id);
const cliente = await getCliente(pedido.clienteId);
const rastreio = await getRastreio(id);

// ✅ paralelo quando não há dependência
const [pedido, rastreio] = await Promise.all([getPedido(id), getRastreio(id)]);
const cliente = await getCliente(pedido.clienteId); // esta depende do pedido

// ✅ melhor ainda: cada componente busca o seu e fica atrás de um Suspense
export default async function Page(props: PageProps<'/pedidos/[id]'>) {
  const { id } = await props.params;
  return (
    <>
      <Suspense fallback={<ResumoSkeleton />}><Resumo id={id} /></Suspense>
      <Suspense fallback={<RastreioSkeleton />}><Rastreio id={id} /></Suspense>
    </>
  );
}
```

### Deduplicar com cache() do React

Quando o layout, a página e `generateMetadata` precisam do mesmo usuário, envolva a função com `cache()` do React. Ela memoiza por argumentos **durante uma única requisição**; não é cache persistente.

```ts [lib/usuario.ts]
import 'server-only';
import { cache } from 'react';
import { cookies } from 'next/headers';

export const getUsuarioAtual = cache(async () => {
  const sessao = (await cookies()).get('sessao')?.value;
  if (!sessao) return null;
  return db.usuario.findBySessao(sessao);  // roda 1x por requisição, não importa quantos chamem
});
```

### Passar uma Promise para o cliente

Um Server Component pode iniciar a busca e passar a Promise sem esperar. O Client Component a resolve com `use()`, dentro de um Suspense. A página começa a renderizar antes do dado chegar e o componente interativo recebe o dado do servidor sem um `useEffect` + fetch.

```tsx [app/painel/page.tsx + Grafico.tsx]
// page.tsx (server)
export default function Page() {
  const vendas = getVendas();          // sem await
  return <Suspense fallback={<Carregando />}><Grafico vendas={vendas} /></Suspense>;
}

// Grafico.tsx
'use client';
import { use } from 'react';
export function Grafico({ vendas }: { vendas: Promise<Venda[]> }) {
  const dados = use(vendas);           // suspende até resolver
  const [filtro, setFiltro] = useState('mes');
  /* ... interativo ... */
}
```
