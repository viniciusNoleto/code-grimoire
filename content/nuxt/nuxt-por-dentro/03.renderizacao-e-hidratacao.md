O modo padrão é a **renderização universal**. Na primeira visita, o servidor executa o app Vue, gera o HTML completo e o envia junto com o *payload* (o estado e os dados buscados, serializados). No navegador, o Vue **hidrata** esse HTML: monta os mesmos componentes, liga os eventos e reaproveita o payload em vez de buscar tudo de novo. Daí em diante, a navegação acontece no cliente como numa SPA.

### O código que roda nos dois lados

O `setup` de uma página roda **no servidor e depois no cliente**. Isso explica a maioria dos bugs de Nuxt:

- **`window`, `document` e `localStorage` não existem no servidor.** Use em `onMounted`, atrás de `if (import.meta.client)`, ou num componente `.client.vue`.
- **Valores que diferem entre servidor e cliente** (`Date.now()`, `Math.random()`, fuso horário, largura da tela) geram HTML diferente e um *hydration mismatch*. Calcule uma vez e transporte com `useState`, ou renderize no cliente (`<ClientOnly>`, `<NuxtTime>`).
- **Buscas com `$fetch` no setup rodam duas vezes**: uma no servidor e outra na hidratação. É para isso que existem `useFetch` e `useAsyncData` (capítulo [06](#busca-de-dados)).

### Modos por rota: routeRules

O `routeRules` do `nuxt.config` define, por padrão de URL, como cada rota é entregue. Assim, um mesmo app pode ter páginas estáticas, páginas em cache e páginas SSR. Isso é a **renderização híbrida**.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  routeRules: {
    '/': { prerender: true },                  // HTML gerado no build
    '/blog/**': { isr: 3600 },                 // cache na CDN, regenera em segundo plano (Vercel, Netlify)
    '/produtos/**': { swr: 600 },              // cache no servidor (Nitro), stale-while-revalidate
    '/painel/**': { ssr: false },              // SPA: o servidor manda só a casca
    '/api/**': { cors: true, headers: { 'cache-control': 's-maxage=60' } },
    '/antigo/**': { redirect: '/novo/**' },
  },
});
```

### Outros modos

- **SPA total:** `ssr: false` no `nuxt.config`. Sem HTML de servidor; útil para painéis internos sem necessidade de SEO.
- **Estático total:** `nuxt generate` pré-renderiza todas as rotas encontradas (seguindo links) para hospedagem estática.
- **Server Components / islands:** um componente `.server.vue` renderiza só no servidor e chega como HTML, sem JS no cliente (ainda experimental para componentes interativos dentro dele).
- **Streaming de SSR** :version[4.5 · exp.]: `experimental.ssrStreaming: true` envia o HTML aos poucos. Crawlers continuam recebendo a página completa. Status e headers ficam fixos no primeiro byte.
