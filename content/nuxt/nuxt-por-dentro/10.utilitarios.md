### Plugins: defineNuxtPlugin

```ts [app/plugins/api.ts]
export default defineNuxtPlugin({
  name: 'api',
  enforce: 'pre',            // ordem: 'pre' | 'default' | 'post'
  parallel: true,            // não bloqueia outros plugins enquanto carrega
  async setup(nuxtApp) {
    const config = useRuntimeConfig();
    const api = $fetch.create({
      baseURL: config.public.apiBase,
      onResponseError({ response }) {
        if (response.status === 401) nuxtApp.runWithContext(() => navigateTo('/login'));
      },
    });
    return { provide: { api } };   // useNuxtApp().$api, tipado automaticamente
  },
  hooks: {
    'page:finish': () => window.scrollTo(0, 0),
  },
});
```

Plugins rodam na criação de cada app: no servidor, **a cada requisição**. Mantenha-os leves. Sufixo `.client.ts` ou `.server.ts` restringe o lado; prefixos numéricos (`01.auth.ts`) ordenam a execução.

### callOnce

```vue [app/app.vue]
<script setup>
const site = useSiteStore();
// roda uma vez no servidor; na hidratação o cliente NÃO repete (o resultado veio no payload)
await callOnce('site-config', () => site.carregarConfig());
// { mode: 'navigation' } faz rodar de novo a cada navegação
</script>
```

### Os demais utilitários

| Utilitário | Uso |
| --- | --- |
| `navigateTo(to, opções)` | Navegar; no servidor vira redirect. Retorne-o em middleware. |
| `abortNavigation(erro?)` | Cancelar a navegação dentro de um middleware. |
| `addRouteMiddleware(nome, fn, { global })` | Registrar middleware dinamicamente (ex.: num plugin). |
| `defineRouteRules({ … })` | Regras de rota declaradas na própria página, em vez do `nuxt.config`. |
| `setPageLayout('nome')` | Trocar o layout da página atual. |
| `refreshNuxtData(chaves?)`, `clearNuxtData(chaves?)` | Refazer ou limpar dados de `useAsyncData`/`useFetch`. |
| `clearNuxtState(chaves?)` | Limpar valores de `useState`. |
| `refreshCookie('nome')` | Sincronizar um `useCookie` após mudança externa. |
| `prerenderRoutes(['/a', '/b'])` | Avisar o pré-renderizador de rotas que ele não descobriria sozinho. |
| `preloadComponents`, `prefetchComponents`, `preloadRouteComponents` | Baixar código de componentes ou rotas antes de precisar. |
| `onNuxtReady(fn)` | Rodar algo depois da hidratação, no ocioso (analytics, widgets). |
| `onBeforeRouteLeave`, `onBeforeRouteUpdate` | Guards de rota no componente (ex.: "você tem alterações não salvas"). |
| `reloadNuxtApp({ path, ttl })` | Recarregar a aplicação inteira. |
| `updateAppConfig({ … })` | Mudar o app config em tempo de execução. |
| `defineNuxtComponent` | Options API com `asyncData` e `head` no estilo Nuxt 2. |
