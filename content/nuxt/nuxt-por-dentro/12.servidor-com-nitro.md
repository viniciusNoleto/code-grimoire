Arquivos em `server/api/` viram endpoints em `/api/`; os de `server/routes/`, rotas sem prefixo. O sufixo define o método (`.get.ts`, `.post.ts`) e colchetes criam parâmetros. Cada arquivo exporta um handler h3. O tipo do retorno é inferido no `$fetch` e no `useFetch` do cliente.

```ts [server/api/produtos/[id].get.ts]
export default defineEventHandler(async (event) => {
  const id = getRouterParam(event, 'id');
  const { incluir } = getQuery(event);               // ?incluir=estoque

  const produto = await db.produto.findUnique({ where: { id } });
  if (!produto) throw createError({ statusCode: 404, statusMessage: 'Produto não encontrado' });
  return produto;                                     // serializado como JSON
});
```

```ts [server/api/pedidos.post.ts]
import { z } from 'zod';

const Pedido = z.object({ itens: z.array(z.object({ id: z.string(), qtd: z.number().int().positive() })) });

export default defineEventHandler(async (event) => {
  const usuario = await exigirUsuario(event);                     // server/utils: auto-importado
  const corpo = await readValidatedBody(event, Pedido.parse);      // 400 automático se inválido
  setResponseStatus(event, 201);
  return criarPedido(usuario.id, corpo.itens);
});
```

### Cache e armazenamento

```ts [server/api/cotacao.get.ts]
// Resposta cacheada no servidor por 5 min, com stale-while-revalidate
export default defineCachedEventHandler(async (event) => {
  return await $fetch('https://api.externa.com/cotacao');
}, { maxAge: 300, swr: true, getKey: (event) => getQuery(event).moeda as string });

// Cachear uma função, não a rota inteira
export const getCambio = defineCachedFunction(async (moeda: string) => buscarCambio(moeda), {
  maxAge: 60, name: 'cambio', getKey: (moeda) => moeda,
});

// Armazenamento chave-valor (memória, fs, Redis, KV…) configurado em nitro.storage
await useStorage('cache').setItem('ultimo-sync', Date.now());
```

- **`server/middleware/`** roda em toda requisição (antes das rotas): logs, headers, anexar o usuário a `event.context`. Não retorne nada, a menos que queira encerrar a resposta.
- **`server/plugins/`** roda uma vez na inicialização do Nitro (conectar a filas, registrar hooks como `render:html`).
- **Cookies e headers**: `getCookie`, `setCookie`, `deleteCookie`, `getHeader`, `setHeader`, `sendRedirect`.
- **4.6:** a camada de servidor (`nuxt/server`) passou a funcionar também fora do Nitro.

::note{type="note" title="Na prática"}
Em `routeRules`, regras de cache agora só cacheiam GET e HEAD (4.6.4), e regras de rota do servidor não diferenciam maiúsculas de minúsculas (4.6.2).
::
