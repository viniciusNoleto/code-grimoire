Num app Vue puro, um store global é só um objeto na memória do navegador. No Nuxt, o mesmo código roda num servidor que atende muitos usuários ao mesmo tempo, e o estado do servidor precisa chegar ao cliente. Isso impõe três regras:

1. **Estado por requisição.** Cada requisição precisa de seu próprio store. `useState` e o Pinia via `@pinia/nuxt` criam uma instância por app (por requisição); variáveis de módulo não.
2. **Transferência pelo payload.** O estado final do servidor é serializado no HTML e o cliente começa a partir dele. Por isso tudo precisa ser serializável.
3. **Inicialização única.** Carregar dados no store no setup sem cuidado roda duas vezes (servidor e hidratação). Use `callOnce` ou `useAsyncData` com retorno.

```ts [app/stores/carrinho.ts]
export const useCarrinhoStore = defineStore('carrinho', () => {
  const itens = ref<Item[]>([]);
  const total = computed(() => itens.value.reduce((s, i) => s + i.preco * i.qtd, 0));

  async function carregar() {
    itens.value = await $fetch('/api/carrinho');   // $fetch: será chamado via callOnce ou useAsyncData
  }
  async function adicionar(id: string) {
    itens.value = await $fetch('/api/carrinho', { method: 'POST', body: { id } });
  }
  return { itens, total, carregar, adicionar };
});
```

```vue [app/layouts/loja.vue]
<script setup>
const carrinho = useCarrinhoStore();

// Opção 1: callOnce — roda no servidor, o estado do Pinia vai no payload
await callOnce('carrinho', () => carrinho.carregar());

// Opção 2: useAsyncData — também dá status, erro e refresh
// const { status } = await useAsyncData('carrinho', () => carrinho.carregar().then(() => true));
</script>
```

|  | useState | Pinia | provide / inject |
| --- | --- | --- | --- |
| Escopo | app inteiro, por chave | app inteiro, por store | subárvore de componentes |
| SSR + payload | sim | sim (com `@pinia/nuxt`) | não transfere sozinho |
| Lógica (actions, getters) | você escreve no composable | estruturada, com DevTools | no provider |
| Bom para | valores simples (tema, locale) | domínio do app (carrinho, sessão) | componentes compostos (formulário, tabela) |
