| Componente | O que faz |
| --- | --- |
| `<NuxtPage>` | Saída da rota atual (equivale ao `<RouterView>`). Aceita `:keepalive`, `:transition`, `name` para named views. |
| `<NuxtLayout>` | Renderiza o layout da página; `name` força um específico. |
| `<NuxtLink>` | Link interno com prefetch (`prefetch-on="interaction"` ou `visibility`), externo com `target` e `rel` seguros. Desde a 4.5, o slot `custom` expõe `prefetch` e `prefetched`. |
| `<ClientOnly>` | Renderiza o conteúdo só no cliente; slot `#fallback` vai no HTML do servidor. |
| `<DevOnly>` | Some do build de produção. |
| `<NuxtClientFallback>` | Se o SSR do conteúdo falhar, renderiza no cliente em vez de derrubar a página. |
| `<NuxtErrorBoundary>` | Captura erros de cliente de uma parte da página; slot `#error="{ error, clearError }"`. |
| `<NuxtLoadingIndicator>` | Barra de progresso entre navegações. |
| `<NuxtRouteAnnouncer>` | Região `aria-live` que anuncia o título da nova página. |
| `<NuxtTime>` | Formata datas sem hydration mismatch (inclusive relativas: "há 3 minutos"). |
| `<NuxtIsland>` | Renderiza um componente de servidor como ilha de HTML. |
| `<NuxtImg>`, `<NuxtPicture>` | Imagens otimizadas (módulo `@nuxt/image`). |
| `<NuxtWelcome>` | Página inicial de projeto novo. |

### Componentes Lazy e hidratação preguiçosa

O prefixo `Lazy` carrega o código do componente só quando ele é renderizado. Os atributos `hydrate-*` vão além: o componente renderiza no servidor (o HTML aparece) mas só **hidrata**, baixando e executando seu JS, quando a condição acontecer.

```vue [app/pages/produto.vue]
<template>
  <LazyComentarios v-if="mostrarComentarios" />          <!-- só baixa quando aparecer -->

  <LazyRecomendacoes hydrate-on-visible />                <!-- hidrata ao entrar na viewport -->
  <LazyChatSuporte hydrate-on-interaction="mouseover" />   <!-- hidrata no primeiro hover -->
  <LazyRodape hydrate-on-idle />                          <!-- quando o navegador ficar ocioso -->
  <LazyMenuMobile hydrate-on-media-query="(max-width: 768px)" />
  <LazyBanner :hydrate-after="3000" />
  <LazyAvisoLegal hydrate-never />                        <!-- HTML estático, nunca hidrata -->
</template>
```

Para os mesmos recursos fora da convenção de prefixo, existe `defineLazyHydrationComponent`.
