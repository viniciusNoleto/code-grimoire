Módulos estendem o build: adicionam componentes, composables, rotas de servidor e configuração. Instale com `npx nuxt module add nome`.

| Módulo | Para quê |
| --- | --- |
| `@pinia/nuxt` | Pinia com SSR, auto-import de `defineStore`. |
| `@nuxt/image` | `<NuxtImg>` e `<NuxtPicture>` com provedores (Cloudinary, Vercel, IPX local). |
| `@nuxt/content` | Conteúdo em Markdown/YAML consultável como banco. |
| `@nuxt/ui` | Biblioteca de componentes oficial. |
| `@nuxtjs/i18n` | Rotas e textos por idioma. |
| `@nuxt/eslint`, `@nuxt/test-utils` | Lint ciente do projeto; testes com ambiente Nuxt (Vitest). |
| `@vueuse/nuxt` | VueUse com auto-import (`useEventSource`, `useWebWorker`…). |
| `nuxt-auth-utils` | Sessões em cookie selado e login OAuth. |

```ts [modules/aviso.ts]
// Um módulo local mínimo (modules/ é carregado automaticamente)
import { defineNuxtModule, addComponent, createResolver } from '@nuxt/kit';

export default defineNuxtModule({
  meta: { name: 'aviso', configKey: 'aviso' },
  defaults: { texto: 'Ambiente de teste' },
  setup(opcoes, nuxt) {
    const { resolve } = createResolver(import.meta.url);
    nuxt.options.runtimeConfig.public.aviso = opcoes.texto;
    addComponent({ name: 'FaixaAviso', filePath: resolve('./runtime/FaixaAviso.vue') });
  },
});
```
