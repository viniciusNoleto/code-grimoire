No Nuxt 4, o código da aplicação Vue fica em `app/`, separado do servidor (`server/`) e do código compartilhado entre os dois (`shared/`). Cada pasta tem um papel que o Nuxt reconhece pelo nome.

| Caminho | Roda em | Papel |
| --- | --- | --- |
| `app/app.vue` | ambos | Componente raiz. Com `pages/`, normalmente só tem `<NuxtLayout><NuxtPage /></NuxtLayout>`. |
| `app/pages/` | ambos | Cada arquivo vira uma rota. |
| `app/layouts/` | ambos | Moldes de página (`default.vue`, `painel.vue`). |
| `app/components/` | ambos | Auto-importados. Sufixos `.client.vue` e `.server.vue` mudam onde renderizam. |
| `app/composables/`, `app/utils/` | ambos | Auto-importados (só o primeiro nível, ou `index.ts` de subpastas). |
| `app/middleware/` | ambos | Middleware de rota (roda antes de navegar). |
| `app/plugins/` | ambos | Rodam na criação do app. `.client.ts` / `.server.ts` restringem o lado. |
| `app/error.vue` | ambos | Página de erro fatal. |
| `server/api/`, `server/routes/` | :server[servidor] | Endpoints do Nitro (`/api/*` e rotas sem prefixo). |
| `server/middleware/`, `server/plugins/`, `server/utils/` | :server[servidor] | Middleware HTTP, plugins do Nitro, utilitários auto-importados no servidor. |
| `shared/` | ambos | Tipos e funções usados pelo app e pelo servidor (auto-importados de `shared/utils` e `shared/types`). |
| `public/` | :client[estático] | Arquivos servidos como estão (`/favicon.ico`). |
| `nuxt.config.ts`, `app/app.config.ts` | build / ambos | Configuração do framework; configuração pública reativa. |

### Auto-imports

Funções do Vue (`ref`, `computed`), do Nuxt (`useFetch`, `navigateTo`), seus composables e seus componentes ficam disponíveis sem `import`. O Nuxt gera as declarações em `.nuxt/`, então o TypeScript enxerga tudo. Se preferir explícito, tudo pode ser importado de `#imports` e componentes de `#components`.

```text [nomes de componentes]
app/components/base/Botao.vue        → <BaseBotao />
app/components/produto/Cartao.vue    → <ProdutoCartao />
app/components/Mapa.client.vue       → <Mapa />        (só renderiza no cliente)
app/components/Grafico.vue           → <LazyGrafico /> (prefixo Lazy: code splitting)
```
