E-mails são enviados por **Mailables**. **Notificações** são uma camada acima: uma mensagem que pode sair por vários canais (e-mail, banco, SMS, Slack, broadcast) conforme a preferência do destinatário.

### Mailables

```bash
php artisan make:mail PedidoConfirmado --markdown=emails.pedido-confirmado
```

```php [app/Mail/PedidoConfirmado.php]
class PedidoConfirmado extends Mailable implements ShouldQueue     // ShouldQueue: sempre vai pela fila
{
    use Queueable, SerializesModels;

    public function __construct(public Pedido $pedido) {}

    public function envelope(): Envelope
    {
        return new Envelope(subject: "Pedido {$this->pedido->numero} confirmado");
    }

    public function content(): Content
    {
        return new Content(markdown: 'emails.pedido-confirmado');  // $pedido fica disponível na view
    }

    public function attachments(): array
    {
        return [Attachment::fromStorageDisk('s3', $this->pedido->recibo_path)->as('recibo.pdf')];
    }
}
```

```php [app/Http/Controllers/PedidoController.php]
Mail::to($pedido->user)->cc('financeiro@loja.test')->send(new PedidoConfirmado($pedido));
Mail::to($user)->queue(new PedidoConfirmado($pedido));
Mail::to($user)->later(now()->addMinutes(10), new PedidoConfirmado($pedido));
```

Para ver o e-mail no navegador durante o desenvolvimento: `Route::get('/preview', fn () => new PedidoConfirmado(Pedido::first()));`. Use `MAIL_MAILER=log` ou o Mailpit (vem no Sail e no Herd) para não enviar e-mails reais.

### Notificações

```bash
php artisan make:notification PedidoEnviado
```

```php [app/Notifications/PedidoEnviado.php]
class PedidoEnviado extends Notification implements ShouldQueue
{
    use Queueable;

    public function __construct(public Pedido $pedido) {}

    public function via(object $notifiable): array                // canais
    {
        return $notifiable->prefere_whatsapp ? ['database', WhatsAppChannel::class] : ['mail', 'database'];
    }

    public function toMail(object $notifiable): MailMessage
    {
        return (new MailMessage)
            ->subject('Seu pedido saiu para entrega')
            ->greeting("Olá, {$notifiable->nome}!")
            ->line("O pedido {$this->pedido->numero} foi enviado.")
            ->action('Rastrear', route('pedidos.show', $this->pedido));
    }

    public function toArray(object $notifiable): array            // canal database
    {
        return ['pedido_id' => $this->pedido->id, 'mensagem' => 'Pedido enviado'];
    }
}
```

```php [app/Http/Controllers/PedidoController.php]
$user->notify(new PedidoEnviado($pedido));                     // Model com a trait Notifiable
Notification::send($clientes, new PromocaoRelampago);          // vários destinatários
Notification::route('mail', 'compras@empresa.test')->notify(new NovoPedido($pedido));  // sem Model
```

php artisan make:notifications-table && php artisan migrate
```

$user->notifications;                     // todas, mais recentes primeiro
$user->unreadNotifications;
$user->unreadNotifications->markAsRead();
$notificacao->data['mensagem'];
```
