Um pleno avançado conhece as ferramentas oficiais e sabe quando cada uma resolve o problema em vez de reinventá-lo.

### Pacotes oficiais

| Pacote | Para quê |
| --- | --- |
| Sanctum | Autenticação de SPA e tokens de API |
| Passport | Servidor OAuth2 completo |
| Fortify | Backend de autenticação sem interface |
| Socialite | Login com Google, GitHub, Facebook… |
| Horizon | Painel e gerência de filas no Redis |
| Telescope | Inspeção em desenvolvimento |
| Pulse | Métricas de produção |
| Octane | Servidor de alta performance com app em memória |
| Reverb | Servidor WebSocket |
| Echo | Cliente JS de broadcasting |
| Scout | Busca full-text com Meilisearch, Typesense, Algolia ou banco |
| Cashier | Assinaturas e cobranças (Stripe, Paddle) |
| Pennant | Feature flags |
| Pint | Formatação de código |
| Sail | Ambiente Docker de desenvolvimento |
| Prompts | Interfaces de linha de comando |
| Precognition | Validação antecipada no frontend usando as regras do backend |
| Folio e Volt | Rotas por arquivo e componentes Livewire de arquivo único |
| Boost | Contexto e ferramentas (MCP) para assistentes de IA trabalharem no projeto |
| AI SDK (*Laravel 13*) | API única para geração de texto, agentes, embeddings, imagens e áudio |

### Ferramentas e serviços

| Nome | Tipo |
| --- | --- |
| Herd | Ambiente local nativo (macOS, Windows) |
| Forge, Vapor, Envoyer, Laravel Cloud | Infraestrutura e deploy |
| Nightwatch | Monitoramento |
| Livewire, Inertia | Frontend integrado ao Laravel |
