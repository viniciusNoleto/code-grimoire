Além do Eloquent, a fachada `DB` dá acesso direto às conexões, ao Query Builder sem Models e às transações.

### Conexões

```php
// config/database.php: uma entrada por conexão; DB_CONNECTION define a padrão
DB::connection('relatorios')->table('vendas')->sum('valor');

// réplica de leitura: SELECTs vão para read, o resto para write
'pgsql' => [
    'read'  => ['host' => ['10.0.0.2', '10.0.0.3']],
    'write' => ['host' => ['10.0.0.1']],
    'sticky' => true,   // depois de escrever, lê do write na mesma requisição
    // ...
],
```

### SQL cru

```php
$linhas = DB::select('select * from pedidos where status = ? and total > ?', ['pago', 100]);
$linhas = DB::select('select * from pedidos where status = :status', ['status' => 'pago']);
$um     = DB::selectOne('select count(*) as total from pedidos');
$valor  = DB::scalar('select max(total) from pedidos');

DB::insert('insert into logs (acao) values (?)', ['login']);
$afetadas = DB::update('update pedidos set status = ? where id = ?', ['pago', 10]);
DB::delete('delete from sessoes where last_activity < ?', [$limite]);
DB::statement('refresh materialized view vendas_mensais');
```

`DB::select` devolve um array de objetos `stdClass`, sem casts, eventos ou relacionamentos.

### Query Builder sem Model

```php
DB::table('pedidos')
    ->join('clientes', 'clientes.id', '=', 'pedidos.cliente_id')
    ->where('pedidos.status', 'pago')
    ->select('clientes.nome', DB::raw('sum(pedidos.total) as gasto'))
    ->groupBy('clientes.nome')
    ->orderByDesc('gasto')
    ->get();      // Collection de stdClass
```

Todos os métodos das [seções 18](#filtros-where) a 20 funcionam aqui. Use `DB::table` para relatórios, tabelas sem Model e operações em massa onde eventos não importam.

### Transações

```php
$pedido = DB::transaction(function () use ($dados) {
    $pedido = Pedido::create($dados);
    $pedido->itens()->createMany($dados['itens']);
    Estoque::baixar($dados['itens']);           // se lançar exceção, tudo é desfeito
    return $pedido;
}, attempts: 3);                                // tenta de novo em caso de deadlock

// controle manual
DB::beginTransaction();
try {
    // ...
    DB::commit();
} catch (Throwable $e) {
    DB::rollBack();
    throw $e;
}

DB::afterCommit(fn () => Cache::forget('vendas'));   // roda só se a transação confirmar
```

::note{type="pitfall" title="Atenção"}
E-mails, jobs e chamadas externas disparados dentro de uma transação podem acontecer mesmo que ela seja desfeita depois. Use `afterCommit()` nos jobs ([seção 39.8](#filas-e-jobs-filas-e-transações)) e `DB::afterCommit()` para o resto.
::

### Seeders

```bash
php artisan make:seeder ProdutoSeeder
php artisan db:seed                       # roda DatabaseSeeder
php artisan db:seed --class=ProdutoSeeder
php artisan migrate:fresh --seed
```

```php
class DatabaseSeeder extends Seeder
{
    use WithoutModelEvents;              // não dispara observers durante o seed

    public function run(): void
    {
        $this->call([CategoriaSeeder::class, ProdutoSeeder::class]);
        User::factory()->create(['email' => 'admin@loja.test']);
        Pedido::factory()->count(50)->create();
    }
}
```

Seeders de dados obrigatórios (papéis, configurações) devem ser idempotentes: use `updateOrCreate` ou `upsert` para poder rodar de novo sem duplicar.

### Redis

```php
use Illuminate\Support\Facades\Redis;

Redis::set('visitas', 0);
Redis::incr('visitas');
Redis::expire('visitas', 3600);
Redis::connection('cache')->get('chave');

Redis::pipeline(function ($pipe) {               // várias operações em uma ida ao servidor
    foreach (range(1, 1000) as $i) $pipe->set("k:$i", $i);
});
```

Na prática, o Redis aparece no Laravel por baixo de cache ([seção 44](#cache-e-locks)), filas e Horizon ([seção 39](#filas-e-jobs)), sessões, locks e rate limiting.

### Monitorar e inspecionar

```php
DB::listen(fn (QueryExecuted $q) => Log::debug($q->toRawSql(), ['ms' => $q->time]));

DB::whenQueryingForLongerThan(500, function (Connection $conexao, QueryExecuted $evento) {
    Log::warning('Requisição passou de 500ms em queries');    // tempo acumulado na requisição
});
```

```bash
php artisan db:show          # visão geral: tamanho, tabelas, conexões
php artisan db:table pedidos # colunas, índices e FKs de uma tabela
php artisan db               # abre o cliente do banco (psql)
```

### Busca vetorial

:version[Laravel 13+] Com PostgreSQL e a extensão `pgvector`, o Query Builder busca por similaridade de embeddings, base para busca semântica e IA:

```php
$documentos = DB::table('documentos')
    ->whereVectorSimilarTo('embedding', 'Melhores vinícolas do Vale dos Vinhedos')
    ->limit(10)
    ->get();
```
