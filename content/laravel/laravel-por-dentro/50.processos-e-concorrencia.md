Ferramentas recentes do framework para executar processos externos, paralelizar trabalho e propagar informações entre requisição, logs e jobs.

### Processos externos

```php [app/Console/Commands/GerarMiniaturas.php]
use Illuminate\Support\Facades\Process;

$resultado = Process::path(storage_path('app'))
    ->timeout(120)
    ->env(['PGPASSWORD' => config('database.connections.pgsql.password')])
    ->run('pg_dump -U loja loja > backup.sql');

$resultado->successful();  $resultado->output();  $resultado->errorOutput();  $resultado->exitCode();
$resultado->throw();                      // ProcessFailedException se falhou

$processo = Process::start('php artisan importar');   // assíncrono
while ($processo->running()) { /* ... */ }
$processo->wait();

Process::fake(['pg_dump *' => Process::result('ok')]);  // testes
Process::assertRan('pg_dump -U loja loja > backup.sql');
```

::note{type="pitfall" title="Cuidado"}
Nunca concatene entrada do usuário no comando. Passe argumentos como array (`Process::run(['convert', $arquivo, 'saida.png'])`), que são escapados.
::

### Concorrência

:version[Laravel 11+] Executa closures em paralelo (em processos PHP separados) e devolve os resultados:

```php [app/Http/Controllers/PainelController.php]
use Illuminate\Support\Facades\Concurrency;

[$totalPedidos, $totalClientes, $faturamento] = Concurrency::run([
    fn () => Pedido::count(),
    fn () => Cliente::count(),
    fn () => Pedido::whereMonth('created_at', now()->month)->sum('total'),
]);

Concurrency::defer([fn () => Metricas::registrar(...)]);   // paralelo, depois da resposta
```

Drivers: `process` (padrão), `fork` (mais rápido, só na linha de comando, exige `spatie/fork`) e `sync` (sequencial, para testes).

### `defer()`

:version[Laravel 11+] Executa uma closure depois que a resposta HTTP foi enviada (ou após o término de um comando ou job), no mesmo processo:

```php [app/Http/Controllers/CheckoutController.php]
defer(fn () => Analytics::registrar('checkout', $pedido->id));
defer(fn () => ...)->always();   // roda mesmo se a resposta for de erro
```

Use para tarefas rápidas e não críticas. Se a tarefa precisa sobreviver a uma falha ou ser repetida, use uma fila.

### Context

:version[Laravel 11+] `Context` guarda informações da execução atual que são anexadas automaticamente a todos os logs e **propagadas para os jobs** despachados dela:

```php [app/Http/Middleware/AdicionarContexto.php]
class AdicionarContexto
{
    public function handle(Request $request, Closure $next): Response
    {
        Context::add('request_id', (string) Str::uuid());
        Context::add('loja_id', $request->user()?->loja_id);
        Context::addHidden('token_parceiro', $token);     // propaga, mas não aparece nos logs

        return $next($request);
    }
}
```

```php [app/Actions/CriarPedido.php]
Log::info('Pedido criado');                       // o log inclui request_id e loja_id
ProcessarNotaFiscal::dispatch($pedido);           // o job enxerga os mesmos valores

Context::get('request_id');
```

Isso permite seguir uma operação de ponta a ponta: a requisição, os jobs que ela gerou e os logs de todos eles compartilham o mesmo `request_id`.

### Qual ferramenta usar

| Situação | Ferramenta |
| --- | --- |
| Trabalho lento, que pode falhar ou precisa de novas tentativas | Fila ([seção 39](#filas-e-jobs)) |
| Trabalho rápido que não deve atrasar a resposta | `defer()` |
| Várias consultas/chamadas independentes que somam tempo | `Concurrency::run` ou `Http::pool` |
| Impedir duas execuções simultâneas do mesmo trecho | Lock ([seção 44.5](#cache-e-locks-locks-atômicos)) |
| Limitar quantas vezes algo acontece por período | `RateLimiter` ([seção 38.5](#seguranca-da-aplicacao-rate-limiting-e-força-bruta)) |
| Rastrear uma operação nos logs e jobs | `Context` |
