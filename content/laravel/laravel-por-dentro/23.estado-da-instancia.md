Cada Model guarda duas versões dos atributos: a atual e a original (como veio do banco). Os métodos abaixo comparam essas versões e controlam o ciclo de vida do objeto.

### Ler e definir atributos

```php [app/Http/Controllers/UserController.php]
$user->nome;                       // leitura (passa por accessor e cast)
$user->nome = 'Ana';               // escrita (passa por mutator e cast)
$user->getAttribute('nome');       // equivalente explícito
$user->setAttribute('nome', 'Ana');
$user->getAttributes();            // array cru, como irá ao banco
$user->getRawOriginal('nome');     // valor original sem casts
isset($user->nome);                // atributo definido e não nulo
unset($user->nome);                // remove do objeto (não do banco)
$user->only(['nome', 'email']);    // array só com estes atributos
```

Também funciona como array: `$user['nome']`.

### Antes de salvar: `isDirty`, `isClean`, `getDirty`

```php [vendor/laravel/framework/src/Illuminate/Database/Eloquent/Concerns/HasAttributes.php]
$model->isDirty(array|string|null $attributes = null): bool
```

- Sem argumento: houve qualquer alteração desde que foi carregado/salvo?
- Com nome(s): algum desses mudou?

```php [app/Http/Controllers/UserController.php]
$user = User::find(1);   // nome = 'Ana'
$user->nome = 'Bia';
$user->isDirty();            // true
$user->isDirty('nome');      // true
$user->isDirty('email');     // false
$user->isClean('email');     // true (oposto de isDirty)
$user->getDirty();           // ['nome' => 'Bia']
$user->getOriginal('nome');  // 'Ana'
$user->getOriginal();        // array com todos os originais
```

`isDirty` é muito usado em eventos (`updating`) para reagir só quando um campo específico muda.

### Depois de salvar: `wasChanged`, `getChanges`, `getPrevious`

Após o `save()`, a versão atual vira a "original" e `isDirty()` volta a ser `false`. Para saber o que mudou **no último save**:

```php [app/Http/Controllers/UserController.php]
$user->nome = 'Bia';
$user->save();

$user->isDirty('nome');      // false
$user->wasChanged('nome');   // true
$user->getChanges();         // ['nome' => 'Bia', 'updated_at' => ...]
$user->getPrevious();        // valores anteriores ao último save (Laravel 10+)
```

### `exists` e `wasRecentlyCreated`

- `$model->exists`: `true` se o registro está no banco (carregado ou já salvo).
- `$model->wasRecentlyCreated`: `true` se foi inserido nesta requisição.

```php [app/Http/Controllers/UserController.php]
$user = User::firstOrCreate(['email' => $e]);
if ($user->wasRecentlyCreated) {
    Mail::to($user)->send(new BoasVindas);
}
```

### Recarregar: `fresh()` e `refresh()`

| Método | O que faz |
| --- | --- |
| `fresh(array\|string $with = [])` | Busca o registro de novo e devolve uma **nova** instância. A original não muda. `$with` carrega relacionamentos. Devolve `null` se o registro foi apagado |
| `refresh()` | Recarrega **a própria** instância, incluindo os relacionamentos já carregados |

```php [app/Http/Controllers/PedidoController.php]
$novo = $pedido->fresh();
-- SQL: select * from "pedidos" where "pedidos"."id" = ? limit 1

$novo = $pedido->fresh(['itens']);
-- SQL: a mesma, mais uma para o relacionamento:
--      select * from "itens" where "itens"."pedido_id" in (10)

$pedido->refresh();
-- SQL: select * from "pedidos" where "pedidos"."id" = ? limit 1
--      (+ uma query por relacionamento já carregado)

$pedido->refreshForUpdate();   // Laravel 13+
-- SQL: select * from "pedidos" where "pedidos"."id" = ? limit 1 for update
```

Use após updates feitos por query ou por outro processo, quando o objeto em memória ficou desatualizado.

:version[Laravel 13+] `refreshForUpdate()` recarrega o Model com `SELECT ... FOR UPDATE`, travando a linha. Use dentro de `DB::transaction()` antes de alterar um registro disputado por várias requisições.

### Copiar: `replicate()`

```php [vendor/laravel/framework/src/Illuminate/Database/Eloquent/Model.php]
$model->replicate(?array $except = null): static
```

Cria uma nova instância **não salva** com os mesmos atributos, sem a chave primária e os timestamps. `$except` lista colunas a não copiar.

```php [app/Http/Controllers/PedidoController.php]
$copia = $pedido->replicate(['numero', 'status'])->fill([   // sem SQL: copia em memória
    'status' => 'rascunho',
]);
$copia->save();
-- SQL: insert into "pedidos" ("cliente_id", "total", "status", "updated_at", "created_at")
--      values (?, ?, ?, ?, ?) returning "id"
```

Relacionamentos não são copiados. `replicateQuietly()` faz o mesmo sem disparar o evento `replicating`.

### Comparar: `is()` e `isNot()`

```php [vendor/laravel/framework/src/Illuminate/Database/Eloquent/Model.php]
$model->is(?Model $other): bool
```

Verdadeiro se os dois têm a mesma chave primária, tabela e conexão. Não compara atributos.

```php [app/Policies/PostPolicy.php]
if ($post->autor->is(auth()->user())) { /* é o dono */ }
$post->autor()->is($user);    // também funciona em belongsTo/hasOne/morphTo, sem consultar
```

### Chaves e metadados

| Método | Retorna |
| --- | --- |
| `getKey()` | Valor da chave primária |
| `getKeyName()` | Nome da chave primária |
| `getTable()` | Nome da tabela |
| `getConnectionName()` | Nome da conexão |
| `getForeignKey()` | Nome padrão da FK para este Model (`user_id`) |
| `getMorphClass()` | Nome usado em relações polimórficas |
| `getRouteKey()` / `getRouteKeyName()` | Valor/nome usado nas rotas |
| `qualifyColumn('nome')` | `'users.nome'` |
| `getFillable()` / `getHidden()` / `getCasts()` | Configurações atuais |
| `relationLoaded('posts')` | Se o relacionamento já foi carregado |
| `getRelations()` / `getRelation('posts')` | Relacionamentos carregados |
| `setRelation('posts', $colecao)` / `unsetRelation('posts')` | Define ou remove um relacionamento em memória |
