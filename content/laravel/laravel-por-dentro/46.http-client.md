A facade `Http` é um cliente para APIs externas, construído sobre o Guzzle, com API fluente, novas tentativas e fakes para testes.

### Requisições e respostas

```php [app/Services/CepService.php]
$resposta = Http::get('https://viacep.com.br/ws/69005010/json/');
$resposta = Http::post('https://api.exemplo.com/pedidos', ['numero' => 'A1', 'total' => 100]);  // JSON por padrão
Http::put($url, $dados);  Http::patch($url, $dados);  Http::delete($url);

$resposta->json();                 // array
$resposta->json('endereco.cidade'); // com notação de ponto
$resposta->collect('itens');        // Collection
$resposta->body();  $resposta->status();  $resposta->header('X-Total');
$resposta->successful();            // 2xx
$resposta->failed();                // 4xx ou 5xx
$resposta->clientError();  $resposta->serverError();
$resposta->throw();                 // lança RequestException se 4xx/5xx; senão devolve a resposta
```

::note{type="pitfall" title="Atenção"}
Por padrão, um 404 ou 500 **não** lança exceção. Use `->throw()` ou cheque `successful()`.
::

### Opções

```php [app/Services/GatewayService.php]
Http::withToken($token)                          // Authorization: Bearer
    ->withHeaders(['X-Loja' => 10])
    ->acceptJson()
    ->baseUrl('https://api.gateway.com/v2')
    ->timeout(10)                                // segundos para a resposta
    ->connectTimeout(3)
    ->retry(3, 200, fn (Exception $e) => $e instanceof ConnectionException)  // 3 tentativas, 200ms entre elas
    ->withQueryParameters(['pagina' => 2])
    ->post('/cobrancas', $dados)
    ->throw();

Http::asForm()->post($url, $dados);                         // application/x-www-form-urlencoded
Http::attach('arquivo', $conteudo, 'nota.xml')->post($url); // multipart
Http::withBasicAuth('usuario', 'senha')->get($url);
```

### Cliente por serviço

```php [app/Providers/AppServiceProvider.php]
class AppServiceProvider extends ServiceProvider
{
    public function boot(): void
    {
        Http::macro('gateway', fn () => Http::withToken(config('services.gateway.token'))
            ->baseUrl(config('services.gateway.url'))
            ->timeout(10)
            ->retry(2, 500));
    }
}
```

```php [app/Services/CobrancaService.php]
Http::gateway()->post('/cobrancas', $dados);
```

Para integrações maiores, uma classe dedicada (`GatewayClient`) que encapsula as chamadas e devolve objetos do seu domínio é mais fácil de testar e manter.

### Requisições em paralelo

```php [app/Services/CotacaoService.php]
$respostas = Http::pool(fn (Pool $pool) => [
    $pool->as('usd')->get('https://api.cotacao/usd'),
    $pool->as('eur')->get('https://api.cotacao/eur'),
]);

$respostas['usd']->json('valor');
```

### Testes

```php [tests/Feature/CotacaoTest.php]
Http::preventStrayRequests();                     // erro se alguma URL não tiver fake
Http::fake([
    'viacep.com.br/*'      => Http::response(['localidade' => 'Manaus'], 200),
    'api.gateway.com/*'    => Http::sequence()->push(['status' => 'pendente'])->push(['status' => 'pago']),
    '*'                    => Http::response('Erro', 500),
]);

// ... executa o código ...

Http::assertSent(fn (Request $r) => $r->url() === 'https://api.gateway.com/v2/cobrancas' && $r['total'] === 100);
Http::assertSentCount(2);
```
