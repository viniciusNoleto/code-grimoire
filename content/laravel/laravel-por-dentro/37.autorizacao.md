Autorização responde "você pode fazer isso?". O Laravel oferece **Gates** (regras soltas, em closures) e **Policies** (regras agrupadas por Model).

### Gates

```php [app/Providers/AppServiceProvider.php]
class AppServiceProvider extends ServiceProvider
{
    public function boot(): void
    {
        Gate::define('ver-relatorios', fn (User $user) => $user->is_admin);

        Gate::define('editar-pedido', function (User $user, Pedido $pedido) {
            return $user->id === $pedido->user_id
                ? Response::allow()
                : Response::deny('Este pedido não é seu.');      // mensagem no 403
        });

        Gate::before(fn (User $user, string $habilidade) => $user->is_super ? true : null);  // null = segue para a regra
    }
}
```

```php [app/Http/Controllers/RelatorioController.php]
Gate::allows('ver-relatorios');            // bool
Gate::denies('editar-pedido', $pedido);
Gate::authorize('editar-pedido', $pedido); // lança AuthorizationException → 403
Gate::forUser($outro)->allows(...);
```

### Policies

```bash
php artisan make:policy PedidoPolicy --model=Pedido
```

```php [app/Policies/PedidoPolicy.php]
class PedidoPolicy
{
    public function before(User $user, string $habilidade): ?bool
    {
        return $user->is_admin ? true : null;           // admin pode tudo
    }

    public function viewAny(User $user): bool { return true; }

    public function view(User $user, Pedido $pedido): bool
    {
        return $user->id === $pedido->user_id;
    }

    public function create(User $user): bool
    {
        return $user->hasVerifiedEmail();
    }

    public function update(User $user, Pedido $pedido): Response
    {
        if ($pedido->pago) return Response::deny('Pedidos pagos não podem ser alterados.');
        return $user->id === $pedido->user_id ? Response::allow() : Response::denyAsNotFound();  // 404 em vez de 403
    }

    public function delete(User $user, Pedido $pedido): bool { return $this->update($user, $pedido)->allowed(); }

    public function cancelar(?User $user, Pedido $pedido): bool   // ?User: permite visitantes
    {
        return $user?->id === $pedido->user_id && ! $pedido->enviado;
    }
}
```

A policy é encontrada pela convenção de nome (`App\Models\Pedido` → `App\Policies\PedidoPolicy`). Fora do padrão: `Gate::policy(Pedido::class, OutraPolicy::class)`.

### Onde verificar

No controller:

```php [app/Http/Controllers/PedidoController.php]
Gate::authorize('update', $pedido);
```

No usuário:

```php [app/Http/Controllers/PedidoController.php]
$request->user()->can('update', $pedido);
$request->user()->cannot('delete', $pedido);
$request->user()->can('create', Pedido::class);          // ações sem instância: passe a classe
```

Na rota:

```php [routes/web.php]
Route::put('/pedidos/{pedido}', ...)->can('update', 'pedido');
Route::post('/pedidos', ...)->middleware('can:create,App\Models\Pedido');
```

No Form Request:

```php [app/Http/Requests/UpdatePedidoRequest.php]
class UpdatePedidoRequest extends FormRequest
{
    public function authorize(): bool
    {
        return $this->user()->can('update', $this->route('pedido'));
    }
}
```

```html
@can('update', $pedido) <a href="...">Editar</a> @endcan
@cannot('delete', $pedido) ... @endcannot
```

:version[Laravel 13+] Também pelo atributo `#[Authorize('update', 'pedido')]` no método do controller ([seção 8.3](#controllers-middleware-no-controller)).

### Autorização em listas

Policies decidem sobre **um** registro. Para listar só o que o usuário pode ver, filtre na query; não carregue tudo para checar um por um:

```php [app/Http/Controllers/PedidoController.php]
class PedidoController extends Controller
{
    public function index(Request $request)
    {
        return Pedido::query()
            ->when(! $request->user()->is_admin, fn ($q) => $q->whereBelongsTo($request->user()))
            ->paginate();
    }
}
```

Para papéis e permissões guardados no banco, o pacote mais usado é o `spatie/laravel-permission`, que se integra a `can()` e `@can`.
