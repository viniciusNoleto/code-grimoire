O cache guarda o resultado de operações caras (consultas pesadas, chamadas externas, cálculos) para reaproveitar nas próximas requisições. O mesmo serviço oferece locks atômicos, que coordenam processos concorrentes.

### Drivers

`CACHE_STORE` (*Laravel 11+*; antes `CACHE_DRIVER`) escolhe o padrão: `database` (padrão em projetos novos), `redis`, `memcached`, `file`, `dynamodb`, `array` (só na memória da requisição, usado em testes).

```php [app/Services/CotacaoService.php]
Cache::store('redis')->get('chave');     // outro store pontualmente
```

### Operações básicas

```php [app/Services/CotacaoService.php]
Cache::get('cotacao_usd');                      // null se não existir
Cache::get('cotacao_usd', 5.0);                 // valor padrão (ou closure)
Cache::put('cotacao_usd', 5.42, 600);           // TTL em segundos
Cache::put('cotacao_usd', 5.42, now()->addMinutes(10));
Cache::add('trava', true, 30);                  // só grava se não existir; devolve bool
Cache::forever('config_loja', $config);
Cache::has('cotacao_usd');
Cache::pull('codigo_2fa');                      // lê e apaga
Cache::forget('cotacao_usd');
Cache::increment('visitas');  Cache::decrement('estoque:10', 2);
Cache::many(['a', 'b']);  Cache::putMany(['a' => 1, 'b' => 2], 60);
Cache::flush();                                 // apaga TUDO do store (cuidado se o store é compartilhado)
```

### `remember` e `flexible`

```php [app/Http/Controllers/ProdutoController.php]
$produtos = Cache::remember('produtos:destaque', 3600, function () {
    return Produto::destaque()->with('imagens')->get();   // só roda se a chave não existir
});

Cache::rememberForever('categorias', fn () => Categoria::orderBy('nome')->get());
```

:version[Laravel 11+] `flexible` aplica *stale-while-revalidate*: dentro do primeiro prazo devolve o valor normalmente; entre o primeiro e o segundo devolve o valor antigo **e** recalcula depois da resposta; depois do segundo, recalcula na hora.

```php [app/Services/RankingService.php]
$ranking = Cache::flexible('ranking', [300, 900], fn () => Venda::rankingDoMes());
//                                    fresco por 5 min, aceitável até 15 min
```

Isso evita que muitas requisições recalculem o mesmo valor ao mesmo tempo quando ele expira (*cache stampede*).

### Tags

Tags agrupam chaves para invalidar em conjunto. Não funcionam nos drivers `file`, `database` e `dynamodb`.

```php [app/Services/CatalogoService.php]
Cache::tags(['produtos', "loja:{$loja->id}"])->put("produto:{$id}", $produto, 3600);
Cache::tags(['produtos', "loja:{$loja->id}"])->get("produto:{$id}");
Cache::tags("loja:{$loja->id}")->flush();        // apaga tudo dessa loja
```

### Locks atômicos

Um lock garante que só um processo (requisição, job, servidor) execute um trecho por vez. Exige driver com suporte: `redis`, `memcached`, `database`, `dynamodb` ou `file` (este só num servidor).

```php [app/Actions/PagarPedido.php]
$lock = Cache::lock("pedido:{$pedido->id}:pagamento", 10);   // expira em 10s mesmo se o processo morrer

if ($lock->get()) {
    try {
        $this->processarPagamento($pedido);
    } finally {
        $lock->release();
    }
}

// com closure: libera sozinho
Cache::lock('relatorio-mensal', 120)->get(fn () => Relatorio::gerar());

// espera até 5s pelo lock; lança LockTimeoutException se não conseguir
Cache::lock('estoque:10', 10)->block(5, fn () => $produto->baixarEstoque(1));
```

Lock entre processos (adquirir numa requisição, liberar num job):

```php [app/Console/Commands/ImportarProdutos.php]
$lock = Cache::lock('importacao', 600);
if ($lock->get()) {
    ImportarPlanilha::dispatch($arquivo, $lock->owner());
}

// no job
Cache::restoreLock('importacao', $this->owner)->release();
```

### Recursos recentes

```php [app/Services/LojaService.php]
Cache::touch('sessao:abc', 3600);               // Laravel 13+: estende o TTL sem ler e regravar o valor

$v = Cache::memo()->get('config_loja');         // versões recentes: na mesma requisição/job,
$v = Cache::memo()->get('config_loja');         // a segunda leitura vem da memória
```

O helper `once()` (*Laravel 11+*) memoriza o resultado de uma closure dentro da requisição, sem tocar no cache:

```php [app/Models/User.php]
class User extends Model
{
    public function plano(): Plano
    {
        return once(fn () => $this->assinatura->plano()->first());   // consulta uma vez por instância
    }
}
```

### Estratégias

- **Chaves descritivas e com versão**: `produtos:destaque:v2`. Mudou o formato do dado, mudou a versão.
- **Invalidar no evento certo**: num observer `saved`/`deleted` do Model, ou com tags.
- **Não cachear objetos enormes**: guarde arrays ou ids, não Collections com relacionamentos profundos.
- **Cuidado com dados por usuário**: inclua o id do usuário (ou do tenant) na chave.
- **Cache HTTP**: para respostas públicas, o middleware `cache.headers` deixa o navegador ou CDN guardar a resposta.
