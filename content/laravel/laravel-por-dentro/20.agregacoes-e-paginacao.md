Agregações devolvem um número calculado pelo banco; paginação devolve uma página de resultados com metadados para montar links.

### Agregações

| Método | Assinatura | Retorna |
| --- | --- | --- |
| `count` | `count(string $columns = '*')` | `int` |
| `sum` | `sum(string $column)` | número (0 se vazio) |
| `avg` / `average` | `avg(string $column)` | número ou `null` |
| `min` | `min(string $column)` | valor ou `null` |
| `max` | `max(string $column)` | valor ou `null` |
| `exists` / `doesntExist` | sem parâmetros | `bool` |

```php
Pedido::where('status', 'pago')->count();
-- SQL: select count(*) as aggregate from "pedidos" where "status" = ?

Pedido::whereYear('created_at', 2026)->sum('total');
-- SQL: select sum("total") as aggregate from "pedidos" where extract(year from "created_at") = ?

Avaliacao::where('produto_id', 5)->avg('nota');
-- SQL: select avg("nota") as aggregate from "avaliacoes" where "produto_id" = ?

Pedido::max('total');
-- SQL: select max("total") as aggregate from "pedidos"
```

O apelido `aggregate` é interno: o Laravel lê essa coluna e devolve só o número.

Agregações combinam com qualquer filtro. Para agregar **por registro relacionado** (quantos pedidos cada usuário tem), use `withCount`/`withSum` ([seção 28](#eager-loading-with)), não um loop com `count()`.

### `paginate()`

```php
->paginate(int|null $perPage = null, array $columns = ['*'], string $pageName = 'page', int|null $page = null, Closure|int|null $total = null)
```

- **`$perPage`**: itens por página. `null` usa `$perPage` do Model (padrão 15).
- **`$columns`**: colunas a trazer.
- **`$pageName`**: nome do parâmetro na URL (`?page=2`). Mude quando houver duas paginações na mesma tela.
- **`$page`**: página atual. `null` lê da requisição automaticamente.
- **`$total`**: total já conhecido (evita a query de contagem); aceita Closure (versões recentes).

Faz duas queries: um `COUNT` para o total e um `SELECT` com `LIMIT/OFFSET`.

```php
$pedidos = Pedido::latest()->paginate(20);           // acessando ?page=2
-- SQL (duas queries):
--      select count(*) as aggregate from "pedidos"
--      select * from "pedidos" order by "created_at" desc limit 20 offset 20

$pedidos = Pedido::paginate(10, ['*'], 'pagina_pedidos');   // lê ?pagina_pedidos=N

$pedidos = Pedido::paginate(perPage: 10, page: 3);
-- SQL: ... limit 10 offset 20

$pedidos = Pedido::simplePaginate(20);               // ?page=2
// SQL (uma query; busca 1 a mais para saber se há próxima):
--      select * from "pedidos" limit 21 offset 20
```

No Blade: `{{ $pedidos->links() }}`. Em JSON, o paginador vira um objeto com `data`, `current_page`, `last_page`, `total`, `links` etc.

### `simplePaginate()`

Mesmos parâmetros, sem `$total`. **Não faz o `COUNT`**: só sabe se existe próxima página. Mais rápido em tabelas grandes; ideal para "Anterior / Próxima".

### `cursorPaginate()`

```php
->cursorPaginate(?int $perPage = null, array $columns = ['*'], string $cursorName = 'cursor', $cursor = null)
```

Usa `WHERE id > último` em vez de `OFFSET`. É o mais rápido e estável para rolagem infinita, mas exige `orderBy` em coluna única e não permite pular para a página N.

```php
$posts = Post::orderBy('id')->cursorPaginate(15);
-- SQL da 1ª página: select * from "posts" order by "id" asc limit 16
-- SQL das próximas: select * from "posts" where ("id" > ?) order by "id" asc limit 16
--                   (o cursor da URL guarda o último id visto)
```

### Métodos do objeto paginador

| Método | Retorna |
| --- | --- |
| `items()` | Os Models da página |
| `total()` / `lastPage()` | Total de itens / última página (só em `paginate`) |
| `currentPage()` / `perPage()` | Página atual / itens por página |
| `count()` | Itens nesta página |
| `hasPages()` / `hasMorePages()` | Se há mais de uma página / se há próxima |
| `onFirstPage()` / `onLastPage()` | Posição atual |
| `firstItem()` / `lastItem()` | Número do primeiro / último item da página |
| `url($page)` / `nextPageUrl()` / `previousPageUrl()` | URLs |
| `withQueryString()` | Mantém os outros parâmetros da URL (filtros) nos links |
| `appends(array $params)` | Acrescenta parâmetros aos links |
| `fragment('secao')` | Acrescenta `#secao` aos links |
| `withPath('/admin/pedidos')` | Troca o caminho base dos links |
| `through(callable)` | Transforma cada item mantendo a paginação |
| `onEachSide(int)` | Quantos links aparecem ao redor da página atual |

```php
$pedidos = Pedido::where('status', $status)->paginate(20)->withQueryString();
```
