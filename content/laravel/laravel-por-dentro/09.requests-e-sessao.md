O objeto `Illuminate\Http\Request` representa a requisição atual e dá acesso tipado a tudo que o cliente enviou.

### Lendo a entrada

```php [app/Http/Controllers/PedidoController.php]
class PedidoController extends Controller
{
    public function store(Request $request)
    {
        $request->input('nome');                     // corpo ou query string
        $request->input('endereco.cidade');          // notação de ponto em arrays/JSON
        $request->input('itens.*.id');               // todos os ids do array
        $request->query('pagina', 1);                // só query string, com padrão
        $request->all();
        $request->only(['nome', 'email']);
        $request->except(['senha']);

        $request->string('nome')->trim();            // Stringable
        $request->integer('quantidade');
        $request->boolean('aceita_termos');          // "1", "true", "on", "yes" viram true
        $request->date('nascimento', 'd/m/Y');       // Carbon ou null
        $request->enum('status', StatusPedido::class);

        $request->has('cupom');                      // a chave existe (mesmo vazia)
        $request->filled('cupom');                   // existe e não está vazia
        $request->missing('cupom');
        $request->whenFilled('cupom', fn ($c) => ...);

        $request->merge(['origem' => 'site']);       // acrescenta valores
        $request->mergeIfMissing(['quantidade' => 1]);
    }
}
```

### Informações da requisição

```php [app/Http/Controllers/PedidoController.php]
$request->path();             // pedidos/10
$request->url();              // sem query string
$request->fullUrl();          // com query string
$request->method();           // GET, POST…
$request->isMethod('post');
$request->is('admin/*');      // padrão de caminho
$request->routeIs('pedidos.*');
$request->ip();
$request->header('X-Origem');
$request->bearerToken();      // Authorization: Bearer xxx
$request->expectsJson();      // AJAX ou Accept: application/json
$request->user();             // usuário autenticado ou null
$request->route('pedido');    // parâmetro da rota
```

### Arquivos enviados

```php [app/Http/Controllers/PerfilController.php]
if ($request->hasFile('avatar') && $request->file('avatar')->isValid()) {
    $arquivo = $request->file('avatar');
    $arquivo->getClientOriginalName();          // nome enviado pelo cliente (não confie)
    $arquivo->extension();                      // extensão pelo conteúdo (MIME)

    $caminho = $arquivo->store('avatars', 's3');                    // nome aleatório
    $caminho = $arquivo->storeAs('avatars', "{$user->id}.jpg", 's3');
}
```

### Sessão

A sessão guarda dados entre requisições do mesmo navegador. Só existe nas rotas `web`.

```php [app/Http/Controllers/CarrinhoController.php]
$request->session()->put('carrinho_id', 15);
session(['carrinho_id' => 15]);               // helper
session('carrinho_id');                       // ler
$request->session()->get('carrinho_id', $padrao);
$request->session()->pull('cupom');           // lê e remove
$request->session()->forget('cupom');
$request->session()->flash('status', 'Pedido criado!');   // só na próxima requisição
$request->session()->regenerate();            // novo id de sessão: faça após login
$request->session()->invalidate();            // descarta tudo: faça no logout
```

Drivers (`SESSION_DRIVER`): `database` (padrão no Laravel 11+), `redis`, `file`, `cookie`, `array` (testes).

### Cookies e old input

```php [app/Http/Controllers/PreferenciaController.php]
return response('ok')->cookie('tema', 'escuro', 60 * 24 * 30);   // minutos
$request->cookie('tema');        // cookies do Laravel são criptografados e assinados

return back()->withInput()->withErrors(['email' => 'E-mail inválido']);
```
