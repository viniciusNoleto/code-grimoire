Facades, contracts e helpers são três formas de acessar o mesmo serviço do container. Escolher entre elas é questão de estilo e de testabilidade, não de funcionalidade.

### Como uma facade funciona

`Cache::get('x')` parece um método estático, mas não é. A classe `Cache` estende `Facade` e só informa qual serviço do container ela representa. O `__callStatic` busca esse objeto no container e repassa a chamada.

```php
class Cache extends Facade
{
    protected static function getFacadeAccessor(): string
    {
        return 'cache';     // nome do binding no container
    }
}

Cache::get('chave');
// equivale a: app('cache')->get('chave');
```

### Três formas, o mesmo serviço

| Forma | Exemplo | Quando preferir |
| --- | --- | --- |
| Facade | `Cache::get('k')` | Código curto em controllers, rotas, providers |
| Injeção (contract) | `__construct(private Repository $cache)` | Classes de domínio; dependências visíveis no construtor |
| Helper | `cache('k')`, `config('app.name')`, `now()` | Views, código de uma linha |

::note{type="tip" title="Regra prática"}
Se uma classe usa muitas facades diferentes, ela provavelmente faz coisas demais. Injetar as dependências torna isso visível.
::

### Contracts

Contracts são as interfaces do framework, em `Illuminate\Contracts\*`: `Cache\Repository`, `Queue\Queue`, `Mail\Mailer`, `Filesystem\Filesystem`, `Auth\Guard`… Depender da interface deixa o código desacoplado da implementação concreta.

```php
use Illuminate\Contracts\Cache\Repository as Cache;

class CotacaoService
{
    public function __construct(private Cache $cache) {}
}
```

### Real-time facades

Qualquer classe vira facade prefixando o namespace com `Facades\`:

```php
use Facades\App\Services\CotacaoService;

CotacaoService::hoje('USD');   // resolve App\Services\CotacaoService do container e chama hoje()
```

### Facades em testes

Toda facade pode ser substituída por um mock ou por um fake:

```php
Cache::shouldReceive('get')->once()->with('cotacao')->andReturn(5.4);

Mail::fake();          // também: Queue, Bus, Event, Notification, Storage, Http
// ... executa o código ...
Mail::assertSent(PedidoConfirmado::class);
```
