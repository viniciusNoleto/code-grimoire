Middleware é uma camada que envolve a requisição: roda código antes de ela chegar ao controller, depois que a resposta é gerada, ou interrompe o fluxo (por exemplo, devolvendo 401).

### Estrutura

```php
// php artisan make:middleware GarantirAssinaturaAtiva
class GarantirAssinaturaAtiva
{
    public function handle(Request $request, Closure $next): Response
    {
        if (! $request->user()?->assinaturaAtiva()) {
            return redirect()->route('planos');     // interrompe: o controller não roda
        }

        $response = $next($request);                // passa para a próxima camada

        $response->headers->set('X-Plano', $request->user()->plano);  // depois do controller
        return $response;
    }
}
```

### Registrar e aplicar

:version[Laravel 11+] Tudo em `bootstrap/app.php`:

```php
->withMiddleware(function (Middleware $middleware): void {
    $middleware->append(RegistrarTempoDeResposta::class);        // global, no fim da fila
    $middleware->prepend(ForcarJson::class);                     // global, no início
    $middleware->web(append: [DefinirIdioma::class]);            // grupo web
    $middleware->api(prepend: [ForcarJson::class]);              // grupo api
    $middleware->alias(['assinante' => GarantirAssinaturaAtiva::class]);
    $middleware->priority([...]);                                // ordem relativa forçada
})
```

```php
Route::get('/painel', ...)->middleware('assinante');
Route::get('/painel', ...)->middleware(['auth', GarantirAssinaturaAtiva::class]);
Route::get('/publico', ...)->withoutMiddleware(['auth']);
```

### Parâmetros

```php
public function handle(Request $request, Closure $next, string ...$papeis): Response
{
    abort_unless($request->user()->temAlgumPapel($papeis), 403);
    return $next($request);
}

Route::get('/admin', ...)->middleware('papel:admin,editor');   // $papeis = ['admin', 'editor']
```

### Middleware terminável

```php
public function terminate(Request $request, Response $response): void
{
    // roda depois de enviar a resposta ao cliente
}
```

Para o `terminate` receber a mesma instância usada no `handle`, registre o middleware como singleton no container.

### Middlewares nativos que você vai usar

| Alias | O que faz |
| --- | --- |
| `auth` / `auth:sanctum` | Exige usuário autenticado (no guard indicado) |
| `guest` | Só para não autenticados (telas de login) |
| `verified` | E-mail verificado |
| `can:update,post` | Autorização via policy ([seção 37](#autorizacao)) |
| `throttle:api` | Rate limit |
| `signed` | URL assinada válida |
| `password.confirm` | Pede a senha de novo antes de ações sensíveis |
| `cache.headers:public;max_age=3600;etag` | Cabeçalhos de cache HTTP |

Os grupos `web` e `api` já incluem cookies, sessão, proteção CSRF (só `web`) e `SubstituteBindings` (que faz o route model binding).
