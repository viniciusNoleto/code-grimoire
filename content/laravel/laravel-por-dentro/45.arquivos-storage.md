A facade `Storage` dá a mesma API para disco local, S3 e outros serviços. Trocar o destino dos arquivos é questão de configuração.

### Discos

```php
// config/filesystems.php
'disks' => [
    'local'  => ['driver' => 'local', 'root' => storage_path('app/private')],   // privado
    'public' => ['driver' => 'local', 'root' => storage_path('app/public'), 'url' => env('APP_URL').'/storage', 'visibility' => 'public'],
    's3'     => ['driver' => 's3', 'key' => env('AWS_ACCESS_KEY_ID'), 'bucket' => env('AWS_BUCKET'), /* ... */],
],
```

```bash
php artisan storage:link     # cria public/storage → storage/app/public
```

### API

```php
Storage::put('relatorios/vendas.csv', $conteudo);            // disco padrão (FILESYSTEM_DISK)
Storage::disk('s3')->put('avatars/1.jpg', $binario, 'public');
Storage::get('relatorios/vendas.csv');
Storage::json('config/importacao.json');                     // decodifica
Storage::exists('x');  Storage::missing('x');
Storage::delete(['a.txt', 'b.txt']);
Storage::copy('a.txt', 'backup/a.txt');
Storage::move('tmp/a.txt', 'final/a.txt');
Storage::size('a.txt');  Storage::lastModified('a.txt');  Storage::mimeType('a.txt');
Storage::files('relatorios');  Storage::allFiles('relatorios');  Storage::directories('/');
Storage::makeDirectory('exportacoes');  Storage::deleteDirectory('tmp');
Storage::append('log.txt', 'linha nova');

Storage::url('avatars/1.jpg');                               // URL pública
Storage::temporaryUrl('contratos/10.pdf', now()->addMinutes(5));   // URL assinada que expira (S3 e drivers compatíveis)
return Storage::download('contratos/10.pdf', 'contrato.pdf');
```

### Uploads

```php
$caminho = $request->file('contrato')->store('contratos', 's3');              // nome aleatório
$caminho = $request->file('contrato')->storeAs('contratos', "{$id}.pdf", 's3');
$caminho = Storage::putFile('avatars', $request->file('avatar'));
$pedido->update(['contrato_path' => $caminho]);                                // guarde o caminho, não a URL
```

Para arquivos privados, sirva por uma rota que verifica autorização ou por `temporaryUrl`; nunca coloque no disco `public`.

### Arquivos grandes

```php
Storage::disk('s3')->writeStream('backups/banco.sql.gz', fopen($local, 'r'));   // sem carregar na memória
$stream = Storage::disk('s3')->readStream('backups/banco.sql.gz');

['url' => $url, 'headers' => $headers] = Storage::disk('s3')->temporaryUploadUrl(
    'uploads/video.mp4', now()->addMinutes(10)
);  // o navegador envia direto ao S3, sem passar pelo servidor
```

Storage::fake('s3');
$this->post('/contratos', ['contrato' => UploadedFile::fake()->create('c.pdf', 200, 'application/pdf')]);
