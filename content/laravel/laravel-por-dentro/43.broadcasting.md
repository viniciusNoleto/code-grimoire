Broadcasting envia eventos do servidor para o navegador por WebSocket: novos pedidos aparecendo no painel, chat, notificações instantâneas, progresso de importação.

### Peças

| Peça | Papel |
| --- | --- |
| Evento com `ShouldBroadcast` | O que será transmitido |
| Servidor WebSocket | Reverb (oficial, auto-hospedado), Pusher ou Ably |
| Canais | Públicos, privados (com autorização) e de presença (sabe quem está conectado) |
| Laravel Echo | Biblioteca JS que escuta os canais no navegador |

```bash
php artisan install:broadcasting    # Laravel 11+: instala Reverb, Echo e cria routes/channels.php
php artisan reverb:start
```

### Evento transmitido

```php
class PedidoAtualizado implements ShouldBroadcast       // ShouldBroadcastNow: sem fila
{
    use Dispatchable, InteractsWithSockets, SerializesModels;

    public function __construct(public Pedido $pedido) {}

    public function broadcastOn(): array
    {
        return [new PrivateChannel("pedidos.{$this->pedido->user_id}")];
    }

    public function broadcastAs(): string { return 'pedido.atualizado'; }

    public function broadcastWith(): array               // payload; sem isso, envia as propriedades públicas
    {
        return ['id' => $this->pedido->id, 'status' => $this->pedido->status];
    }
}

broadcast(new PedidoAtualizado($pedido))->toOthers();    // não envia para quem originou a ação
```

### Autorizar canais

```php
// routes/channels.php
Broadcast::channel('pedidos.{userId}', fn (User $user, int $userId) => $user->id === $userId);

Broadcast::channel('sala.{salaId}', function (User $user, int $salaId) {   // presença: devolve dados do usuário
    return $user->participaDa($salaId) ? ['id' => $user->id, 'nome' => $user->nome] : false;
});
```

### No navegador

```js
Echo.private(`pedidos.${userId}`)
    .listen('.pedido.atualizado', (e) => atualizarStatus(e.id, e.status));

Echo.join(`sala.${salaId}`)
    .here((usuarios) => ...)
    .joining((u) => ...)
    .leaving((u) => ...);
```

Os starter kits do Laravel 12+ trazem hooks prontos para React e Vue (`useEcho`). Models também podem transmitir os próprios eventos com a trait `BroadcastsEvents`.
