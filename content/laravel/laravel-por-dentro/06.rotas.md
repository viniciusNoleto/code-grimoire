Uma rota liga um método HTTP e uma URL a um controller ou closure. As rotas web ficam em `routes/web.php` (com sessão, cookies e CSRF) e as de API em `routes/api.php` (sem estado, prefixo `/api`).

### Definindo rotas

```php
use Illuminate\Support\Facades\Route;

Route::get('/pedidos', [PedidoController::class, 'index']);
Route::post('/pedidos', [PedidoController::class, 'store']);
Route::put('/pedidos/{pedido}', [PedidoController::class, 'update']);
Route::patch('/pedidos/{pedido}', ...);
Route::delete('/pedidos/{pedido}', ...);

Route::match(['get', 'post'], '/busca', BuscaController::class);   // controller de ação única
Route::any('/webhook', WebhookController::class);

Route::redirect('/antigo', '/novo', 301);
Route::view('/sobre', 'paginas.sobre', ['ano' => 2026]);   // devolve uma view sem controller
```

Formulários HTML só enviam GET e POST. Para PUT, PATCH e DELETE, envie POST com `@method('PUT')` no Blade.

### Parâmetros e restrições

```php
Route::get('/usuarios/{id}', fn (string $id) => ...);
Route::get('/usuarios/{nome?}', fn (?string $nome = 'visitante') => ...);   // opcional

Route::get('/pedidos/{id}', ...)->whereNumber('id');
Route::get('/arquivos/{uuid}', ...)->whereUuid('uuid');
Route::get('/categoria/{tipo}', ...)->whereIn('tipo', ['livro', 'filme']);
Route::get('/posts/{slug}', ...)->where('slug', '[a-z0-9-]+');

// em AppServiceProvider::boot(): vale para todas as rotas com {id}
Route::pattern('id', '[0-9]+');
```

### Nomes e geração de URLs

Dê nome às rotas e gere URLs pelo nome. Assim, mudar o caminho não quebra links.

```php
Route::get('/pedidos/{pedido}', [PedidoController::class, 'show'])->name('pedidos.show');

route('pedidos.show', $pedido);                        // http://app.test/pedidos/10
route('pedidos.show', ['pedido' => 10, 'aba' => 'itens']);  // parâmetros extras viram query string
url('/ajuda');                                         // URL absoluta de um caminho
to_route('pedidos.show', $pedido);                     // resposta de redirecionamento

request()->routeIs('pedidos.*');                       // a rota atual casa com o padrão?
```

**URLs assinadas** carregam uma assinatura que impede alteração, úteis para links de e-mail:

```php
$url = URL::temporarySignedRoute('pedidos.recibo', now()->addHour(), ['pedido' => 10]);

Route::get('/recibo/{pedido}', ...)->name('pedidos.recibo')->middleware('signed');  // 403 se adulterada ou expirada
```

### Grupos

Grupos aplicam atributos comuns a várias rotas:

```php
Route::middleware(['auth', 'verified'])
    ->prefix('admin')                 // URLs começam com /admin
    ->name('admin.')                  // nomes começam com admin.
    ->group(function () {
        Route::get('/relatorios', ...)->name('relatorios');   // admin.relatorios

        Route::controller(PedidoAdminController::class)->group(function () {
            Route::get('/pedidos', 'index');                   // método do controller pelo nome
            Route::post('/pedidos/{pedido}/cancelar', 'cancelar');
        });
    });

Route::domain('{loja}.meusite.com')->group(...);   // roteamento por subdomínio
```

### Route model binding

Quando o parâmetro da rota tem o mesmo nome de uma variável tipada com um Model, o Laravel busca o registro e responde 404 se não existir.

```php
Route::get('/posts/{post}', fn (Post $post) => $post);          // busca por id
Route::get('/posts/{post:slug}', fn (Post $post) => $post);     // busca por outra coluna

// escopo: o comentário precisa pertencer ao post
Route::get('/posts/{post}/comentarios/{comentario:slug}', fn (Post $post, Comentario $comentario) => ...)
    ->scopeBindings();

Route::get('/posts/{post}', ...)->withTrashed();                 // inclui soft deleted

Route::get('/posts/{post:slug}', ...)
    ->missing(fn (Request $r) => to_route('posts.index'));        // em vez de 404

Route::get('/categorias/{categoria}', fn (Categoria $categoria) => ...);  // enum PHP: 404 se o valor não existir no enum
```

O comportamento padrão de busca é configurável no Model com `getRouteKeyName()` ou `resolveRouteBinding()` ([seção 16.12](#criar-e-configurar-chave-usada-nas-rotas)).

### Rotas de recurso

```php
Route::resource('pedidos', PedidoController::class);
Route::apiResource('pedidos', PedidoController::class);          // sem create e edit
Route::resource('pedidos', PedidoController::class)->only(['index', 'show']);
Route::resource('pedidos.itens', ItemController::class)->shallow();  // aninhado
```

| Verbo | URL | Método | Nome |
| --- | --- | --- | --- |
| GET | `/pedidos` | `index` | `pedidos.index` |
| GET | `/pedidos/create` | `create` | `pedidos.create` |
| POST | `/pedidos` | `store` | `pedidos.store` |
| GET | `/pedidos/{pedido}` | `show` | `pedidos.show` |
| GET | `/pedidos/{pedido}/edit` | `edit` | `pedidos.edit` |
| PUT/PATCH | `/pedidos/{pedido}` | `update` | `pedidos.update` |
| DELETE | `/pedidos/{pedido}` | `destroy` | `pedidos.destroy` |

### Rate limiting nas rotas

Os limites são definidos em `AppServiceProvider::boot()` e aplicados com o middleware `throttle`:

```php
RateLimiter::for('api', function (Request $request) {
    return $request->user()
        ? Limit::perMinute(120)->by($request->user()->id)
        : Limit::perMinute(30)->by($request->ip());
});

RateLimiter::for('login', fn (Request $r) => [
    Limit::perMinute(5)->by($r->input('email').$r->ip()),
    Limit::perHour(100)->by($r->ip()),                    // vários limites ao mesmo tempo
]);

Route::post('/login', ...)->middleware('throttle:login');
Route::middleware('throttle:60,1')->group(...);          // 60 por minuto, sem limiter nomeado
```

Ao estourar, o cliente recebe 429 com os cabeçalhos `Retry-After` e `X-RateLimit-*`.

### API, fallback e cache de rotas

```bash
php artisan install:api      # Laravel 11+: cria routes/api.php e instala o Sanctum
php artisan route:list --path=api --except-vendor
php artisan route:cache      # em produção; não aceita rotas com closure
```

```php
Route::fallback(fn () => response()->json(['message' => 'Rota não encontrada'], 404));
```
