O Laravel traz uma biblioteca de utilitários usada em todo o framework. Dominá-la reduz muito código de laço e manipulação de arrays.

### Collections

```php
$pedidos = collect($array);         // ou o retorno de qualquer get()

$pedidos->map(fn ($p) => $p->total);
$pedidos->filter(fn ($p) => $p->pago);           // mantém as chaves; use ->values() para reindexar
$pedidos->reject(fn ($p) => $p->cancelado);
$pedidos->where('status', 'pago');               // filtro por chave/valor
$pedidos->firstWhere('numero', 'A1');
$pedidos->pluck('total', 'numero');
$pedidos->keyBy('id');
$pedidos->groupBy('status');                     // ['pago' => Collection, ...]
$pedidos->groupBy(fn ($p) => $p->created_at->format('Y-m'));
$pedidos->sortBy('total');  $pedidos->sortByDesc('created_at');
$pedidos->sum('total');  $pedidos->avg('total');  $pedidos->max('total');
$pedidos->countBy('status');                     // ['pago' => 10, 'pendente' => 3]
$pedidos->partition(fn ($p) => $p->pago);        // [pagos, nao_pagos]
$pedidos->chunk(100);  $pedidos->take(5);  $pedidos->skip(10);
$pedidos->unique('cliente_id');
$pedidos->flatMap(fn ($p) => $p->itens);
$pedidos->mapWithKeys(fn ($p) => [$p->numero => $p->total]);
$pedidos->reduce(fn ($soma, $p) => $soma + $p->total, 0);
$pedidos->contains(fn ($p) => $p->total > 1000);
$pedidos->every(fn ($p) => $p->pago);
$pedidos->isEmpty();  $pedidos->isNotEmpty();
$pedidos->when($soPagos, fn ($c) => $c->where('pago', true));
$pedidos->pipe(fn ($c) => new RelatorioDePedidos($c));

$pedidos->each->notificarCliente();              // higher order: chama o método em cada item
$pedidos->sum->total;
```

### Lazy collections

Processam itens um a um, com memória constante:

```php
LazyCollection::make(function () {
    $handle = fopen(storage_path('import/clientes.csv'), 'r');
    while (($linha = fgetcsv($handle)) !== false) yield $linha;
})
->skip(1)                       // cabeçalho
->chunk(500)
->each(fn ($bloco) => Cliente::upsert($bloco->map(...)->all(), ['cpf']));
```

### Strings

```php
use Illuminate\Support\Str;

Str::slug('Pedido Número 1');           // pedido-numero-1
Str::limit($texto, 100);                 // corta com ...
Str::title('joão da silva');             // João Da Silva
Str::camel('nome_completo');  Str::snake('nomeCompleto');  Str::kebab(...);  Str::studly(...);
Str::plural('pedido');                   // pedidos (regras do inglês)
Str::contains($s, ['pix', 'boleto']);  Str::startsWith($s, 'A');  Str::endsWith($s, '.pdf');
Str::uuid();  Str::ulid();  Str::random(32);  Str::password(16);
Str::mask('12345678900', '*', 3, 5);     // 123*****900
Str::between($s, '[', ']');  Str::after($s, '@');  Str::before($s, '@');

Str::of('  pedido-a1  ')->trim()->upper()->replace('-', ' ')->toString();   // fluente
str('texto')->slug();                    // helper
```

### Arrays

```php
use Illuminate\Support\Arr;

Arr::get($dados, 'endereco.cidade', 'N/D');     // notação de ponto
Arr::set($dados, 'endereco.uf', 'AM');
Arr::has($dados, 'endereco.cep');
Arr::only($dados, ['nome', 'email']);  Arr::except($dados, ['senha']);
Arr::wrap($valor);                               // garante array
Arr::first($itens, fn ($i) => $i['ativo']);
Arr::pluck($itens, 'id');  Arr::flatten($aninhado);
Arr::dot(['a' => ['b' => 1]]);                   // ['a.b' => 1]
Arr::undot(['a.b' => 1]);

data_get($pedido, 'itens.*.produto.nome');       // funciona com arrays e objetos
data_set($dados, 'meta.origem', 'api');
```

### Números e datas

```php
use Illuminate\Support\Number;

Number::currency(1234.5, in: 'BRL', locale: 'pt_BR');   // R$ 1.234,50
Number::format(1234567.891, precision: 2, locale: 'pt_BR');
Number::percentage(12.5);                               // 13%
Number::fileSize(1536);                                 // 2 KB
Number::forHumans(1500000);                             // 1.5 million
Number::abbreviate(1500000);                            // 2M

now();  today();  now()->addDays(3)->startOfDay();
$data->diffForHumans();              // "há 2 dias" (com locale pt_BR)
$data->isPast();  $data->isWeekend();  $data->between($inicio, $fim);
Carbon::parse('2026-11-06')->format('d/m/Y');
CarbonImmutable::now();              // operações não alteram o objeto original
```

::note{type="tip" title="Dica"}
Para evitar bugs em que `$data->addDay()` altera a variável original, configure datas imutáveis no `boot()` com `Date::use(CarbonImmutable::class)`.
::

### Helpers gerais

```php
blank($v);  filled($v);              // vazio no sentido do Laravel ('' , null, [], coleção vazia, só espaços)
optional($user)->nome;               // null-safe (em PHP 8, prefira $user?->nome)
value($valorOuClosure);
tap($pedido, fn ($p) => $p->save()); // executa e devolve o próprio objeto
with($valor, fn ($v) => ...);
retry(3, fn () => Http::get($url)->throw(), 200);   // 3 tentativas com 200ms
throw_if($pedido->pago, PedidoJaPago::class);
throw_unless($user->ativo, AuthorizationException::class);
Benchmark::dd(fn () => Pedido::count());   // mede tempo de execução
Sleep::for(2)->seconds();                  // sleep que pode ser simulado em testes
```

### Pipeline

Passa um objeto por uma sequência de etapas, como os middlewares:

```php
$pedido = Pipeline::send($pedido)
    ->through([
        AplicarCupom::class,
        CalcularFrete::class,
        CalcularImpostos::class,
    ])
    ->thenReturn();

class AplicarCupom
{
    public function handle(Pedido $pedido, Closure $next)
    {
        if ($pedido->cupom) $pedido->desconto = $pedido->cupom->calcular($pedido);
        return $next($pedido);
    }
}
```
