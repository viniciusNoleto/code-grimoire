Se um método não aparece em nenhuma seção deste guia, ele foi criado no seu projeto ou em um pacote. `$this->model->byToken(...)` é um exemplo típico: `byToken` não existe no Laravel.

### Onde procurar um método desconhecido

Busque o nome no projeto, nesta ordem:

| Busque por | Se encontrar, é |
| --- | --- |
| `scopeByToken` | Local scope clássico ([seção 24.1](#scopes-local-scope-forma-clássica)) |
| `#[Scope]` seguido de `function byToken` | Local scope com atributo ([seção 24.2](#scopes-local-scope-com-atributo-scope)) |
| `function byToken` no Model | Método comum do Model |
| `function byToken` em `app/Repositories` ou `app/Services` | Método de repository/service |
| `macro('byToken'` | Macro registrada num ServiceProvider |
| `function byToken` numa trait em `app/Traits` ou `app/Models/Concerns` | Método vindo de uma trait usada pelo Model |
| Nada no projeto | Pacote em `vendor/` (busque lá também) |

Na IDE, "Ir para definição" resolve isso em um clique, desde que o `laravel-ide-helper` esteja instalado ([seção 35.4](#depuracao-comandos-e-ferramentas-para-entender-models)).

### O padrão Repository: o que é `$this->model`

Em projetos que usam Repository, uma classe intermediária recebe o Model no construtor e o guarda em `$this->model`. O controller conversa com o repository, não com o Model.

```php [app/Repositories/UserRepository.php]
class UserRepository
{
    public function __construct(protected User $model) {}

    public function findByToken(string $token): ?User
    {
        return $this->model->byToken($token)->first();
        // $this->model é uma instância de User; byToken() é um scope do User
    }

    public function ativosPaginados(int $porPagina = 15)
    {
        return $this->model->newQuery()->where('ativo', true)->paginate($porPagina);
    }
}
```

Como `$this->model` é uma **instância**, `$this->model->where(...)` funciona: a instância também encaminha chamadas desconhecidas para um Builder novo ([seção 15.1](#como-um-model-funciona-a-cadeia-de-encaminhamento)). Mesmo assim, `$this->model->newQuery()` deixa explícito que começa uma consulta nova.

É comum ter um `BaseRepository` com métodos genéricos (`find`, `create`, `update`, `delete`, `paginate`) que só repassam para `$this->model`. Esses métodos são do seu projeto, mesmo tendo nomes iguais aos do Eloquent.

### Métodos próprios no Model

Três formas, conforme o que o método devolve:

```php [app/Models/User.php]
class User extends Model
{
    // 1. Scope: devolve Builder, encadeável
    public function scopeByToken(Builder $query, string $token): void
    {
        $query->where('token', $token);
    }

    // 2. Estático: devolve resultado pronto
    public static function findByToken(string $token): ?self
    {
        return static::where('token', $token)->first();
    }

    // 3. De instância: age sobre um registro
    public function regenerarToken(): void
    {
        $this->update(['token' => Str::random(60)]);
    }
}
```

```php [app/Http/Controllers/UserController.php]
User::byToken($t)->where('ativo', true)->first();  // 1
User::findByToken($t);                              // 2
$user->regenerarToken();                            // 3
```

### Macros no Builder

Acrescentam métodos a **todos** os Models, pelo Builder. Registre no `AppServiceProvider::boot()`:

```php [app/Providers/AppServiceProvider.php]
use Illuminate\Database\Eloquent\Builder;

class AppServiceProvider extends ServiceProvider
{
    public function boot(): void
    {
        Builder::macro('byToken', function (string $token) {
            /** @var Builder $this */
            return $this->where('token', $token);
        });
    }
}
```

```php [app/Http/Controllers/UserController.php]
User::byToken($t)->first();
Cliente::byToken($t)->first();   // em qualquer Model
```

`Builder::hasGlobalMacro('byToken')` verifica se existe. Use macros com moderação: são difíceis de encontrar para quem lê o código.

### Builder personalizado

Para Models com muitos scopes, dá para mover tudo para uma classe Builder própria:

```php [app/Models/Builders/UserBuilder.php]
class UserBuilder extends Builder
{
    public function byToken(string $token): static
    {
        return $this->where('token', $token);
    }
}
```

```php [app/Models/User.php]
use Illuminate\Database\Eloquent\Attributes\UseEloquentBuilder;

#[UseEloquentBuilder(UserBuilder::class)]   // Laravel 12+; antes, sobrescreva newEloquentBuilder($query)
class User extends Model {}
```

### Traits reutilizáveis

Comportamento compartilhado entre Models (como o `SoftDeletes`) vai em traits. Uma trait pode ter um método `boot{NomeDaTrait}()` e `initialize{NomeDaTrait}()`, chamados automaticamente pelo Model.

```php [app/Models/Concerns/TemToken.php]
trait TemToken
{
    public static function bootTemToken(): void
    {
        static::creating(fn ($model) => $model->token ??= Str::random(60));
    }

    public function scopeByToken(Builder $query, string $token): void
    {
        $query->where('token', $token);
    }
}
```

```php [app/Models/User.php]
class User extends Model { use TemToken; }
class ApiCliente extends Model { use TemToken; }
```
