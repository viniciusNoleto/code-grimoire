Os três transformam valores entre o banco e o PHP: o **accessor** age na leitura, o **mutator** na escrita, e o **cast** faz as duas conversões para tipos comuns sem você escrever lógica.

### Accessor e mutator com `Attribute`

Um método `protected` com o nome do atributo em camelCase, retornando `Attribute::make()`.

```php
Attribute::make(?callable $get = null, ?callable $set = null): Attribute
```

- **`get`**: recebe `($value, $attributes)`. `$value` é o valor cru da coluna; `$attributes` é o array com todos os atributos crus. Devolve o valor que o seu código vai ver.
- **`set`**: recebe `($value, $attributes)` e devolve o valor a gravar, **ou** um array `['coluna' => valor, ...]` para preencher várias colunas.

```php
use Illuminate\Database\Eloquent\Casts\Attribute;

class User extends Model
{
    protected function nome(): Attribute
    {
        return Attribute::make(
            get: fn (string $value) => ucfirst($value),
            set: fn (string $value) => strtolower($value),
        );
    }
}

$user->nome = 'ANA';   // grava 'ana'
echo $user->nome;      // 'Ana'
```

Coluna `primeiro_nome` → método `primeiroNome()` → acesso `$user->primeiro_nome`.

### Atributos calculados (sem coluna)

Um accessor pode criar um atributo que não existe na tabela, combinando outros.

```php
protected function nomeCompleto(): Attribute
{
    return Attribute::make(
        get: fn ($value, array $attributes) => $attributes['nome'].' '.$attributes['sobrenome'],
    );
}

$user->nome_completo;   // 'Ana Silva'
```

Para aparecer no JSON, adicione em `$appends` ([seção 30](#serializacao)).

### Mutator que preenche várias colunas

```php
protected function endereco(): Attribute
{
    return Attribute::make(
        get: fn ($v, $attrs) => new Endereco($attrs['rua'], $attrs['cidade']),
        set: fn (Endereco $e) => ['rua' => $e->rua, 'cidade' => $e->cidade],
    );
}
```

### Cache de accessor: `shouldCache()` e `withoutObjectCaching()`

Accessors que devolvem **objetos** são guardados em cache por padrão: alterações no objeto voltam ao Model automaticamente no save.

- `->shouldCache()`: força cache também para valores primitivos (útil para cálculos pesados).
- `->withoutObjectCaching()`: desliga o cache de objetos.

```php
protected function hash(): Attribute
{
    return Attribute::make(get: fn ($v) => bcrypt($v))->shouldCache();
}
```

### Sintaxe antiga (ainda funciona)

```php
public function getNomeAttribute($value) { return ucfirst($value); }   // accessor
public function setNomeAttribute($value) { $this->attributes['nome'] = strtolower($value); } // mutator
```

Você vai encontrar isso em projetos antigos. Prefira `Attribute` em código novo.

### Casts: tipos disponíveis

Declarados no método `casts()` (Laravel 11+) ou na propriedade `$casts`.

| Cast | Efeito ao ler | Observações |
| --- | --- | --- |
| `integer` / `int` | `int` |  |
| `real` / `float` / `double` | `float` |  |
| `decimal:2` | `string` com 2 casas | Evita erro de arredondamento de float |
| `string` | `string` |  |
| `boolean` / `bool` | `true`/`false` | Converte 0/1 do banco |
| `array` | `array` | Coluna JSON/texto; grava com `json_encode` |
| `json` | `array` | Igual a `array` |
| `object` | `stdClass` |  |
| `collection` | `Collection` |  |
| `date` | `Carbon` (00:00) |  |
| `datetime` | `Carbon` | `datetime:Y-m-d` define o formato na serialização |
| `immutable_date` / `immutable_datetime` | `CarbonImmutable` | Alterações não mudam o Model sem querer |
| `timestamp` | `int` | Unix timestamp |
| `hashed` | — | Faz hash ao gravar (senhas) |
| `encrypted` | `string` descriptografada | Criptografa ao gravar com a `APP_KEY` |
| `encrypted:array` / `encrypted:collection` / `encrypted:object` | Tipos correspondentes | Criptografados |
| `AsStringable::class` | `Stringable` | Permite `$user->nome->upper()` |
| `AsArrayObject::class` | `ArrayObject` | Permite alterar índices: `$user->opcoes['a'] = 1` |
| `AsCollection::class` | `Collection` | Alterável; `AsCollection::of(Item::class)` mapeia itens |
| `AsEnumCollection::of(Status::class)` | Collection de Enums |  |
| `AsEnumArrayObject::of(Status::class)` | ArrayObject de Enums |  |
| `AsEncryptedArrayObject` / `AsEncryptedCollection` | Versões criptografadas |  |
| `Status::class` (Enum PHP) | Instância do Enum | Grava o valor do backed enum |

```php
protected function casts(): array
{
    return [
        'ativo' => 'boolean',
        'saldo' => 'decimal:2',
        'nascimento' => 'date',
        'pago_em' => 'datetime:d/m/Y H:i',
        'opcoes' => AsArrayObject::class,
        'senha' => 'hashed',
        'status' => StatusPedido::class,
    ];
}

$pedido->status === StatusPedido::Pago;   // Enum
$pedido->pago_em->diffForHumans();         // Carbon
```

A coluna `array` sem `AsArrayObject` tem uma pegadinha: `$user->opcoes['tema'] = 'escuro'` **não funciona** (erro de modificação indireta). Pegue, altere e reatribua o array inteiro, ou use `AsArrayObject`/`AsCollection`.

### Datas

`created_at`, `updated_at` e `deleted_at` já são `datetime`. Para o formato no JSON de todas as datas, sobrescreva:

```php
protected function serializeDate(DateTimeInterface $date): string
{
    return $date->format('Y-m-d H:i:s');
}
```

### Cast em tempo de execução

```php
$user->mergeCasts(['metadados' => 'array']);           // numa instância
User::select('*')->withCasts(['ultimo_login' => 'datetime'])->get(); // numa query (útil em selectRaw)
```

### Casts personalizados

`php artisan make:cast Dinheiro` cria uma classe com `get` e `set`.

```php
use Illuminate\Contracts\Database\Eloquent\CastsAttributes;

class Dinheiro implements CastsAttributes
{
    public function get(Model $model, string $key, mixed $value, array $attributes): float
    {
        return $value / 100;              // banco guarda centavos
    }

    public function set(Model $model, string $key, mixed $value, array $attributes): int
    {
        return (int) round($value * 100);
    }
}

// no Model: 'preco' => Dinheiro::class
```

Parâmetros dos métodos:

- `$model`: a instância.
- `$key`: o nome do atributo.
- `$value`: o valor (cru em `get`, do PHP em `set`).
- `$attributes`: todos os atributos crus.

Variações:

- **Parâmetros no cast**: `'preco' => Dinheiro::class.':BRL'` → o construtor recebe `'BRL'`.
- **`CastsInboundAttributes`**: só `set` (ex.: um hash).
- **`Castable`**: um objeto de valor (como `Endereco`) declara qual cast usar via `castUsing()`, e o Model faz `'endereco' => Endereco::class`.
- **`SerializesCastableAttributes`**: controla como o valor aparece no `toArray()`.
- Um `set` pode devolver um array para gravar várias colunas, como no mutator.
