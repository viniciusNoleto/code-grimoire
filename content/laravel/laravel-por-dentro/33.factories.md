Uma factory descreve como criar um Model com dados falsos. Ela é ligada ao Model pela trait `HasFactory` e usada em testes e seeders.

### Definição

`php artisan make:factory PedidoFactory --model=Pedido`

```php
class PedidoFactory extends Factory
{
    public function definition(): array
    {
        return [
            'user_id' => User::factory(),          // cria um User junto, se não informado
            'numero' => fake()->unique()->numerify('PED-#####'),
            'total' => fake()->randomFloat(2, 10, 1000),
            'status' => 'pendente',
        ];
    }

    public function pago(): static                  // "state" reutilizável
    {
        return $this->state(fn (array $attributes) => ['status' => 'pago']);
    }
}

class Pedido extends Model
{
    use HasFactory;   // habilita Pedido::factory()
}
```

Se a factory não seguir a convenção de nome, use `#[UseFactory(PedidoFactory::class)]` no Model (*Laravel 12+*) ou sobrescreva `newFactory()`.

### Uso

| Método | Efeito |
| --- | --- |
| `Pedido::factory()->create(array $attributes = [])` | Cria e salva |
| `->make(array $attributes = [])` | Instancia sem salvar |
| `->raw()` | Só o array de atributos |
| `->count(int $n)` | Quantidade (retorna Collection) |
| `->state(array\|callable $state)` | Sobrescreve atributos |
| `->pago()` | State definido na factory |
| `->sequence(...)` | Alterna valores entre os registros |
| `->for(Model\|Factory $parent, ?string $relationship = null)` | Define o pai (`belongsTo`) |
| `->has(Factory $factory, ?string $relationship = null)` | Cria filhos (`hasMany`) |
| `->hasAttached(Factory\|Collection $factory, array $pivot = [], ?string $relationship = null)` | Liga em `belongsToMany` com dados de pivô |
| `->recycle(Model\|Collection $model)` | Reaproveita Models existentes nas relações, em vez de criar novos |
| `->afterCreating(Closure)` / `->afterMaking(Closure)` | Callbacks (geralmente em `configure()`) |
| `->createQuietly()` | Cria sem eventos |
| `->trashed()` | Cria já em soft delete |

```php
$pedido = Pedido::factory()->create();
$pedidos = Pedido::factory()->count(10)->pago()->create();
Pedido::factory()->count(4)->sequence(['status' => 'pago'], ['status' => 'pendente'])->create();

Pedido::factory()->for($user)->create();                   // pedido do usuário $user
User::factory()->has(Pedido::factory()->count(3))->create(); // usuário com 3 pedidos
User::factory()->hasPedidos(3)->create();                  // atalho mágico: has + nome da relação
User::factory()->hasAttached(Role::factory()->count(2), ['ativo' => true])->create();

Pedido::factory()->count(50)->recycle(User::factory()->count(5)->create())->create();
```
