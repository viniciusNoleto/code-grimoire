`get()`, `all()` e relacionamentos "muitos" devolvem uma `Illuminate\Database\Eloquent\Collection`. Ela tem todos os métodos da Collection comum (`map`, `filter`, `sum`, `groupBy`, `sortBy`, `first`, `each`, `pluck`…) e mais alguns específicos para Models.

::note{type="tip" title="Regra de ouro"}
Métodos de Collection rodam **no PHP**, sobre o que já foi carregado. Se puder filtrar no banco (`where`), filtre lá.
::

### Métodos exclusivos da Eloquent Collection

| Método | O que faz |
| --- | --- |
| `contains($key, $operator = null, $value = null)` | Aceita Model ou id: `$users->contains($user)`, `$users->contains(5)` |
| `diff($items)` | Models que não estão na outra coleção (por chave) |
| `intersect($items)` | Models presentes nas duas |
| `except($keys)` | Remove Models pelas chaves primárias |
| `only($keys)` | Mantém só os Models com essas chaves |
| `find($key, $default = null)` | Busca por chave primária na coleção (sem query); aceita array |
| `findOrFail($key)` | Idem, lança exceção se não achar (versões recentes) |
| `modelKeys()` | Array com as chaves primárias: `[1, 2, 3]` |
| `fresh($with = [])` | Nova coleção recarregada do banco |
| `unique($key = null, $strict = false)` | Remove duplicados (por chave primária, por padrão) |
| `load(...)`, `loadMissing`, `loadCount`, `loadSum`, `loadMorph`… | Eager loading em todos os Models ([seção 28.5](#eager-loading-with-load-carregar-depois)) |
| `makeVisible($attrs)` / `makeHidden($attrs)` | Em todos os Models |
| `append($attrs)` | Em todos os Models |
| `setVisible` / `setHidden` | Em todos os Models |
| `toQuery()` | Converte em Builder com `whereIn` nas chaves, para atualizar em massa |
| `withRelationshipAutoloading()` | Eager loading automático ([seção 28.9](#eager-loading-with-eager-loading-automático)) |
| `getDictionary()` | Array `[chave => Model]` |

```php [app/Http/Controllers/UserController.php]
$users = User::where('ativo', true)->get();

$users->contains($admin);                 // bool
$users->find(10);                         // sem consultar o banco
$ids = $users->modelKeys();               // [1, 4, 9]
$semAdmins = $users->except($admins->modelKeys());

$users->toQuery()->update(['notificado' => true]);   // 1 UPDATE WHERE id IN (...)
```

### Métodos comuns mais usados com Models

```php [app/Services/RelatorioService.php]
$pedidos->sum('total');
$pedidos->avg('total');
$pedidos->groupBy('status');                       // ['pago' => Collection, ...]
$pedidos->keyBy('numero');                         // indexa pelo número
$pedidos->sortByDesc('created_at');
$pedidos->filter(fn ($p) => $p->total > 100);
$pedidos->map(fn ($p) => $p->numero);              // vira Collection comum
$pedidos->pluck('cliente.nome');                   // aceita ponto em relacionamentos carregados
$pedidos->firstWhere('status', 'pago');
$pedidos->where('status', 'pago');                 // filtro em memória (não é query!)
$pedidos->isEmpty(); $pedidos->isNotEmpty();
$pedidos->chunk(10);
$pedidos->partition(fn ($p) => $p->pago);          // [pagos, nao_pagos]
```

::note{type="pitfall" title="Atenção"}
Métodos com o mesmo nome da query: `$user->pedidos()->where(...)` consulta o banco; `$user->pedidos->where(...)` filtra a Collection já carregada.
::

### Collection personalizada

Para acrescentar métodos próprios às coleções de um Model:

```php [app/Collections/PedidoCollection.php]
use Illuminate\Database\Eloquent\Collection;

class PedidoCollection extends Collection
{
    public function totalPago(): float
    {
        return $this->where('status', 'pago')->sum('total');
    }
}
```

```php [app/Models/Pedido.php]
use Illuminate\Database\Eloquent\Attributes\CollectedBy;

#[CollectedBy(PedidoCollection::class)]     // Laravel 11+
class Pedido extends Model {}

// alternativa em versões anteriores, no Model:
public function newCollection(array $models = []): Collection
{
    return new PedidoCollection($models);
}
```

```php [app/Http/Controllers/PedidoController.php]
Pedido::all()->totalPago();
```
