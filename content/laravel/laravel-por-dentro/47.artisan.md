Artisan é a interface de linha de comando do Laravel. Além dos comandos do framework, você cria os seus para tarefas de manutenção, importações e rotinas agendadas.

### Comandos do dia a dia

| Comando | Para quê |
| --- | --- |
| `php artisan about` | Versões, drivers e caches ativos |
| `php artisan tinker` | Console interativo com a aplicação carregada |
| `php artisan make:<tipo>` | Gera classes (model, controller, job, policy, test…) |
| `php artisan route:list` | Rotas registradas |
| `php artisan migrate`, `db:seed` | Banco ([seção 13](#migrations)) |
| `php artisan queue:work`, `queue:failed` | Filas ([seção 39](#filas-e-jobs)) |
| `php artisan schedule:list` | Agendamentos |
| `php artisan optimize`, `optimize:clear` | Caches de produção ([seção 52](#performance)) |
| `php artisan config:show app` | Configuração final |
| `php artisan test --parallel` | Testes |
| `php artisan down`, `up` | Manutenção |
| `php artisan vendor:publish --tag=...` | Copia arquivos de pacotes para o projeto |
| `php artisan pail` | Acompanha os logs em tempo real |

### Criar um comando

```bash
php artisan make:command ExpirarPedidos
```

```php [app/Console/Commands/ExpirarPedidos.php]
class ExpirarPedidos extends Command
{
    protected $signature = 'pedidos:expirar
                            {dias=3 : Dias sem pagamento}
                            {--loja=* : Ids de lojas (pode repetir)}
                            {--dry-run : Só mostra, não altera}';

    protected $description = 'Cancela pedidos não pagos há mais de N dias';

    public function handle(PedidoService $servico): int        // dependências injetadas
    {
        $dias = (int) $this->argument('dias');
        $lojas = $this->option('loja');                         // array
        $simular = $this->option('dry-run');                    // bool

        $pedidos = $servico->vencidos($dias, $lojas);

        if ($pedidos->isEmpty()) {
            $this->info('Nada a expirar.');
            return self::SUCCESS;
        }

        $this->table(['Número', 'Total'], $pedidos->map->only(['numero', 'total']));

        if ($simular || ! $this->confirm("Cancelar {$pedidos->count()} pedidos?", true)) {
            return self::SUCCESS;
        }

        $this->withProgressBar($pedidos, fn (Pedido $p) => $servico->cancelar($p));
        $this->newLine();
        $this->info('Concluído.');
        return self::SUCCESS;                                   // 0; FAILURE = 1
    }
}
```

```bash
php artisan pedidos:expirar 5 --loja=1 --loja=2 --dry-run
```

Sintaxe da assinatura: `{arg}` obrigatório, `{arg?}` opcional, `{arg=padrao}`, `{arg*}` array, `{--opcao}` booleana, `{--opcao=}` com valor, `{--O|opcao}` atalho.

### Entrada e saída

```php [app/Console/Commands/CriarLoja.php]
$this->line('normal');  $this->info('verde');  $this->warn('amarelo');  $this->error('vermelho');
$nome  = $this->ask('Nome da loja?');
$senha = $this->secret('Senha?');
$tipo  = $this->choice('Tipo?', ['pf', 'pj'], 0);
```

Os **Laravel Prompts** dão interfaces mais ricas (busca, multisseleção, spinner):

```php [app/Console/Commands/CriarLoja.php]
use function Laravel\Prompts\{text, select, confirm, spin};

$loja = select('Loja', Loja::pluck('nome', 'id')->all());
$total = spin(fn () => $servico->processar($loja), 'Processando...');
```

### Comandos em closure e chamadas pelo código

```php [routes/console.php]
Artisan::command('cache:aquecer', function () {
    Cache::put('categorias', Categoria::all());
    $this->info('Cache aquecido');
})->purpose('Pré-carrega o cache');
```

Em qualquer lugar do código:

```php [app/Http/Controllers/Admin/ManutencaoController.php]
Artisan::call('pedidos:expirar', ['dias' => 5, '--dry-run' => true]);
Artisan::output();
Artisan::queue('relatorios:gerar');      // pela fila
```

Comandos que não podem rodar em paralelo implementam `Isolatable` e são chamados com `--isolated`.
