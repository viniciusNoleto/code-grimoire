O agendador substitui dezenas de linhas no crontab por código versionado. No servidor existe uma única entrada no cron, que roda a cada minuto e executa o que estiver na hora.

### Configuração no servidor

```bash
* * * * * cd /var/www/loja && php artisan schedule:run >> /dev/null 2>&1
```

Em desenvolvimento: `php artisan schedule:work` (roda em primeiro plano, a cada minuto).

### Definindo tarefas

:version[Laravel 11+] Em `routes/console.php`:

```php [routes/console.php]
use Illuminate\Support\Facades\Schedule;

Schedule::command('pedidos:expirar')->hourly();
Schedule::command('relatorios:enviar --tipo=diario')->dailyAt('07:00')->timezone('America/Manaus');
Schedule::job(new LimparCarrinhosAbandonados)->daily();
Schedule::call(fn () => DB::table('sessoes_antigas')->delete())->weekly();
Schedule::exec('pg_dump loja > /backups/loja.sql')->dailyAt('03:00');
Schedule::command('model:prune')->daily();
```

### Frequências

| Método | Quando |
| --- | --- |
| `everyMinute()`, `everyFiveMinutes()`, `everyFifteenMinutes()` | Intervalos curtos |
| `hourly()`, `hourlyAt(17)` | A cada hora (no minuto 17) |
| `daily()`, `dailyAt('13:00')`, `twiceDaily(1, 13)` | Diário |
| `weekly()`, `weeklyOn(1, '8:00')` | Semanal (1 = segunda) |
| `monthly()`, `monthlyOn(5, '9:00')`, `lastDayOfMonth('23:00')` | Mensal |
| `cron('0 */6 * * *')` | Expressão cron |
| `weekdays()`, `weekends()`, `between('8:00', '18:00')` | Restrições combináveis |

### Controle de execução

```php [routes/console.php]
Schedule::command('relatorios:gerar')
    ->daily()
    ->withoutOverlapping(30)          // não inicia se a anterior ainda roda (trava expira em 30 min)
    ->onOneServer()                   // com vários servidores, só um executa (precisa de cache compartilhado)
    ->runInBackground()               // não bloqueia as outras tarefas do mesmo minuto
    ->environments(['production'])
    ->when(fn () => Feature::active('relatorios'))
    ->onFailure(fn () => Log::error('Relatório falhou'))
    ->pingOnSuccess('https://monitor.exemplo/ok');   // monitoramento de cron
```

```bash
php artisan schedule:list      # próximas execuções
php artisan schedule:test      # escolhe uma tarefa e roda agora
```
