Blade é o motor de templates do Laravel. Ele compila as views para PHP puro e as guarda em cache, então não pesa em produção.

### Sintaxe essencial

```html
<h1>{{ $pedido->numero }}</h1>          {{-- escapa HTML: seguro contra XSS --}}
{!! $html_confiavel !!}                  {{-- sem escape: só com conteúdo que você controla --}}

@if ($pedido->pago) Pago @elseif ($pedido->vencido) Vencido @else Aberto @endif
@unless ($user->ativo) Conta bloqueada @endunless
@isset($cupom) ... @endisset
@empty($itens) ... @endempty

@foreach ($itens as $item)
    {{ $loop->iteration }} de {{ $loop->count }} @if ($loop->last) (último) @endif
@endforeach

@forelse ($pedidos as $pedido) <li>{{ $pedido->numero }}</li> @empty <p>Nenhum pedido.</p> @endforelse

@auth ... @endauth   @guest ... @endguest
@can('update', $pedido) <a href="...">Editar</a> @endcan

<form method="POST" action="{{ route('pedidos.update', $pedido) }}">
    @csrf
    @method('PUT')
    <input name="email" value="{{ old('email') }}" @class(['input', 'erro' => $errors->has('email')])>
    @error('email') <span>{{ $message }}</span> @enderror
    <input type="checkbox" name="ativo" @checked($user->ativo)>
</form>

<script>const pedido = {{ Js::from($pedido) }};</script>
@include('partials.alerta', ['tipo' => 'sucesso'])
```

### Componentes

```bash
php artisan make:component Alerta            # classe + view
php artisan make:component botao --view      # só a view (anônimo)
```

```html
{{-- resources/views/components/alerta.blade.php --}}
@props(['tipo' => 'info', 'titulo'])
<div {{ $attributes->merge(['class' => "alerta alerta-$tipo"]) }}>
    <strong>{{ $titulo }}</strong>
    {{ $slot }}
    @isset($rodape) <footer>{{ $rodape }}</footer> @endisset
</div>

{{-- uso --}}
<x-alerta tipo="erro" titulo="Falha no pagamento" class="mt-4">
    O cartão foi recusado.
    <x-slot:rodape>Tente outro cartão.</x-slot:rodape>
</x-alerta>
```

Use `:prop="$variavel"` para passar expressões PHP. `$attributes` carrega todo atributo que não é prop.

### Layouts

```html
{{-- resources/views/components/layout.blade.php --}}
<html><body>
    <header>{{ $cabecalho ?? '' }}</header>
    <main>{{ $slot }}</main>
</body></html>

{{-- página --}}
<x-layout>
    <x-slot:cabecalho>Pedidos</x-slot:cabecalho>
    ...
</x-layout>
```

A forma antiga, com `@extends`, `@section` e `@yield`, continua funcionando.

### Dados para as views

```php [app/Http/Controllers/PedidoController.php]
return view('pedidos.show', ['pedido' => $pedido]);
return view('pedidos.show', compact('pedido'));
View::share('empresa', 'Loja X');                             // em um provider: disponível em todas
View::composer('partials.menu', fn ($view) => $view->with('categorias', Categoria::all()));
```

### Vite e o frontend

```html
@vite(['resources/css/app.css', 'resources/js/app.js'])
```

```bash
npm run dev     # servidor com hot reload
npm run build   # gera arquivos versionados em public/build
```

Os caminhos de frontend mais usados com Laravel:

| Abordagem | Como funciona |
| --- | --- |
| Blade puro | Páginas renderizadas no servidor |
| Livewire | Componentes PHP com interatividade sem escrever JS |
| Inertia (React, Vue, Svelte) | SPA com rotas e controllers do Laravel, sem API separada |
| API + SPA ou app mobile | Laravel só como API (Sanctum para autenticação) |

:version[Laravel 12+] Os starter kits oficiais (React, Vue, Livewire) já trazem autenticação, layout e testes prontos.
