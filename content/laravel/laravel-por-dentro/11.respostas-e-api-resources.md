Todo controller devolve algo que o Laravel converte em resposta HTTP. Para APIs, os API Resources definem o formato do JSON de forma explícita e independente das colunas do banco.

### Tipos de resposta

```php
return 'texto';                                  // 200 text/html
return ['ok' => true];                           // array vira JSON
return $pedido;                                  // Model/Collection vira JSON (toArray)
return response()->json($dados, 201, ['X-Total' => 10]);
return response()->noContent();                  // 204
return response($conteudo, 200)->header('Content-Type', 'text/csv');

return redirect('/painel');
return redirect()->route('pedidos.show', $pedido)->with('status', 'Salvo!');
return back()->withErrors(['campo' => 'erro'])->withInput();
return redirect()->away('https://pagamento.com/checkout');

return response()->download($caminho, 'recibo.pdf');
return response()->file($caminho);                       // exibe no navegador
return response()->streamDownload(function () use ($csv) { echo $csv; }, 'relatorio.csv');
return response()->stream(function () { /* echo + flush aos poucos */ }, 200, ['Content-Type' => 'text/event-stream']);
```

### Erros e status

```php
abort(404);
abort(403, 'Sem permissão');
abort_if($pedido->pago, 409, 'Pedido já pago');
abort_unless($user->ativo, 403);
```

| Status | Quando usar |
| --- | --- |
| 200 OK | Leitura ou atualização com corpo na resposta |
| 201 Created | Recurso criado (`store`) |
| 204 No Content | Sucesso sem corpo (`destroy`) |
| 401 Unauthorized | Não autenticado |
| 403 Forbidden | Autenticado, mas sem permissão |
| 404 Not Found | Não existe (ou você não quer revelar que existe) |
| 409 Conflict | Conflito com o estado atual |
| 422 Unprocessable | Validação falhou |
| 429 Too Many Requests | Rate limit |
| 500 Server Error | Erro não tratado |

### API Resources

```bash
php artisan make:resource PedidoResource
php artisan make:resource PedidoCollection     # só se precisar de meta própria na coleção
```

```php
class PedidoResource extends JsonResource
{
    public function toArray(Request $request): array
    {
        return [
            'id'         => $this->id,
            'numero'     => $this->numero,
            'total'      => (float) $this->total,
            'status'     => $this->status->value,
            'criado_em'  => $this->created_at->toIso8601String(),
            'cliente'    => new ClienteResource($this->whenLoaded('cliente')),   // só se carregado com with()
            'itens'      => ItemResource::collection($this->whenLoaded('itens')),
            'qtd_itens'  => $this->whenCounted('itens'),                         // só se veio de withCount()
            'nota_fiscal'=> $this->when($request->user()->is_admin, $this->nota_fiscal),
            $this->mergeWhen($this->pago, ['pago_em' => $this->pago_em]),
        ];
    }

    public function with(Request $request): array      // chaves extras no topo da resposta
    {
        return ['versao' => 'v1'];
    }
}

return new PedidoResource($pedido->load('cliente'));
return PedidoResource::collection(Pedido::with('cliente')->paginate(20));
return (new PedidoResource($pedido))->response()->setStatusCode(201);
return $pedido->toResource();        // Laravel 12+: encontra PedidoResource pela convenção de nome
```

Resposta paginada:

```json
{
  "data": [ { "id": 1, "numero": "A1" } ],
  "links": { "first": "...?page=1", "next": "...?page=2" },
  "meta": { "current_page": 1, "per_page": 20, "total": 87 }
}
```

`JsonResource::withoutWrapping()` (no `boot()`) remove a chave `data` de recursos individuais. *Laravel 13+:* há suporte nativo a respostas no formato JSON:API.
