Um scope é um filtro reutilizável que você define no Model. **Local scopes** são chamados quando você quer (`Pedido::pagos()`); **global scopes** se aplicam sozinhos a todas as consultas. Métodos como `byToken()` quase sempre são local scopes.

### Local scope (forma clássica)

Um método público com prefixo `scope`, que recebe o Builder como primeiro parâmetro. Ao chamar, você tira o prefixo e a primeira letra fica minúscula.

```php
class Pedido extends Model
{
    public function scopePagos(Builder $query): void
    {
        $query->where('status', 'pago');                           // → "status" = ?
    }

    public function scopeRecentes(Builder $query): void
    {
        $query->where('created_at', '>=', now()->subDays(7));      // → "created_at" >= ?
    }
}

Pedido::pagos()->recentes()->get();     // encadeáveis entre si e com qualquer where
-- SQL: select * from "pedidos" where "status" = ? and "created_at" >= ?

$user->pedidos()->pagos()->count();     // funcionam em relacionamentos também
-- SQL: select count(*) as aggregate from "pedidos"
--      where "pedidos"."user_id" = ? and "pedidos"."user_id" is not null and "status" = ?
```

O scope apenas acrescenta condições: o SQL é o mesmo que você teria escrito com `where` direto.

O método pode retornar `void` ou o próprio `$query`; o efeito é o mesmo.

### Local scope com atributo `#[Scope]`

:version[Laravel 12+] Em vez do prefixo, marque um método `protected` com o atributo. O nome chamado é o próprio nome do método.

```php
use Illuminate\Database\Eloquent\Attributes\Scope;

class Pedido extends Model
{
    #[Scope]
    protected function pagos(Builder $query): void
    {
        $query->where('status', 'pago');
    }
}

Pedido::pagos()->get();
```

### Scopes com parâmetros (dinâmicos)

Parâmetros depois do `$query` são os argumentos da chamada. É exatamente o padrão do `byToken`.

```php
public function scopeByToken(Builder $query, string $token): void
{
    $query->where('token', $token);
}

public function scopeDoTipo(Builder $query, string $tipo = 'cliente'): void
{
    $query->where('tipo', $tipo);
}

public function scopeEntre(Builder $query, $inicio, $fim): void
{
    $query->whereBetween('created_at', [$inicio, $fim]);
}

User::byToken($token)->first();
-- SQL: select * from "users" where "token" = ? limit 1

User::doTipo()->get();                 // usa o padrão 'cliente'
-- SQL: select * from "users" where "tipo" = ?

Pedido::entre($inicio, $fim)->sum('total');
-- SQL: select sum("total") as aggregate from "pedidos" where "created_at" between ? and ?
```

### Scopes com OR

Dentro de um scope, use uma Closure para não quebrar a precedência de quem chamar:

```php
public function scopeVisiveis(Builder $query): void
{
    $query->where(fn ($q) => $q->where('publico', true)->orWhere('user_id', auth()->id()));
}

Post::where('categoria', 'php')->visiveis()->get();
-- SQL: select * from "posts" where "categoria" = ? and ("publico" = ? or "user_id" = ?)
--      sem a Closure, o OR quebraria o filtro de categoria

Pedido::pagos()->orWhere->recentes()->get();
-- SQL: select * from "pedidos" where ("status" = ?) or ("created_at" >= ?)
```

Para encadear scopes com `OR`, use a forma de Closure: `Pedido::pagos()->orWhere->recentes()` (o `orWhere` como propriedade aplica o próximo scope com OR).

### Pending attributes: `withAttributes()`

:version[Laravel 12+] Um scope pode, além de filtrar, definir valores para Models criados a partir dele.

```php
public function scopeRascunhos(Builder $query): void
{
    $query->withAttributes(['status' => 'rascunho']);
}

Post::rascunhos()->get();                                 // o atributo vira filtro
-- SQL: select * from "posts" where "status" = ?

$post = Post::rascunhos()->create(['titulo' => 'Novo']);  // e também valor no INSERT
-- SQL: insert into "posts" ("status", "titulo", "updated_at", "created_at")
--      values (?, ?, ?, ?) returning "id"
```

O segundo parâmetro `asConditions: false` aplica só na criação, sem filtrar.

### Global scopes

Aplicam-se a **todas** as queries do Model, sem você chamar. O `SoftDeletes` é um global scope.

**Como classe:**

```php
use Illuminate\Database\Eloquent\Scope;

class AtivoScope implements Scope
{
    public function apply(Builder $builder, Model $model): void
    {
        $builder->where('ativo', true);
    }
}
```

Registre com o atributo ou no `booted()`:

```php
use Illuminate\Database\Eloquent\Attributes\ScopedBy;

#[ScopedBy([AtivoScope::class])]
class Produto extends Model {}

// ou
protected static function booted(): void
{
    static::addGlobalScope(new AtivoScope);
}
```

**Como Closure (anônimo, com nome):**

```php
protected static function booted(): void
{
    static::addGlobalScope('loja_atual', function (Builder $builder) {
        $builder->where('loja_id', session('loja_id'));
    });
}

// Com AtivoScope e 'loja_atual' registrados, qualquer consulta ganha os dois filtros:
Produto::where('preco', '<', 50)->get();
-- SQL: select * from "produtos" where "preco" < ? and "ativo" = ? and "loja_id" = ?
```

`php artisan make:scope AtivoScope` gera a classe.

### Desligar global scopes

```php
Produto::withoutGlobalScope(AtivoScope::class)->get();   // um, pela classe
-- SQL: select * from "produtos" where "loja_id" = ?

Produto::withoutGlobalScope('loja_atual')->get();        // um, pelo nome
-- SQL: select * from "produtos" where "ativo" = ?

Produto::withoutGlobalScopes()->get();                   // todos
-- SQL: select * from "produtos"

Produto::withoutGlobalScopes([AtivoScope::class, 'loja_atual'])->get();  // alguns
-- SQL: select * from "produtos"

Produto::withoutGlobalScopesExcept([AtivoScope::class])->get();          // todos, menos estes
-- SQL: select * from "produtos" where "ativo" = ?
```

::note{type="pitfall" title="Cuidado"}
Global scopes são invisíveis no código da consulta. Se uma query "some" com registros, verifique os global scopes do Model e o `toRawSql()` ([seção 35](#depuracao)).
::

### Local scope vs. global scope vs. método comum

| Tipo | Chamada | Quando usar |
| --- | --- | --- |
| Local scope | `Model::nome()`, encadeável | Filtro que você reutiliza em várias consultas |
| Global scope | Automático | Regra que vale sempre (multi-tenant, ativo, publicado) |
| Método estático comum | `Model::buscarPorToken($t)` | Quando precisa devolver o resultado pronto (não uma query) |
| Método de instância | `$model->marcarComoPago()` | Ação sobre um registro específico |
