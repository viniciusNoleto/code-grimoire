Service Providers são as classes que configuram a aplicação na inicialização: registram bindings, listeners, rotas de pacotes, macros e regras globais. O `AppServiceProvider` já existe em todo projeto.

### `register()` e `boot()`

| Método | Quando roda | O que colocar |
| --- | --- | --- |
| `register()` | Antes de qualquer `boot()` | Somente bindings no container (`bind`, `singleton`…) |
| `boot()` | Depois de todos os `register()` | Tudo que usa outros serviços: Gates, rate limiters, observers, macros, `Model::shouldBeStrict()`, View composers |

```php
class AppServiceProvider extends ServiceProvider
{
    public function register(): void
    {
        $this->app->singleton(GatewayPagamento::class, fn () => new GatewayPagamento(config('services.pagamento.key')));
    }

    public function boot(): void
    {
        Model::shouldBeStrict(! $this->app->isProduction());
        Gate::define('ver-relatorios', fn (User $user) => $user->is_admin);
        RateLimiter::for('api', fn (Request $r) => Limit::perMinute(60)->by($r->user()?->id ?: $r->ip()));
        Password::defaults(fn () => Password::min(8)->mixedCase()->uncompromised());
    }
}
```

::note{type="pitfall" title="Cuidado"}
Usar outro serviço dentro de `register()` (por exemplo `config()` de um pacote ainda não registrado, ou uma facade) pode falhar porque o provider dele talvez ainda não tenha sido registrado.
::

### Criar e registrar

```bash
php artisan make:provider PagamentoServiceProvider
```

:version[Laravel 11+] O comando já adiciona a classe em `bootstrap/providers.php`, que é a lista de providers da aplicação. Providers de pacotes são descobertos automaticamente pelo `composer.json` do pacote (`extra.laravel.providers`).

### Propriedades `$bindings` e `$singletons`

Atalho para registros simples, sem escrever o `register()`:

```php
public $bindings = [Notificador::class => NotificadorWhatsApp::class];
public $singletons = [GatewayPagamento::class => GatewayStripe::class];
```

### Providers adiados

Um provider que só registra bindings pode ser carregado apenas quando um desses serviços for pedido, poupando trabalho em todas as outras requisições:

```php
class PagamentoServiceProvider extends ServiceProvider implements DeferrableProvider
{
    public function register(): void
    {
        $this->app->singleton(GatewayPagamento::class, fn () => new GatewayPagamento(...));
    }

    public function provides(): array
    {
        return [GatewayPagamento::class];   // só carrega quando isto for resolvido
    }
}
```
