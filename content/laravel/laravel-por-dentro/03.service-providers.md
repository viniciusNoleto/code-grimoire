Service Providers são as classes que configuram a aplicação na inicialização: registram bindings, listeners, rotas de pacotes, macros e regras globais. O `AppServiceProvider` já existe em todo projeto.

### `register()` e `boot()`

| Método | Quando roda | O que colocar |
| --- | --- | --- |
| `register()` | Antes de qualquer `boot()` | Somente bindings no container (`bind`, `singleton`…) |
| `boot()` | Depois de todos os `register()` | Tudo que usa outros serviços: Gates, rate limiters, observers, macros, `Model::shouldBeStrict()`, View composers |

```php [app/Providers/AppServiceProvider.php]
namespace App\Providers;

use App\Models\User;
use App\Services\GatewayPagamento;
use Illuminate\Cache\RateLimiting\Limit;
use Illuminate\Database\Eloquent\Model;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Gate;
use Illuminate\Support\Facades\RateLimiter;
use Illuminate\Support\ServiceProvider;
use Illuminate\Validation\Rules\Password;

class AppServiceProvider extends ServiceProvider
{
    public function register(): void
    {
        $this->app->singleton(GatewayPagamento::class, fn () => new GatewayPagamento(config('services.pagamento.key')));
    }

    public function boot(): void
    {
        Model::shouldBeStrict(! $this->app->isProduction());
        Gate::define('ver-relatorios', fn (User $user) => $user->is_admin);
        RateLimiter::for('api', fn (Request $r) => Limit::perMinute(60)->by($r->user()?->id ?: $r->ip()));
        Password::defaults(fn () => Password::min(8)->mixedCase()->uncompromised());
    }
}
```

::note{type="pitfall" title="Cuidado"}
Usar outro serviço dentro de `register()` (por exemplo `config()` de um pacote ainda não registrado, ou uma facade) pode falhar porque o provider dele talvez ainda não tenha sido registrado.
::

### Criar e registrar

```bash
php artisan make:provider PagamentoServiceProvider
```

:version[Laravel 11+] O comando cria `app/Providers/PagamentoServiceProvider.php` e já adiciona a classe em `bootstrap/providers.php`, que é a lista de providers da aplicação.

```php [bootstrap/providers.php]
return [
    App\Providers\AppServiceProvider::class,
    App\Providers\PagamentoServiceProvider::class,
];
```

 Providers de pacotes são descobertos automaticamente pelo `composer.json` do pacote (`extra.laravel.providers`).

### Propriedades `$bindings` e `$singletons`

São duas propriedades públicas que **qualquer Service Provider** pode declarar, no corpo da própria classe (ao lado de `register()` e `boot()`), como no `AppServiceProvider` em `app/Providers/AppServiceProvider.php` ou num provider criado por você. Quando o provider é registrado, o Laravel lê esses arrays e faz por você as chamadas `$this->app->bind()` e `$this->app->singleton()` correspondentes. É um atalho para registros simples, sem escrever o `register()`:

```php [app/Providers/AppServiceProvider.php]
namespace App\Providers;

use App\Contracts\GatewayPagamento;
use App\Contracts\Notificador;
use App\Services\GatewayStripe;
use App\Services\NotificadorWhatsApp;
use Illuminate\Support\ServiceProvider;

class AppServiceProvider extends ServiceProvider
{
    // equivale a $this->app->bind(Notificador::class, NotificadorWhatsApp::class)
    public $bindings = [
        Notificador::class => NotificadorWhatsApp::class,
    ];

    // equivale a $this->app->singleton(GatewayPagamento::class, GatewayStripe::class)
    public $singletons = [
        GatewayPagamento::class => GatewayStripe::class,
    ];

    public function register(): void
    {
        // pode continuar existindo para registros que precisam de closure
    }
}
```

Os arrays só aceitam o par "abstrato ⇒ classe concreta". Se a construção precisa de configuração (`config()`, parâmetros primitivos, outro serviço montado à mão), use o `register()` com closure.

### Providers adiados

Um provider que só registra bindings pode ser carregado apenas quando um desses serviços for pedido, poupando trabalho em todas as outras requisições:

```php [app/Providers/PagamentoServiceProvider.php]
namespace App\Providers;

use App\Services\GatewayPagamento;
use Illuminate\Contracts\Support\DeferrableProvider;
use Illuminate\Support\ServiceProvider;

class PagamentoServiceProvider extends ServiceProvider implements DeferrableProvider
{
    public function register(): void
    {
        $this->app->singleton(GatewayPagamento::class, fn () => new GatewayPagamento(...));
    }

    public function provides(): array
    {
        return [GatewayPagamento::class];   // só carrega quando isto for resolvido
    }
}
```
