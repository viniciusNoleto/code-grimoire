Um Model funciona com zero configuração se seguir as convenções; as propriedades abaixo existem para quando a sua tabela foge delas.

### `php artisan make:model`

```bash
php artisan make:model Pedido
```

Cria `app/Models/Pedido.php`. As flags geram arquivos relacionados ao mesmo tempo:

| Flag | Gera |
| --- | --- |
| `-m` / `--migration` | Migration da tabela |
| `-f` / `--factory` | Factory |
| `-s` / `--seed` | Seeder |
| `-c` / `--controller` | Controller |
| `-r` / `--resource` | Controller com os 7 métodos REST (use com `-c`) |
| `--api` | Controller resource sem `create`/`edit` |
| `-R` / `--requests` | Form Requests de store e update |
| `--policy` | Policy |
| `-p` / `--pivot` | Model de tabela pivô (estende `Pivot`) |
| `--morph-pivot` | Model de pivô polimórfico |
| `-a` / `--all` | Migration, factory, seeder, policy, controller resource e requests |
| `--test` / `--pest` / `--phpunit` | Teste para o Model |

```bash
php artisan make:model Pedido -mfsc --resource   # combinação comum
```

Para inspecionar um Model existente: `php artisan model:show Pedido` lista tabela, colunas, casts, relacionamentos e observers.

### Convenções (o que o Laravel supõe)

- **Tabela**: plural em snake_case do nome da classe. `Pedido` → `pedidos`; `ItemPedido` → `item_pedidos`. A pluralização segue regras do inglês, então nomes em português costumam precisar de `$table`.
- **Chave primária**: coluna `id`, inteira e autoincremento.
- **Timestamps**: colunas `created_at` e `updated_at`, preenchidas automaticamente.
- **Conexão**: a padrão de `config/database.php`.
- **Chave estrangeira** em relacionamentos: `nome_do_model_em_snake_id` (`user_id`).

### Propriedades de tabela e chave

```php
class Pedido extends Model
{
    protected $table = 'tb_pedidos';      // nome da tabela
    protected $primaryKey = 'codigo';     // nome da PK (padrão 'id')
    public $incrementing = false;         // PK não é autoincremento
    protected $keyType = 'string';        // tipo da PK: 'int' (padrão) ou 'string'
    protected $connection = 'mysql_legado'; // conexão de config/database.php
}
```

- `$incrementing = false` é obrigatório quando a PK é gerada por você (UUID, código). Senão, o Laravel tenta ler o id gerado pelo banco após o insert.
- `$keyType = 'string'` evita que o Laravel converta a chave para inteiro.
- O Eloquent **não suporta chave primária composta**. Para tabelas assim, use uma PK simples ou consultas pelo Query Builder.

### Timestamps

```php
public $timestamps = false;                 // desliga created_at/updated_at
const CREATED_AT = 'data_criacao';          // renomeia a coluna
const UPDATED_AT = 'data_alteracao';        // ou null para não ter essa coluna
protected $dateFormat = 'U';                // formato salvo no banco (aqui: unix timestamp)
```

Para salvar sem tocar no `updated_at` uma única vez: `Model::withoutTimestamps(fn () => $pedido->save());` ou `$pedido->timestamps = false; $pedido->save();`.

### Valores padrão de atributos

```php
protected $attributes = [
    'status' => 'pendente',
    'opcoes' => '[]',   // valores "crus", como ficam no banco
];
```

O valor aparece em `new Pedido` antes de salvar. Diferente do `default` da migration, ele já está no objeto PHP.

### Mass assignment: `$fillable` e `$guarded`

Métodos como `create()`, `fill()` e `update()` recebem um array e preenchem vários campos de uma vez. Para impedir que um usuário mal-intencionado envie campos extras (como `is_admin`), o Laravel exige que você declare o que pode ser preenchido.

```php
protected $fillable = ['nome', 'email', 'senha']; // lista de permitidos
// OU
protected $guarded = ['id', 'is_admin'];          // lista de bloqueados
protected $guarded = [];                          // libera tudo (use com cuidado)
```

Use um ou outro, não os dois. Campos fora do `$fillable` são **ignorados em silêncio**, a não ser que o modo estrito esteja ligado ([seção 32](#modo-estrito)). Atribuir diretamente (`$pedido->is_admin = true`) sempre funciona; a proteção vale só para preenchimento em massa.

**Colunas JSON**: para permitir preencher uma chave dentro de um JSON em massa, liste a chave com `->` no `$fillable`: `protected $fillable = ['opcoes->ativo'];`. Com `$guarded`, o Laravel não permite atualizar chaves JSON aninhadas.

### Visibilidade na serialização

```php
protected $hidden = ['senha', 'remember_token']; // some do toArray()/JSON
protected $visible = ['id', 'nome'];             // só estes aparecem (lista branca)
protected $appends = ['nome_completo'];          // accessors incluídos no JSON
```

Detalhes na [seção 30](#serializacao).

### Casts

```php
protected function casts(): array   // Laravel 11+; antes era a propriedade $casts
{
    return [
        'ativo' => 'boolean',
        'pago_em' => 'datetime',
        'opcoes' => 'array',
    ];
}
```

Converte o valor ao ler e ao gravar. Lista completa na [seção 25](#accessors-e-casts).

### Eager loading padrão

```php
protected $with = ['cliente'];          // sempre carrega este relacionamento
protected $withCount = ['itens'];       // sempre traz itens_count
```

Ver [seção 28](#eager-loading-with) para desligar caso a caso.

### Outras propriedades

```php
protected $perPage = 25;              // itens por página no paginate() sem argumento (padrão 15)
protected $touches = ['cliente'];     // ao salvar, atualiza updated_at do cliente (seção 27)
protected $dispatchesEvents = [];     // mapeia eventos do model para classes de evento (seção 29)
```

### Chaves UUID e ULID

Para usar identificadores não sequenciais, use uma trait. Ela gera o valor no `creating` e já ajusta `$incrementing` e `$keyType`.

```php
use Illuminate\Database\Eloquent\Concerns\HasUuids;

class Pedido extends Model
{
    use HasUuids;   // UUID ordenável (v7 no Laravel 12; v4 ordenada antes)
}
// migration: $table->uuid('id')->primary();
```

```php
use Illuminate\Database\Eloquent\Concerns\HasUlids;   // ULID: 26 caracteres, ordenável
// migration: $table->ulid('id')->primary();
```

Personalizações:

```php
public function newUniqueId(): string { return (string) Str::uuid(); } // como gerar
public function uniqueIds(): array { return ['id', 'codigo_publico']; } // quais colunas recebem
```

### Chave usada nas rotas

No *route model binding*, `Route::get('/pedidos/{pedido}')` busca pela PK. Para buscar por outra coluna:

```php
public function getRouteKeyName(): string
{
    return 'slug';
}
// ou só numa rota: Route::get('/pedidos/{pedido:slug}', ...)
```

Para lógica personalizada, sobrescreva `resolveRouteBinding($value, $field = null)`, que deve devolver o Model ou `null`.

### O método `booted()`

É chamado uma vez quando a classe é inicializada. É o lugar para registrar eventos ([seção 29](#eventos-e-observers)) e global scopes ([seção 24](#scopes)).

```php
protected static function booted(): void
{
    static::creating(function (Pedido $pedido) {
        $pedido->numero ??= Str::upper(Str::random(8));
    });
}
```

### Laravel 13: configuração por atributos PHP

No Laravel 13, a documentação passou a configurar o Model com atributos PHP sobre a classe, em vez de propriedades. As propriedades das seções anteriores continuam sendo o que você vai encontrar na maioria dos projetos existentes.

| Atributo | Equivale a |
| --- | --- |
| `#[Table('voos')]` | `$table` |
| `#[Table(key: 'codigo', keyType: 'string', incrementing: false)]` | `$primaryKey`, `$keyType`, `$incrementing` |
| `#[Table(timestamps: false, dateFormat: 'U')]` | `$timestamps`, `$dateFormat` |
| `#[WithoutIncrementing]` | `$incrementing = false` |
| `#[WithoutTimestamps]` | `$timestamps = false` |
| `#[DateFormat('U')]` | `$dateFormat` |
| `#[Connection('mysql')]` | `$connection` |
| `#[Fillable(['nome', 'email'])]` | `$fillable` |
| `#[Guarded([...])]` | `$guarded` |
| `#[Unguarded]` | `$guarded = []` |
| `#[Refreshes(['slug'])]` | Recarrega essas colunas do banco após cada insert/update (útil para colunas geradas pelo banco) |

```php
use Illuminate\Database\Eloquent\Attributes\Fillable;
use Illuminate\Database\Eloquent\Attributes\Table;

#[Table('tb_pedidos', key: 'codigo', keyType: 'string', incrementing: false)]
#[Fillable(['cliente_id', 'total'])]
class Pedido extends Model {}
```

Todos ficam no namespace `Illuminate\Database\Eloquent\Attributes`.
