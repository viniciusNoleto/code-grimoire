A validação garante que só dados no formato esperado cheguem à regra de negócio. Quando falha, o Laravel responde sozinho: redireciona de volta com os erros (requisição web) ou devolve **422** com JSON (requisição que espera JSON).

### `$request->validate()`

```php
$dados = $request->validate([
    'titulo' => ['required', 'string', 'max:255'],
    'email'  => 'required|email|unique:users,email',      // string com | também vale
    'preco'  => ['required', 'decimal:0,2', 'min:0'],
    'tags'   => ['array'],
    'tags.*' => ['string', 'distinct'],
]);
// $dados contém SOMENTE os campos validados
```

Resposta JSON em caso de erro:

```json
{
  "message": "O campo título é obrigatório. (and 1 more error)",
  "errors": { "titulo": ["O campo título é obrigatório."], "email": ["..."] }
}
```

### Form Requests

Para validação reutilizável e controllers limpos:

```bash
php artisan make:request StorePedidoRequest
```

```php
class StorePedidoRequest extends FormRequest
{
    public function authorize(): bool                     // false → 403
    {
        return $this->user()->can('create', Pedido::class);
    }

    protected function prepareForValidation(): void       // ajusta a entrada antes de validar
    {
        $this->merge(['cupom' => strtoupper($this->cupom ?? '')]);
    }

    public function rules(): array
    {
        return [
            'cliente_id'        => ['required', Rule::exists('clientes', 'id')->where('ativo', true)],
            'itens'             => ['required', 'array', 'min:1'],
            'itens.*.produto_id'=> ['required', 'integer', 'exists:produtos,id'],
            'itens.*.quantidade'=> ['required', 'integer', 'between:1,100'],
            'cupom'             => ['nullable', 'string', 'size:8'],
        ];
    }

    public function messages(): array                    // mensagens personalizadas
    {
        return ['itens.min' => 'Adicione pelo menos um item ao pedido.'];
    }

    public function attributes(): array                  // nome do campo nas mensagens
    {
        return ['cliente_id' => 'cliente'];
    }

    public function after(): array                       // validações que dependem de vários campos
    {
        return [function (Validator $validator) {
            if ($this->totalExcedeLimite()) {
                $validator->errors()->add('itens', 'O pedido passa do limite de crédito.');
            }
        }];
    }
}

public function store(StorePedidoRequest $request)       // valida e autoriza antes de entrar no método
{
    $request->validated();                                // todos os validados
    $request->validated('itens');                         // um campo
    $request->safe()->only(['cliente_id', 'cupom']);
}
```

Propriedades úteis: `protected $stopOnFirstFailure = true;` e `protected $redirectRoute = 'pedidos.create';`.

### Regras mais usadas

| Regra | Significado |
| --- | --- |
| `required`, `nullable`, `sometimes` | Obrigatório; pode ser nulo; só valida se o campo vier |
| `present`, `filled`, `missing` | A chave existe; se existir, não é vazia; não pode existir |
| `string`, `integer`, `numeric`, `boolean`, `array`, `decimal:0,2` | Tipos |
| `min:3`, `max:255`, `between:1,10`, `size:8` | Tamanho de string, valor numérico, itens de array ou KB de arquivo |
| `email`, `url`, `uuid`, `ulid`, `ip`, `json`, `regex:/^\d{8}$/` | Formatos |
| `in:a,b`, `not_in:x`, `enum` (com `Rule::enum`) | Lista de valores |
| `unique:tabela,coluna`, `exists:tabela,coluna` | Consultam o banco |
| `date`, `date_format:d/m/Y`, `after:today`, `before_or_equal:fim` | Datas |
| `confirmed` | Exige `campo_confirmation` igual (senhas) |
| `same:campo`, `different:campo`, `gt:campo`, `lte:campo` | Compara com outro campo |
| `required_if:tipo,pj`, `required_with:x`, `required_without:x`, `prohibited_if:...` | Condicionais |
| `exclude_if:tipo,pf` | Remove o campo dos dados validados |
| `file`, `image`, `mimes:pdf,jpg`, `mimetypes:application/pdf`, `max:2048` | Arquivos (tamanho em KB) |
| `bail` | Para no primeiro erro daquele campo |
| `distinct` | Sem repetição dentro de um array |

### Regras como objetos

```php
use Illuminate\Validation\Rule;
use Illuminate\Validation\Rules\{Password, File, Enum};

'email' => ['required', 'email', Rule::unique('users')->ignore($user->id)],   // edição: ignora o próprio registro
'status' => [Rule::enum(StatusPedido::class)->except([StatusPedido::Cancelado])],
'papel' => [Rule::in(['admin', 'editor'])],
'cnpj' => [Rule::requiredIf(fn () => $this->tipo === 'pj')],
'senha' => ['required', 'confirmed', Password::min(8)->letters()->mixedCase()->numbers()->symbols()->uncompromised()],
'foto' => ['required', File::image()->max('5mb')->dimensions(Rule::dimensions()->maxWidth(4000))],
'contrato' => [File::types(['pdf'])->max(10 * 1024)],
```

### Arrays e validação condicional

```php
'itens' => ['required', 'array:produto_id,quantidade'],   // só aceita essas chaves em cada item
'itens.*.quantidade' => ['integer', 'min:1'],
'enderecos.*.cep' => ['required_with:enderecos.*.rua', 'regex:/^\d{5}-?\d{3}$/'],

$validator->sometimes('motivo', 'required|min:20', fn ($input) => $input->status === 'cancelado');
```

### Regras personalizadas

```bash
php artisan make:rule Cpf
```

```php
class Cpf implements ValidationRule
{
    public function validate(string $attribute, mixed $value, Closure $fail): void
    {
        if (! self::digitosValidos(preg_replace('/\D/', '', $value))) {
            $fail('O :attribute não é um CPF válido.');
        }
    }
}

'cpf' => ['required', new Cpf],
'cupom' => ['nullable', function (string $attr, mixed $valor, Closure $fail) {   // regra inline
    if (! Cupom::ativo($valor)) $fail('Cupom expirado.');
}],
```

### Validator manual

```php
$validator = Validator::make($dados, $regras, $mensagens, $atributos);

if ($validator->fails()) {
    return response()->json(['errors' => $validator->errors()], 422);
}

$validator->errors()->first('email');
$validados = $validator->validated();
$validator->validate();    // lança ValidationException (o Laravel transforma em 422/redirect)
```
