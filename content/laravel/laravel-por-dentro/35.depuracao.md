Quando um método é desconhecido ou o resultado é inesperado, veja o SQL gerado. Estas ferramentas mostram exatamente o que o Eloquent está pedindo ao banco.

### Ver o SQL sem executar

| Método | Mostra |
| --- | --- |
| `toSql()` | SQL com `?` no lugar dos valores |
| `getBindings()` | Os valores dos `?` |
| `toRawSql()` | SQL com os valores já inseridos (*Laravel 10+*) |
| `dump()` / `dd()` | Imprime SQL e bindings (o `dd` para a execução) |
| `dumpRawSql()` / `ddRawSql()` | Imprime o SQL com valores |
| `explain()` | Plano de execução do banco (uso de índices) |

```php [app/Http/Controllers/UserController.php]
User::byToken('abc')->where('ativo', 1)->toRawSql();
-- select * from "users" where "token" = 'abc' and "ativo" = 1

Pedido::with('itens')->where('total', '>', 100)->ddRawSql();
```

`toSql` mostra só a query principal; eager loads (`with`) rodam como queries separadas depois do `get()`.

### Registrar todas as queries executadas

```php [app/Http/Controllers/UserController.php]
DB::enableQueryLog();
$users = User::with('pedidos')->get();
dd(DB::getQueryLog());   // lista de queries, bindings e tempo

DB::listen(function ($query) {   // no AppServiceProvider
    Log::debug($query->toRawSql(), ['ms' => $query->time]);
});
```

Ferramentas visuais: **Laravel Debugbar** (barra no navegador com todas as queries e alertas de N+1) e **Laravel Telescope** (painel de requisições, queries e eventos).

### Testar no console: `tinker`

```bash
php artisan tinker
```

```php [php artisan tinker]
> User::byToken('abc')->toRawSql()
> $u = User::first()
> $u->getAttributes()
> $u->getDirty()
> get_class_methods($u)          // lista métodos da instância (incluindo os herdados)
> (new ReflectionMethod(User::class, 'scopeByToken'))->getFileName()  // onde foi definido
```

### Comandos e ferramentas para entender Models

| Ferramenta | Para quê |
| --- | --- |
| `php artisan model:show User` | Tabela, colunas, tipos, casts, relacionamentos, observers |
| `php artisan db:table users` | Estrutura da tabela no banco |
| `php artisan db:show` | Visão geral do banco |
| `barryvdh/laravel-ide-helper` (`php artisan ide-helper:models`) | Gera PHPDoc para a IDE autocompletar colunas, relacionamentos e scopes, e "ir para definição" |
| `Model::preventLazyLoading()` | Encontra N+1 ([seção 32](#modo-estrito)) |
| Documentação oficial: laravel.com/docs → Eloquent | Referência completa |
| API reference: api.laravel.com | Todos os métodos de `Model`, `Eloquent\Builder` e `Query\Builder`, com assinaturas |
