A biblioteca padrão de Go é grande e estável, e projetos Go usam bem menos dependências que em outras linguagens. Estes são os pacotes que você vai encontrar em quase todo arquivo.

### fmt: imprimir e formatar

```go
fmt.Println("a", 1, true)                 // separa com espaço, quebra linha
fmt.Printf("%s tem %d anos\n", name, age) // formato
s := fmt.Sprintf("%05.2f", 3.14159)       // devolve string: "03.14"
fmt.Fprintf(w, "olá %s", name)            // escreve num io.Writer (arquivo, resposta HTTP)
err := fmt.Errorf("falhou: %w", err)
```

| Verbo | Mostra |
| --- | --- |
| `%v` | o valor no formato padrão (serve para tudo) |
| `%+v` | structs com nome dos campos: `{Name:Ana Age:30}` |
| `%#v` | sintaxe Go: `main.User{Name:"Ana", Age:30}` (ótimo para depurar) |
| `%T` | o tipo: `main.User` |
| `%d` `%x` `%b` | inteiro em decimal, hexadecimal, binário |
| `%f` `%.2f` `%e` | float, com 2 casas, notação científica |
| `%s` `%q` | string, string entre aspas com escapes |
| `%t` | bool |
| `%p` | ponteiro |
| `%w` | só no `Errorf`: embrulha um erro |

Um tipo com método `String() string` (a interface `fmt.Stringer`) é impresso pelo próprio método em `%v` e `%s`.

### strings e strconv

```go
strings.Contains("golang", "lang")      // true
strings.HasPrefix(s, "http")             // também HasSuffix
strings.Split("a,b,c", ",")              // []string{"a", "b", "c"}
strings.Join([]string{"a", "b"}, "-")    // "a-b"
strings.TrimSpace("  oi \n")             // "oi"
strings.ToLower(s); strings.ReplaceAll(s, "a", "b")
before, after, found := strings.Cut("key=value", "=")  // "key", "value", true

var sb strings.Builder                   // montar string em laço sem realocar
for _, w := range words {
	sb.WriteString(w)
}
result := sb.String()

strconv.Itoa(42)                         // "42"
n, err := strconv.Atoi("42")             // 42
f, err := strconv.ParseFloat("3.14", 64)
b, err := strconv.ParseBool("true")
```

O pacote `bytes` tem as mesmas funções para `[]byte`, e `unicode` classifica runes (`unicode.IsUpper`).

### time

```go
now := time.Now()
later := now.Add(90 * time.Minute)
d := later.Sub(now)                      // time.Duration: 1h30m0s
time.Since(start)                        // quanto tempo passou: muito usado para medir
now.Before(later); now.Equal(other)      // compare com métodos, não com ==

time.Sleep(500 * time.Millisecond)
timeout := 5 * time.Second               // Duration é um int64 de nanossegundos

// formatação usa uma DATA DE REFERÊNCIA, não %Y-%m-%d:
now.Format("2006-01-02 15:04:05")        // "2026-11-12 14:30:00"
now.Format(time.RFC3339)                 // "2026-11-12T14:30:00-04:00"
t, err := time.Parse("02/01/2006", "25/12/2026")
```

::note{type="tip" title="A data mágica"}
O layout de `Format` e `Parse` é a data `Mon Jan 2 15:04:05 MST 2006` escrita do jeito que você quer a saída. Decore pela sequência 1 2 3 4 5 6 7: mês **01**, dia **02**, hora **15** (3 da tarde), minuto **04**, segundo **05**, ano **2006**, fuso **-07**00. `"02/01/2006"` é o formato brasileiro.
::

### os e io: arquivos e fluxos

```go
data, err := os.ReadFile("config.json")         // lê tudo
err = os.WriteFile("out.txt", data, 0o644)     // escreve tudo (0o644 = permissões)

f, err := os.Open("big.log")                   // só leitura; os.Create cria/trunca
if err != nil { return err }
defer f.Close()

scanner := bufio.NewScanner(f)                 // ler linha por linha
for scanner.Scan() {
	line := scanner.Text()
	_ = line
}
if err := scanner.Err(); err != nil { return err }

port := os.Getenv("PORT")                      // variável de ambiente
os.Exit(1)                                     // sai NA HORA, sem rodar os defer
```

`io.Copy(dst, src)`, `io.ReadAll(r)`, `io.MultiWriter(a, b)` e `io.TeeReader` trabalham com qualquer `io.Reader`/`io.Writer`, então servem igual para arquivo, rede e memória. `path/filepath` monta caminhos (`filepath.Join("dir", "a.txt")`) e o pacote `embed` coloca arquivos dentro do binário (`//go:embed templates/*`).

### encoding/json

```go
type Order struct {
	ID       int64      `json:"id"`
	Customer string     `json:"customer"`
	Items    []Item     `json:"items"`
	Note     string     `json:"note,omitempty"` // fora do JSON se vazia
	PaidAt   *time.Time `json:"paid_at"`        // ponteiro: null quando nil
}

// struct → JSON
b, err := json.Marshal(order)                   // []byte
b, err = json.MarshalIndent(order, "", "  ")

// JSON → struct: passe um PONTEIRO
var o Order
err = json.Unmarshal(b, &o)

// em fluxos (corpo HTTP, arquivo)
err = json.NewDecoder(r.Body).Decode(&o)
err = json.NewEncoder(w).Encode(o)

// JSON de formato desconhecido
var anyData map[string]any                      // números viram float64
```

Só campos **exportados** entram no JSON. Campos que faltam no JSON ficam com o valor zero, e campos a mais são ignorados. Desde o Go 1.27, o `encoding/json` roda sobre a nova implementação `encoding/json/v2`, mais rápida e mais rigorosa (rejeita UTF-8 inválido e nomes duplicados); a API v1 continua igual.

### log/slog: logs estruturados

```go
logger := slog.New(slog.NewJSONHandler(os.Stdout, nil))
slog.SetDefault(logger)

slog.Info("pedido criado", "id", order.ID, "total", order.Total)
slog.Error("falha no pagamento", "err", err, "order_id", id)
log := slog.With("request_id", reqID)          // logger com campos fixos
log.Debug("cache miss", "key", key)
// {"time":"…","level":"INFO","msg":"pedido criado","id":7,"total":120.5}
```

Os argumentos depois da mensagem vêm em pares **chave, valor**. O pacote `log` antigo (`log.Println`, `log.Fatal`) também aparece muito; `log.Fatal` imprime e chama `os.Exit(1)`.

### Outros que aparecem sempre

| --- | --- |
| `errors` | `New`, `Is`, `As`, `AsType`, `Join` |
| `context` | cancelamento e prazos |

| `text/template`, `html/template` | templates (o `html/` escapa contra XSS) |
| `os/signal` | capturar Ctrl+C para desligar com calma |
