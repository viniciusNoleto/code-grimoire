Go é uma linguagem compilada, com tipagem estática e coleta de lixo, criada no Google para programas de servidor grandes mantidos por muita gente. O design inteiro gira em torno de uma ideia: **código fácil de ler vale mais que código esperto**. Por isso a linguagem tem só 25 palavras reservadas, um único laço (`for`), nenhuma herança de classe e um formatador oficial que todo mundo usa.

O resultado do `go build` é **um único binário** com tudo dentro, inclusive o runtime. No servidor não há interpretador nem máquina virtual para instalar.

### Instalar e rodar

Baixe o instalador em [go.dev/dl](https://go.dev/dl) e confira com `go version`. Para testar sem instalar nada, use [go.dev/play](https://go.dev/play).

```bash
mkdir ola && cd ola
go mod init example.com/ola   # cria o go.mod: o projeto vira um módulo
go run .                      # compila e executa sem deixar binário
go build                      # gera o executável ./ola
```

```go [main.go]
package main

import (
	"fmt"
	"os"
)

func main() {
	name := "mundo"
	if len(os.Args) > 1 {
		name = os.Args[1]
	}
	fmt.Println("Olá,", name)
}
```

### Lendo o arquivo linha por linha

| Trecho | O que significa |
| --- | --- |
| `package main` | Todo arquivo começa dizendo a que pacote pertence. `main` é especial: é o pacote que vira executável. Qualquer outro nome vira biblioteca. |
| `import ( "fmt" "os" )` | Pacotes usados neste arquivo. `fmt` (formatação e impressão) e `os` (sistema operacional) são da biblioteca padrão. Import não usado é **erro de compilação**. |
| `func main()` | O ponto de entrada. Não recebe argumentos nem devolve nada: os argumentos ficam em `os.Args` e o código de saída sai por `os.Exit(n)`. |
| `name := "mundo"` | Declara e inicializa uma variável; o tipo (`string`) é deduzido. Variável local não usada também é erro. |
| `fmt.Println(...)` | Função `Println` do pacote `fmt`. Começa com maiúscula porque é **exportada** (pública). |

::note{type="tip" title="Maiúscula é public, minúscula é private"}
Go não tem `public` nem `private`. Um nome que começa com letra maiúscula (`Println`, `User`, `MaxSize`) é visível fora do pacote; com minúscula (`name`, `parseLine`) só dentro dele. Vale para funções, tipos, variáveis, constantes, campos de struct e métodos. Essa é a regra que mais ajuda a ler código Go: bateu o olho na inicial, sabe se é API pública.
::

### As regras de sintaxe que você vai ver em todo lugar

- **Sem ponto e vírgula.** O compilador insere sozinho no fim da linha. Consequência: a chave `{` precisa ficar na **mesma linha** do `if`, `for` ou `func`; na linha de baixo é erro.
- **Sem parênteses** em volta da condição: `if x > 0 {`, `for i := 0; i < n; i++ {`. As chaves são obrigatórias, mesmo com uma linha só.
- **O tipo vem depois do nome**: `var age int`, `func add(a int, b int) int`. Lê-se da esquerda para a direita: "age é um int".
- **Comentários** com `//` e `/* */`. Um comentário colado acima de uma declaração exportada é a documentação dela (o `go doc` mostra).
- **Indentação com tab**, decidida pelo `gofmt`, não por você.

::note{type="note" title="Setas e sinais neste tomo"}
A fonte de código do grimório junta alguns pares de símbolos num desenho só: `<-` aparece como uma seta, `!=` como um sinal de diferente, `>=` e `<=` como ≥ e ≤. No editor e no teclado eles continuam sendo dois caracteres (`<` e `-`, `!` e `=`).
::

### gofmt: um estilo só

`gofmt` (ou `go fmt ./...`) reescreve o arquivo no formato oficial: tabs, alinhamento de campos e comentários, espaço em volta de operadores. Editores rodam ao salvar. Por isso todo código Go do mundo tem a mesma cara, e discussões de estilo simplesmente não existem.

### Os comandos do dia a dia

| Comando | Para quê |
| --- | --- |
| `go run .` | Compila e roda o pacote do diretório atual. |
| `go build` | Gera o binário. `GOOS=linux GOARCH=arm64 go build` compila para outra plataforma. |
| `go test ./...` | Roda os testes de todos os pacotes (`./...` = este diretório e todos abaixo). |
| `go fmt ./...` | Formata. |
| `go vet ./...` | Procura erros prováveis que compilam (formato errado no `Printf`, cópia de mutex…). |
| `go mod tidy` | Acerta o `go.mod`: adiciona dependências usadas e remove as que sobraram. |
| `go get pacote@versão` | Adiciona ou atualiza uma dependência. |
| `go doc fmt.Println` | Mostra a documentação no terminal. |
| `go fix ./...` :version[Go 1.26] | Aplica os "modernizadores": reescreve código antigo nos idiomas atuais. |

::note{type="note" title="Por que tanto erro de compilação por coisa não usada?"}
Import ou variável sobrando quase sempre é resto de refatoração ou bug (você calculou algo e esqueceu de usar). Go prefere quebrar a compilação a deixar passar. Quando você precisa ignorar algo de propósito, usa o identificador vazio `_` (próximo capítulo).
::
