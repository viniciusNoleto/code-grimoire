Tente responder antes de abrir.

::question
#title
Como saber se uma função, tipo ou campo é público em Go?

#default
Pela primeira letra. Maiúscula (`Println`, `User`, `Name`) é exportada e visível fora do pacote; minúscula só dentro dele. Vale também para campos de struct, o que explica por que um campo minúsculo nunca aparece no JSON.
::

::question
#title
Qual a diferença entre `x := 1` e `x = 1`?

#default
`:=` declara uma variável nova (com o tipo deduzido) e só funciona dentro de funções; `=` atribui a uma variável que já existe. Em `a, err := f()`, basta uma variável da esquerda ser nova. Dentro de um bloco, `:=` cria uma variável que sombreia a de fora.
::

::question
#title
O que vale uma variável declarada com `var s string` e com `var m map[string]int`?

#default
O valor zero do tipo: `""` para a string e `nil` para o map. Ler de um map `nil` devolve o valor zero; escrever nele dá panic. Crie com `make` ou com um literal.
::

::question
#title
Por que sempre se escreve `s = append(s, x)`?

#default
Porque, quando o `cap` acaba, `append` aloca um array novo e devolve um slice que aponta para ele. O slice antigo continua apontando para o array velho. Sem atribuir, o elemento novo se perde.
::

::question
#title
Fiz `part := nums[1:3]` e alterei `part[0]`. Por que `nums` mudou?

#default
Fatiar não copia: `part` é uma janela sobre o mesmo array de `nums`. Para uma cópia independente, use `slices.Clone(part)` ou `copy`.
::

::question
#title
Como distinguir "chave ausente" de "chave com valor zero" num map?

#default
Com o idioma vírgula-ok: `v, ok := m[k]`. `ok` é `false` quando a chave não existe.
::

::question
#title
Quando um método deve ter receptor de ponteiro (`*T`)?

#default
Quando altera o valor, quando a struct é grande ou quando contém um `sync.Mutex`. Na prática é o caso mais comum, e um tipo costuma usar o mesmo tipo de receptor em todos os métodos. Lembre que, com receptor ponteiro, só `*T` satisfaz a interface.
::

::question
#title
Como um tipo implementa uma interface em Go?

#default
Tendo os métodos dela. Não há `implements`: a satisfação é implícita e verificada pelo compilador onde o valor é usado como a interface. `var _ Iface = (*T)(nil)` força a verificação.
::

::question
#title
Por que `err == nil` deu `false` se a função devolveu um ponteiro `nil`?

#default
Uma interface guarda tipo e valor. Devolver um `*MyErr` nulo como `error` preenche o tipo, então a interface não é `nil`. Devolva `nil` literal no caminho de sucesso.
::

::question
#title
Qual a diferença entre `%w` e `%v` no `fmt.Errorf`?

#default
`%w` embrulha o erro: `errors.Is` e `errors.As` continuam enxergando o original na cadeia. `%v` só copia o texto e corta a cadeia.
::

::question
#title
Quando roda uma chamada com `defer`, e com quais argumentos?

#default
Quando a função que a contém retorna, por qualquer caminho (inclusive panic), em ordem inversa à dos `defer`. Os argumentos são avaliados no momento do `defer`, não na execução.
::

::question
#title
O que acontece com as goroutines quando `main` retorna?

#default
O programa termina e elas morrem no meio do trabalho. É preciso esperar explicitamente com `sync.WaitGroup`, `errgroup` ou channels.
::

::question
#title
Qual a diferença entre channel com e sem buffer?

#default
Sem buffer, envio e recebimento se encontram: quem envia bloqueia até alguém receber. Com buffer de N, o envio só bloqueia quando há N itens esperando. Num channel `nil`, as duas operações bloqueiam para sempre.
::

::question
#title
O que significam `chan<- T` e `<-chan T`?

#default
Channel só de envio e só de recebimento. A seta mostra a direção do dado em relação ao `chan`. Funções usam esses tipos para documentar e garantir quem produz e quem consome.
::

::question
#title
Para que serve o `ctx context.Context` como primeiro parâmetro?

#default
Para propagar cancelamento e prazo por toda a cadeia de chamadas de uma operação. Quando o cliente desconecta ou o timeout vence, o contexto é cancelado, e banco, chamadas HTTP e laços que o respeitam param. Depois de `WithTimeout` ou `WithCancel`, sempre `defer cancel()`.
::

::question
#title
`client.Do(req)` devolveu `err == nil`. A requisição deu certo?

#default
Não necessariamente. O erro só indica falha de transporte (DNS, conexão, timeout). Respostas 4xx e 5xx chegam com `err == nil`: confira `resp.StatusCode` e feche o `resp.Body`.
::

::question
#title
O que é `func Map[T, U any](s []T, f func(T) U) []U`?

#default
Uma função genérica: `T` e `U` são parâmetros de tipo (entre colchetes logo depois do nome), e `any` é a restrição, que aceita qualquer tipo. Na chamada, os tipos são inferidos pelos argumentos.
::
