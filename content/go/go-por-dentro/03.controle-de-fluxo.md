Go tem só três estruturas de controle: `if`, `for` e `switch` (mais o `select`, que é de concorrência). Não existe `while`, `do-while`, operador ternário nem `foreach`: tudo isso é `for` ou `if`.

### if, com e sem inicialização

```go
if age >= 18 {
	fmt.Println("maior")
} else if age >= 12 {
	fmt.Println("adolescente")
} else {
	fmt.Println("criança")
}

// if com instrução antes da condição: a variável só existe dentro do if/else
if n, err := strconv.Atoi(input); err != nil {
	fmt.Println("não é número:", err)
} else {
	fmt.Println("dobro:", n*2)
}
```

A forma `if inicialização; condição {` é muito comum, sobretudo com erros e maps (`if v, ok := m[k]; ok {`). Leia o `;` como "e então teste".

::note{type="tip" title="Sem ternário"}
Não existe `x ? a : b`. O idioma é declarar com um valor e sobrescrever:
```go
label := "inativo"
if active {
	label = "ativo"
}
```
::

### As quatro formas do for

```go
for i := 0; i < 5; i++ { }   // 1. clássico: init; condição; pós

for n < 100 { n *= 2 }        // 2. só condição: é o "while"

for {                         // 3. infinito: sai com break ou return
	if done() { break }
}

for i, v := range items { }   // 4. range: percorre uma coleção
```

`break` sai do laço, `continue` pula para a próxima volta. Não existe `i++` como expressão (`x := i++` não compila): é só uma instrução.

### range: o que cada coleção entrega

| Sobre | Primeiro valor | Segundo valor |
| --- | --- | --- |
| slice / array | índice | **cópia** do elemento |
| string | posição em bytes | rune (caractere) |
| map | chave | valor (ordem **aleatória**) |
| channel | o valor recebido | – |
| inteiro `n` :version[Go 1.22] | 0, 1, …, n-1 | – |
| função iteradora :version[Go 1.23] | o que a função entregar | idem ([capítulo de iteradores](#generics-e-iteradores)) |

```go
for i := range 3 { fmt.Println(i) }       // 0 1 2
for _, name := range names { }            // só os valores
for i := range names { }                  // só os índices
for key, value := range ages { }          // map
for range 3 { fmt.Println("oi") }         // nem precisa da variável
```

::note{type="pitfall" title="O valor do range é uma cópia"}
Em `for _, u := range users { u.Active = true }`, você altera a cópia; o slice não muda. Para modificar, use o índice: `users[i].Active = true`.
Desde o Go 1.22, cada volta cria uma **variável nova**, então capturar `v` numa closure ou goroutine dentro do laço é seguro. Em código antigo você ainda verá a gambiarra `v := v` dentro do `for`, que hoje não é mais necessária.
::

### switch

```go
switch day {
case "sáb", "dom":                // vários valores num case
	fmt.Println("fim de semana")
case "sex":
	fmt.Println("quase")
	fallthrough                   // raro: força cair no próximo case
default:
	fmt.Println("dia útil")
}

switch {                          // sem expressão: cada case é uma condição
case temp < 0:
	fmt.Println("congelando")
case temp < 25:
	fmt.Println("agradável")
default:
	fmt.Println("quente")
}

switch ext := filepath.Ext(path); ext { // também aceita inicialização
case ".go":
	// ...
}
```

Diferente de C, Java e JavaScript, **cada case para sozinho**: não precisa de `break`. O `switch` sem expressão é a forma idiomática de escrever uma cadeia longa de `if/else if`. Existe ainda o **type switch** (`switch v := x.(type)`), visto no [capítulo de interfaces](#interfaces).

### Labels: break e continue no laço de fora

```go
outer:
	for _, row := range grid {
		for _, cell := range row {
			if cell == target {
				break outer // sai dos DOIS laços
			}
		}
	}
```

Um `break` dentro de `switch` ou `select` sai só do `switch`; quando ele está dentro de um `for`, o label é o jeito de sair do laço.

### O estilo "retorne cedo"

Código Go raramente tem `else` depois de um `return`. O caminho feliz fica alinhado à esquerda, e cada problema sai cedo:

```go
func process(id string) error {
	if id == "" {
		return errors.New("id vazio")
	}
	user, err := find(id)
	if err != nil {
		return err
	}
	if !user.Active {
		return ErrInactive
	}
	return send(user)  // caminho feliz, sem aninhamento
}
```

Lendo código Go, procure o caminho feliz na margem esquerda; os blocos indentados são os desvios.
