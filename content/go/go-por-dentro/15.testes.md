Testes fazem parte da ferramenta: não há framework para instalar. Um arquivo `x_test.go` ao lado do código, funções `TestAlgo(t *testing.T)` e `go test` roda tudo.

### O básico

```go [mathx/mathx.go]
package mathx

func Abs(n int) int {
	if n < 0 {
		return -n
	}
	return n
}
```

```go [mathx/mathx_test.go]
package mathx

import "testing"

func TestAbs(t *testing.T) {
	got := Abs(-3)
	if got != 3 {
		t.Errorf("Abs(-3) = %d; quero 3", got)
	}
}
```

```bash
go test ./...              # todos os pacotes
go test -run TestAbs -v    # só os testes cujo nome casa com a regex, com saída detalhada
go test -race -cover ./... # com detector de corridas e cobertura
```

Não há `assert`: a verificação é um `if` comum. A mensagem segue o formato `Função(entrada) = obtido; quero esperado`.

| Método | Efeito |
| --- | --- |
| `t.Errorf(...)` / `t.Error` | Marca falha e **continua** o teste. |
| `t.Fatalf(...)` / `t.Fatal` | Marca falha e **para** o teste (use quando seguir não faz sentido, como um erro no setup). |
| `t.Helper()` | Na primeira linha de uma função auxiliar: a falha aponta a linha de quem chamou. |
| `t.Cleanup(f)` | Roda `f` ao fim do teste (como um `defer` que vale para helpers). |
| `t.Parallel()` | Roda este teste em paralelo com outros que também chamaram. |
| `t.TempDir()` | Diretório temporário apagado no fim. |
| `t.Context()` :version[Go 1.24] | Contexto cancelado quando o teste termina. |
| `t.Skip(...)` | Pula o teste. |

### Testes em tabela: o formato mais comum

```go
func TestParseAmount(t *testing.T) {
	tests := []struct {
		name    string
		in      string
		want    int64
		wantErr bool
	}{
		{name: "inteiro", in: "10", want: 1000},
		{name: "com centavos", in: "10,50", want: 1050},
		{name: "vazio", in: "", wantErr: true},
		{name: "letras", in: "abc", wantErr: true},
	}

	for _, tt := range tests {
		t.Run(tt.name, func(t *testing.T) {   // um subteste por linha
			got, err := ParseAmount(tt.in)
			if (err != nil) != tt.wantErr {
				t.Fatalf("erro = %v, wantErr %v", err, tt.wantErr)
			}
			if got != tt.want {
				t.Errorf("ParseAmount(%q) = %d; quero %d", tt.in, got, tt.want)
			}
		})
	}
}
```

Um slice de structs anônimas com os casos e um laço com `t.Run`. Adicionar um caso é adicionar uma linha. `go test -run 'TestParseAmount/vazio'` roda só um subteste. Quando o resultado é uma struct grande, muitos projetos comparam com `github.com/google/go-cmp` (`cmp.Diff(want, got)`) ou usam `testify` (`assert.Equal(t, want, got)`, `require.NoError(t, err)`).

### Fakes pela interface

Como interfaces são implícitas, um dublê de teste é só um tipo pequeno no arquivo de teste:

```go
type fakeSender struct {
	sent []string
	err  error
}

func (f *fakeSender) Send(ctx context.Context, to, body string) error {
	f.sent = append(f.sent, to)
	return f.err
}

func TestNotify(t *testing.T) {
	fake := &fakeSender{}
	svc := NewService(fake)          // o serviço só conhece a interface Sender

	if err := svc.Notify(t.Context(), "ana@x.com"); err != nil {
		t.Fatal(err)
	}
	if len(fake.sent) != 1 {
		t.Errorf("enviou %d mensagens; quero 1", len(fake.sent))
	}
}
```

### Testar HTTP com httptest

```go
func TestGetTodo(t *testing.T) {
	s := &store{todos: map[int]Todo{1: {ID: 1, Title: "x"}}}
	mux := http.NewServeMux()
	mux.HandleFunc("GET /todos/{id}", s.get)

	req := httptest.NewRequest("GET", "/todos/1", nil)
	rec := httptest.NewRecorder()           // um ResponseWriter que grava tudo
	mux.ServeHTTP(rec, req)

	if rec.Code != http.StatusOK {
		t.Fatalf("status = %d", rec.Code)
	}
}
```

`httptest.NewServer(handler)` sobe um servidor real numa porta local, para testar clientes HTTP.

### Pacote de teste externo

Um arquivo de teste com `package mathx_test` (sufixo `_test`) só enxerga a API exportada, como um usuário do pacote. Os dois estilos convivem no mesmo diretório.

### Benchmarks, exemplos e fuzzing

```go
func BenchmarkAbs(b *testing.B) {
	for b.Loop() {               // Go 1.24+; código antigo usa for i := 0; i < b.N; i++
		Abs(-3)
	}
}

func ExampleAbs() {              // aparece na documentação E é testado
	fmt.Println(Abs(-5))
	// Output: 5
}

func FuzzParseAmount(f *testing.F) {
	f.Add("10,50")               // entrada inicial
	f.Fuzz(func(t *testing.T, s string) {
		ParseAmount(s)           // não pode dar panic com nenhuma entrada
	})
}
```

```bash
go test -bench=. -benchmem   # tempo e alocações por operação
go test -fuzz=FuzzParseAmount
```

### Onde ficam os dados de teste

Um diretório `testdata/` dentro do pacote é ignorado pelo compilador e pelo `go build`: é o lugar de arquivos de entrada, JSONs de exemplo e "golden files".
