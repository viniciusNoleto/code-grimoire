A biblioteca padrão já traz um servidor HTTP de produção. Muitos serviços Go usam só `net/http`; frameworks como chi, Echo e Gin seguem as mesmas ideias, então entender a base é o que permite ler qualquer um deles.

### O serviço completo

```go [main.go]
package main

import (
	"context"
	"encoding/json"
	"errors"
	"log/slog"
	"net/http"
	"os"
	"os/signal"
	"strconv"
	"sync"
	"time"
)

type Todo struct {
	ID    int    `json:"id"`
	Title string `json:"title"`
	Done  bool   `json:"done"`
}

type store struct {
	mu    sync.Mutex
	next  int
	todos map[int]Todo
}

func (s *store) list(w http.ResponseWriter, r *http.Request) {
	s.mu.Lock()
	defer s.mu.Unlock()
	out := make([]Todo, 0, len(s.todos))
	for _, t := range s.todos {
		out = append(out, t)
	}
	writeJSON(w, http.StatusOK, out)
}

func (s *store) get(w http.ResponseWriter, r *http.Request) {
	id, err := strconv.Atoi(r.PathValue("id")) // o {id} da rota
	if err != nil {
		http.Error(w, "id inválido", http.StatusBadRequest)
		return // sempre retorne depois de responder com erro
	}
	s.mu.Lock()
	t, ok := s.todos[id]
	s.mu.Unlock()
	if !ok {
		http.NotFound(w, r)
		return
	}
	writeJSON(w, http.StatusOK, t)
}

func (s *store) create(w http.ResponseWriter, r *http.Request) {
	var in struct {
		Title string `json:"title"`
	}
	if err := json.NewDecoder(r.Body).Decode(&in); err != nil || in.Title == "" {
		http.Error(w, "json inválido", http.StatusBadRequest)
		return
	}
	s.mu.Lock()
	s.next++
	t := Todo{ID: s.next, Title: in.Title}
	s.todos[t.ID] = t
	s.mu.Unlock()
	writeJSON(w, http.StatusCreated, t)
}

func writeJSON(w http.ResponseWriter, status int, v any) {
	w.Header().Set("Content-Type", "application/json")
	w.WriteHeader(status) // cabeçalhos ANTES do WriteHeader; corpo depois
	json.NewEncoder(w).Encode(v)
}

func logging(next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		start := time.Now()
		next.ServeHTTP(w, r)
		slog.Info("req", "method", r.Method, "path", r.URL.Path, "dur", time.Since(start))
	})
}

func main() {
	s := &store{todos: make(map[int]Todo)}

	mux := http.NewServeMux()
	mux.HandleFunc("GET /todos", s.list)
	mux.HandleFunc("GET /todos/{id}", s.get)
	mux.HandleFunc("POST /todos", s.create)

	srv := &http.Server{
		Addr:              ":8080",
		Handler:           logging(mux),
		ReadHeaderTimeout: 5 * time.Second,
	}

	ctx, stop := signal.NotifyContext(context.Background(), os.Interrupt)
	defer stop()

	go func() {
		if err := srv.ListenAndServe(); err != nil && !errors.Is(err, http.ErrServerClosed) {
			slog.Error("servidor", "err", err)
			os.Exit(1)
		}
	}()

	<-ctx.Done() // espera o Ctrl+C
	shutdown, cancel := context.WithTimeout(context.Background(), 10*time.Second)
	defer cancel()
	srv.Shutdown(shutdown) // para de aceitar e espera as requisições em andamento
}
```

### As peças

| Peça | O que é |
| --- | --- |
| `http.Handler` | A interface central: `ServeHTTP(w http.ResponseWriter, r *http.Request)`. Tudo que responde HTTP é um Handler. |
| `http.HandlerFunc` | Um tipo função que satisfaz `Handler`. Converte `func(w, r)` comum em Handler. |
| `w http.ResponseWriter` | Onde se escreve a resposta: `w.Header().Set`, `w.WriteHeader(código)`, `w.Write(bytes)`. É um `io.Writer`. |
| `r *http.Request` | A requisição: `r.Method`, `r.URL.Query().Get("q")`, `r.Header.Get(...)`, `r.Body` (um `io.Reader`), `r.Context()`, `r.PathValue("id")`. |
| `http.ServeMux` | O roteador. Desde o Go 1.22 aceita método e curingas: `"GET /todos/{id}"`, `"/files/{path...}"`. |
| `http.Server` | O servidor com endereço, handler e timeouts. |

Cada requisição roda na **sua própria goroutine**. Por isso o `store` precisa de mutex: duas requisições podem mexer no map ao mesmo tempo.

### Middleware: uma função que embrulha um Handler

O padrão `func(next http.Handler) http.Handler` é o middleware em Go. Ele recebe o próximo handler e devolve um novo que faz algo antes e/ou depois de chamar `next.ServeHTTP`. Encadear é aninhar: `logging(auth(mux))`. Chi, Echo e Gin usam a mesma ideia com assinaturas próprias.

Para passar dados do middleware para o handler (o usuário autenticado), usa-se o contexto: `r = r.WithContext(context.WithValue(r.Context(), userKey{}, u))`.

### Cliente HTTP

```go
client := &http.Client{Timeout: 10 * time.Second} // o http.DefaultClient NÃO tem timeout

req, err := http.NewRequestWithContext(ctx, http.MethodGet, "https://api.x.com/users/7", nil)
if err != nil { return err }
req.Header.Set("Authorization", "Bearer "+token)

resp, err := client.Do(req)
if err != nil { return err }
defer resp.Body.Close()                 // sempre feche o corpo

if resp.StatusCode != http.StatusOK {   // 4xx e 5xx NÃO são erro para o Go
	return fmt.Errorf("api: status %d", resp.StatusCode)
}
var u User
if err := json.NewDecoder(resp.Body).Decode(&u); err != nil { return err }
```

::note{type="pitfall" title="Status ruim não é err"}
`client.Do` só devolve erro quando a requisição nem completou (DNS, conexão, timeout). Uma resposta 404 ou 500 chega com `err == nil`: confira `resp.StatusCode` sempre.
::

### Frameworks que você vai encontrar

| Biblioteca | Como reconhecer |
| --- | --- |
| chi | `r := chi.NewRouter()`, `r.Get("/todos/{id}", h)`, `chi.URLParam(r, "id")`. Handlers continuam `func(w, r)`. |
| Gin | `r := gin.Default()`, handlers `func(c *gin.Context)`, `c.JSON(200, x)`, `c.Param("id")`. |
| Echo | `e := echo.New()`, handlers `func(c echo.Context) error`, `return c.JSON(200, x)`. |
| Fiber | `app := fiber.New()`, `func(c *fiber.Ctx) error`; não usa `net/http` por baixo. |

Banco de dados costuma vir com `database/sql` + driver, `pgx` (PostgreSQL) ou `sqlc` (gera Go a partir de SQL). ORMs como GORM existem, mas são menos comuns do que em outras linguagens.
