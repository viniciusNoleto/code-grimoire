Com a sintaxe dos capítulos anteriores, o que falta para ler código Go com fluência são as **convenções**: padrões que a linguagem não exige, mas que a comunidade inteira segue. Este capítulo junta os que mais aparecem.

### Nomes

| Convenção | Exemplo | Por quê |
| --- | --- | --- |
| Nomes curtos para escopos curtos | `i`, `n`, `r`, `w`, `ctx`, `err`, `ok`, `buf` | A variável vive três linhas; o tipo já diz o resto. |
| Nomes longos para escopos longos | `defaultRetryPolicy`, `ErrInvalidSignature` | Visíveis no pacote todo. |
| MixedCaps, nunca `_` | `userID`, `parseURL`, `MaxBodySize` | Siglas ficam todas maiúsculas: `ID`, `URL`, `HTTP`, `JSON`. |
| Receptor de 1 a 2 letras | `func (s *Server)`, `func (c *Client)` | Sempre o mesmo nome em todos os métodos do tipo. |
| Sem `Get` em getters | `u.Name()`, e `u.SetName(n)` no setter | |
| Interfaces de um método terminam em `-er` | `Reader`, `Validator`, `Notifier` | |
| Pacote não se repete no nome | `order.Service`, não `order.OrderService` | Quem chama já escreve `order.`. |

Abreviações comuns: `r` (request ou reader), `w` (writer), `b` (bytes ou benchmark), `t` (teste), `tt` (caso de teste), `fn`/`f` (função), `mu` (mutex), `wg` (WaitGroup), `cfg` (config), `srv` (server), `db`, `tx` (transação), `req`/`resp`.

### Idiomas que você vai encontrar

**Vírgula-ok**: o segundo retorno `bool` diz se deu certo, sem erro detalhado.

```go
v, ok := m[key]          // a chave existe?
s, ok := x.(string)      // é string?
v, ok := <-ch            // o channel ainda está aberto?
```

**Verificação em compilação** de que um tipo satisfaz uma interface:

```go
var _ http.Handler = (*Router)(nil)
```

**Opções funcionais**: o substituto de parâmetros opcionais e builders.

```go
type Option func(*Client)

func WithTimeout(d time.Duration) Option {
	return func(c *Client) { c.timeout = d }
}

func NewClient(base string, opts ...Option) *Client {
	c := &Client{base: base, timeout: 10 * time.Second} // padrões
	for _, opt := range opts {
		opt(c)
	}
	return c
}

c := NewClient("https://api.x.com", WithTimeout(3*time.Second), WithRetries(2))
```

A alternativa também comum é uma struct de config: `NewClient(Config{Base: "...", Timeout: 3 * time.Second})`, aproveitando o valor zero como "padrão".

**Struct vazia como sinal**: `chan struct{}` (só o evento importa), `map[string]struct{}` (conjunto).

**Embutir para "herdar" comportamento** em testes e wrappers: `type loggingWriter struct{ http.ResponseWriter; status int }` só sobrescreve `WriteHeader` e herda o resto.

**Accept interfaces, return structs**: parâmetros como interfaces pequenas, retornos como tipos concretos ([capítulo de interfaces](#interfaces-onde-declarar-a-interface)).

**Erro cedo, caminho feliz à esquerda** ([capítulo de controle de fluxo](#controle-de-fluxo-o-estilo-retorne-cedo)).

### Diretivas e comentários especiais

Comentários que começam com `//go:` (sem espaço) são instruções para a ferramenta:

| Diretiva | Efeito |
| --- | --- |
| `//go:build linux && !arm` | No topo do arquivo: só compila nessas condições (build tags). |
| `//go:embed static/*` | Embute arquivos no binário, na variável logo abaixo (`embed.FS`, `string` ou `[]byte`). |
| `//go:generate stringer -type=Status` | Comando rodado por `go generate`; gera código (mocks, enums, sqlc). |
| `//go:fix inline` :version[Go 1.26] | Marca uma função antiga para o `go fix` substituir pelas chamadas do corpo dela. |
| `//nolint:errcheck` | Silencia um linter na linha (do golangci-lint, não do Go). |

Arquivos com sufixos `_linux.go`, `_windows.go`, `_amd64.go` só compilam naquele sistema ou arquitetura. Arquivos que começam com `// Code generated ... DO NOT EDIT.` são gerados: leia o que gerou, não edite.

### Um arquivo real, comentado

Um repositório de pedidos sobre PostgreSQL, no estilo que você vai encontrar em serviços Go:

```go [internal/order/repo.go]
package order // o pacote se chama order: as chamadas lá fora serão order.NewRepo, order.ErrNotFound

import (
	"context"
	"database/sql"
	"errors"
	"fmt"
	"time"
)

// ErrNotFound é devolvido quando o pedido não existe.
var ErrNotFound = errors.New("pedido não encontrado") // erro sentinela: testável com errors.Is

type Status int // um enum: tipo próprio + constantes com iota

const (
	StatusPending  Status = iota // 0
	StatusPaid                   // 1
	StatusCanceled               // 2
)

type Order struct { // exportada: maiúscula
	ID        int64
	Customer  string
	Total     int64 // em centavos
	Status    Status
	CreatedAt time.Time
}

// Repo acessa os pedidos no banco.
type Repo struct {
	db *sql.DB // minúsculo: só o pacote mexe
}

func NewRepo(db *sql.DB) *Repo { // "construtor" por convenção
	return &Repo{db: db}
}

// Find busca um pedido pelo ID.
func (r *Repo) Find(ctx context.Context, id int64) (*Order, error) { // ctx primeiro, error por último
	const q = `SELECT id, customer, total, status, created_at
	           FROM orders WHERE id = $1` // raw string: SQL multilinha

	var o Order
	err := r.db.QueryRowContext(ctx, q, id).Scan( // ctx repassado: cancela a consulta junto com a requisição
		&o.ID, &o.Customer, &o.Total, &o.Status, &o.CreatedAt, // Scan escreve nos endereços
	)
	if errors.Is(err, sql.ErrNoRows) {
		return nil, ErrNotFound // traduz o erro do banco para o do domínio
	}
	if err != nil {
		return nil, fmt.Errorf("buscar pedido %d: %w", id, err) // contexto + %w
	}
	return &o, nil // sucesso: nil literal no erro
}

// MarkPaid marca o pedido como pago dentro de uma transação.
func (r *Repo) MarkPaid(ctx context.Context, id int64) (err error) { // retorno nomeado
	tx, err := r.db.BeginTx(ctx, nil)
	if err != nil {
		return err
	}
	defer func() { // roda em qualquer saída
		if err != nil {
			tx.Rollback() // houve erro: desfaz
		}
	}()

	res, err := tx.ExecContext(ctx,
		`UPDATE orders SET status = $1 WHERE id = $2 AND status = $3`,
		StatusPaid, id, StatusPending)
	if err != nil {
		return fmt.Errorf("atualizar pedido %d: %w", id, err)
	}
	if n, _ := res.RowsAffected(); n == 0 { // if com inicialização; o erro ignorado de propósito
		return ErrNotFound
	}
	return tx.Commit() // o erro do Commit vira o err nomeado que o defer enxerga
}
```

### Roteiro para um repositório desconhecido

1. **`go.mod`**: versão do Go e dependências. Já diz se é chi ou Gin, pgx ou GORM, gRPC ou HTTP.
2. **`cmd/*/main.go`**: onde tudo é montado. Siga as chamadas `NewAlgo(...)` para descobrir as peças e como se conectam.
3. **Tipos exportados de cada pacote**: `go doc ./internal/order` lista a API pública. Comece pelas structs e interfaces.
4. **Testes**: os `_test.go` mostram como cada coisa deve ser usada, com entradas e saídas reais.
5. **Ferramentas do editor**: com o `gopls` (o servidor de linguagem oficial, usado pelo VS Code e GoLand), "ir para definição" e "encontrar implementações" de uma interface resolvem quase toda dúvida de "de onde vem isso?".
